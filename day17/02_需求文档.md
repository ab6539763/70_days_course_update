## 4. 功能需求

### 4.1 PromptTemplate

| 字段 | 说明 |
|------|------|
| `instruction` | 任务指令 |
| `context` | 可选背景 |
| `input_text` | 待处理输入 |
| `output_format` | 输出格式约束 |
| `role` | system 角色扮演 |
| `examples` | few-shot 示例列表 |
| `build_user_prompt()` | 拼装完整 user 内容 |
| `to_messages()` | 输出 OpenAI messages |

### 4.2 prompt_library（10 条）

| 编号 | 任务类型 | 文件名 |
|------|----------|--------|
| P01-P02, P09 | translation | `01_`, `02_`, `09_` |
| P03-P04 | summary | `03_`, `04_` |
| P05-P06 | rewrite | `05_`, `06_` |
| P07-P08, P10 | classification | `07_`, `08_`, `10_` |

### 4.3 few_shot_demo.py

- zero-shot：0 个示例  
- one-shot：1 个示例  
- few-shot：3 个示例  
- 额外演示角色扮演改写  

### 4.4 llm_client.py

- 无 Key → mock 模式  
- mock 根据关键词返回翻译/摘要/改写/分类确定性结果
