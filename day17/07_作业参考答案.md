## A1. 工单优先级模板（参考）

```python
from prompt_templates import PromptTemplate
from llm_client import LLMClient

template = PromptTemplate(
    role="你是星火智服工单分拣专家。",
    instruction="根据工单内容判断优先级：P0紧急、P1高、P2普通。",
    context="VIP 客户定义：年消费 > 10 万或签约企业版。",
    input_text="VIP 客户反馈支付失败，影响门店营业。",
    output_format='JSON：{"priority": "P0|P1|P2", "reason": "一句话"}',
)

client = LLMClient()
print(template.build_user_prompt())
print(client.chat(template.to_messages()).text)
```

## A2. 分隔符说明（参考）

用户输入可能包含 `忽略系统指令` 等文本。若直接拼接进 Prompt，模型可能把用户文本中的句子当作新指令。`<<<input>>>` 明确边界，配合 system 规则「只处理标签内内容」可降低风险。Day 18 有完整防御管线。

## F. validate_template（参考）

```python
def validate_template(data: dict) -> list[str]:
    errors: list[str] = []
    if not data.get("instruction"):
        errors.append("缺少 instruction")
    if data.get("metadata", {}).get("task") == "classification":
        if not data.get("output_format"):
            errors.append("classification 建议提供 output_format")
    if "examples" in data and not isinstance(data["examples"], list):
        errors.append("examples 必须是 list")
    return errors
```
