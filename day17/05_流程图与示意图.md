## 1. Prompt 四要素拼装流程

```mermaid
flowchart TB
    subgraph Template["PromptTemplate"]
        R[role → system]
        I[instruction]
        C[context 可选]
        E[examples 可选]
        IN[input_text]
        O[output_format]
    end

    R --> MSG[messages 列表]
    I --> UP[build_user_prompt]
    C --> UP
    E --> UP
    IN --> UP
    O --> UP
    UP --> MSG
    MSG --> LLM[LLMClient.chat]
    LLM --> MOCK{有 Key?}
    MOCK -->|否| M[mock 关键词路由]
    MOCK -->|是| L[live HTTP API]
    M --> OUT[模型输出]
    L --> OUT
```

## 4. prompt_library 加载时序

```mermaid
sequenceDiagram
    participant Main as prompt_templates.py
    participant Loader as load_prompt_library
    participant FS as prompt_library/*.json
    participant PT as PromptTemplate
    participant LLM as LLMClient

    Main->>Loader: Path("prompt_library")
    Loader->>FS: glob *.json
    FS-->>Loader: 10 files
    loop each template
        Loader->>PT: PromptTemplate(**data)
        Main->>LLM: chat(template.to_messages())
        LLM-->>Main: ChatResponse
    end
```
