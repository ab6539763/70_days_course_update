## 3. 数据模型

### 3.1 RAGEvalInput

```python
@dataclass
class RAGEvalInput:
    question: str
    answer: str
    contexts: list[str]           # RAG 实际检索到的
    ground_truth_answer: str
    ground_truth_contexts: list[str]
```

### 3.2 RAGEvalScores

| 字段 | 范围 | 含义 |
|------|------|------|
| faithfulness | 0–1 | 答案是否忠于 contexts |
| answer_relevance | 0–1 | 答案是否回应 question |
| context_precision | 0–1 | 检索噪声比例（越低越差） |
| context_recall | 0–1 | 标准上下文覆盖度 |

## 4. 指标计算设计（教学版）

### 4.1 faithfulness

```text
  答案按句切分
       │
       ▼
  每句与 contexts 算 Jaccard
       │
       ▼
  支撑句比例 × 0.7 + 平均相似度 × 0.3
```

### 4.2 context_precision

```text
  对每条 retrieved context：
    与 question 或 ground_truth_context 相似度 > 阈值 → 相关
  precision = 相关条数 / 检索总条数
```

故意在 `mock_rag_pipeline` 混入噪声 context，使 precision ≈ 0.5 便于教学观察。
