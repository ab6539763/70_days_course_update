## 4. 功能需求

### 4.1 sample_qa_pairs.json

| 字段 | 说明 |
|------|------|
| id | 唯一标识 |
| category | 分类 |
| question | 用户问题 |
| ground_truth_answer | 标准答案 |
| ground_truth_contexts | 应被检索到的上下文列表 |
| tags | 可选标签 |

至少 8 条种子；`build_test_set.py` 合并后 ≥ 10 条。

### 4.2 rag_eval_demo.py

| 符号 | 行为 |
|------|------|
| `score_faithfulness` | 答案句子是否被 contexts 支撑 |
| `score_answer_relevance` | 问题与答案语义重叠 |
| `score_context_precision` | 检索结果中相关条占比 |
| `score_context_recall` | 标准上下文被覆盖比例 |
| `evaluate_rag_sample` | 返回 `RAGEvalScores` |
| `mock_rag_pipeline` | 模拟检索 + 故意混入噪声 |

### 4.3 build_test_set.py

| 符号 | 行为 |
|------|------|
| `parse_markdown_sections` | 按 `##` 切分 |
| `build_from_kb` | 从 `data/*.md` 生成 QA |
| `merge_pairs` | 种子优先去重 |
| `validate_pairs` | 字段完整性校验 |

### 4.4 ragas_eval.py

| 模式 | 行为 |
|------|------|
| ragas | `evaluate()` + 四指标 |
| mock_heuristic | 调用 `rag_eval_demo` |
| `--force-mock` | 强制启发式 |
