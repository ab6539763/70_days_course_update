## 第一章 · 为什么 RAG 必须评估（09:00–09:45）

### 1.1 幻觉的两种来源

| 类型 | 原因 | 指标 |
|------|------|------|
| 无依据编造 | 答案未出现在 contexts | **faithfulness** |
| 答非所问 | 检索偏了或生成偏了 | **answer relevance** |
| 检索噪声 | Top-K 里无关片段多 | **context precision** |
| 检索遗漏 | 该找的 chunk 没进上下文 | **context recall** |

### 1.2 评估 vs 单元测试

- 单元测试：函数输入输出确定  
- RAG 评估：LLM 输出有随机性 → 用 **黄金集 + 统计指标**

## 第二章 · 四大指标详解（09:45–11:00）

### 2.1 Faithfulness（忠实度）

**定义**：生成的答案是否可以从检索到的上下文中推断出来。

```text
  坏例子：
    context: 「退款 3-7 个工作日到账」
    answer:  「退款 30 个工作日到账」  → faithfulness 低

  好例子：
    answer  复述 context 中的事实     → faithfulness 高
```

打开 [code/rag_eval_demo.py](./code/rag_eval_demo.py) 中 `score_faithfulness`。

### 2.2 Answer Relevance（答案相关性）

**定义**：答案是否针对用户问题，而非泛泛而谈。

### 2.3 Context Precision（上下文精确率）

**定义**：检索到的片段里，有多少是真正相关的。

```text
  检索 4 条，2 条相关 → precision = 0.5
```

今日 `mock_rag_pipeline` **故意加噪声**，便于观察 precision 下降。

### 2.4 Context Recall（上下文召回率）

**定义**：标准答案依赖的上下文，有多少被检索到了。

▶ 运行：`python3 rag_eval_demo.py`

## 第四章 · Ragas 框架（14:00–15:30）

### 4.1 Ragas 是什么

[Ragas](https://docs.ragas.io/) 是 RAG 评估开源框架，常用 LLM-as-judge 计算指标。

```python
from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy, context_precision, context_recall
```

### 4.2 本课封装：ragas_eval.py

| 模式 | 说明 |
|------|------|
| `ragas` | 官方 evaluate |
| `mock_heuristic` | 无 Ragas 时用 `rag_eval_demo` |
| `mock_fallback` | Ragas 调用失败时回退 |

```bash
python3 ragas_eval.py --force-mock --limit 5
python3 ragas_eval.py --json
```

### 4.3 安装 Ragas（选做）

```bash
pip install ragas datasets
export OPENAI_API_KEY=sk-...
python3 ragas_eval.py --limit 3
```
