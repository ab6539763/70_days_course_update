## 第 2 节 · 工具层 tools/（60 min）

### 2.1 日历工具

打开 `tools/calendar.py`：

- `calendar_list(days)` — 只读查询  
- `calendar_schedule(...)` — 写操作，Executor 在审批后调用  

**课堂提问**：为何 list 与 schedule 拆成两个工具？  
**答案**：读写在 Agent 策略上分离；schedule 属于敏感写操作。

### 2.2 邮件工具

`tools/email_tool.py`：

```python
draft = email_draft(["team@x.com"], "主题", "正文")
send = email_send(draft["draft"]["draft_id"])  # 仅审批后
```

### 2.3 文档 RAG

`tools/document_rag.py` 扫描 `data/sample_docs/`：

```bash
ls data/sample_docs/
# refund_policy.md  office_handbook.md
```

演示：

```python
from tools.document_rag import build_rag_index, document_rag_search
build_rag_index()
document_rag_search("退款 7 天")
```

### 2.4 联网搜索 mock

`web_search(query)` 返回固定模板——答辩时说明 **接口形状与 live 一致**，便于替换 Serper/Tavily。

### 2.5 任务列表

衔接 Day 4：`task_list_add` / `task_list_list`。

| 现象 | 原因 | 处理 |
