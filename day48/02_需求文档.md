## 2. 用户故事

### US-01 任务拆解

**作为** 运营专员  
**我希望** 输入自然语言任务后系统自动生成执行计划  
**以便** 我知道 Agent 将要做什么  

**验收**：Planner 输出 ≥2 步计划，字段 `plan: list[str]`

### US-02 内外部调研

**作为** 运营专员  
**我希望** 系统自动检索公司制度并补充外部资讯  
**以便** 邮件内容有依据  

**验收**：Researcher 同时调用 `document_rag_search` 与 `web_search`

### US-03 草稿与敏感动作隔离

**作为** 主管  
**我希望** 邮件先进入草稿态，发送前必须审批  
**以便** 避免误发客户  

**验收**：`email_draft` 与 `email_send` 分离；Day 49 接 interrupt

### US-04 日历协同

**作为** 项目经理  
**我希望** 任务含「会议」时能预览并创建日程  
**以便** 减少手工建会  

**验收**：`calendar_schedule` 返回 event id

### US-05 离线演示

**作为** 培训学员  
**我希望** 无 API Key 也能完整跑通 mock  
**以便** 答辩不依赖外网  

**验收**：`SPARKTECH_MOCK=1` 时全链路可用
