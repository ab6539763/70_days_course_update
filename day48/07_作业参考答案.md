## B2 · keyword 过滤参考

```python
def calendar_list(days: int = 7, keyword: str | None = None) -> dict[str, Any]:
    events = list(_EVENTS)
    if keyword:
        kw = keyword.lower()
        events = [e for e in events if kw in e["title"].lower()]
    return {"tool": "calendar_list", "days": days, "events": events, ...}
```

## X1 · 合规 Agent 片段

```python
SENSITIVE = ("机密", "薪资", "裁员")

class ComplianceAgent:
  def run(self, body: str) -> dict:
    warnings = [w for w in SENSITIVE if w in body]
    return {"agent": "compliance", "warnings": warnings, "blocked": bool(warnings)}
```
