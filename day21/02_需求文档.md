### 4.2 integrated_assistant.py

#### 4.2.1 ConversationSession

| 符号 | 行为 |
|------|------|
| `add_user_message(text)` | 追加 user 消息 |
| `add_assistant_message(text)` | 追加 assistant 消息 |
| `add_tool_result(name, result)` | 追加 tool 角色消息（教学用 dict 模拟） |
| `to_api_messages()` | 转为 OpenAI 格式列表 |
| `clear()` | 清空历史 |
| `trim(max_messages=20)` | 保留 system + 最近 N 条 |

#### 4.2.2 ToolRegistry

| 工具名 | 触发关键词（mock 路由） | 返回示例 |
|--------|-------------------------|----------|
| `get_weather` | 天气、气温 | 城市天气 JSON |
| `calc` | 计算、等于、+ - * / | 算术结果 |
| `lookup_order` | 订单、ST- | 订单状态 JSON |

| 符号 | 行为 |
|------|------|
| `register(name, schema, handler)` | 注册工具 |
| `list_tools()` | 返回名称列表 |
| `maybe_invoke(user_text)` | mock 模式关键词路由；live 模式由模型 tool_calls 驱动 |
| `execute(name, arguments)` | 执行并返回字符串 |

#### 4.2.3 流式输出

| 符号 | 行为 |
|------|------|
| `stream_tokens(text)` | 生成器，按词或字 yield |
| `stream_chat(...)` | 封装完整回复的流式产出 |
| `/stream on\|off` | REPL 命令切换 |

#### 4.2.4 REPL 命令

| 命令 | 行为 |
|------|------|
| `/help` | 打印帮助 |
| `/clear` | 清空会话 |
| `/tools` | 列出工具 |
| `/stream on\|off` | 切换流式 |
| `/history` | 显示最近 5 条消息摘要 |
| `/exit` | 退出 |
