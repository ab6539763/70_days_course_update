### 三、简答题（每题 5 分）

**21.** 简述 Agent 工具环三步。  
**参考答案**：① 用户输入进入带 tools 的模型；② 若返回 tool_calls 则执行工具并把结果写入 messages；③ 再次调用模型生成面向用户的自然语言回复。循环应有上限防死循环。

**22.** 为何 Day 21 默认关键词 mock 路由？  
**参考答案**：无 API Key 时仍能演示完整工具链；课堂、CI、答辩环境零配置；关键词路由行为确定，便于验收。

**23.** 流式 SSE 与 Python 生成器的关系？  
**参考答案**：生成器 `yield` 是语言层惰性产出；SSE 是 HTTP 传输层按 chunk 推送。Day 20 用网络流，Day 21 用生成器模拟相同消费模式。

**24.** trim 为何保留 system？  
**参考答案**：system 含角色与工具说明，删掉后模型行为漂移；只截断 user/assistant 历史即可控 token。

**25.** Day 22 静态 UI 与今日 CLI 如何衔接？  
**参考答案**：CLI 的交互文案、工具回复格式导出为 JSON mock；Day 22 `app.js` 先读 mock；Day 24 `fetch` 对接真实 `/api/chat`。

def handle_get_time(_: dict) -> str:
    return datetime.now(timezone.utc).isoformat()

registry.register(
    "get_time",
    {"name": "get_time", "description": "返回当前 UTC 时间"},
    handle_get_time,
    keywords=("时间", "几点", "现在几点"),
)

## 第三部分 · pytest 选做参考

```python
from integrated_assistant import ConversationSession, ToolRegistry, stream_tokens

def test_trim_keeps_system():
    s = ConversationSession()
    s.add_user_message("a" * 30)
    s.trim(max_messages=5)
    roles = [m["role"] for m in s.to_api_messages()]
    assert roles[0] == "system"

def test_tool_weather():
    reg = ToolRegistry()
    call = reg.maybe_invoke("上海天气怎么样")
    assert call is not None
    assert call.name == "get_weather"

def test_stream_tokens_nonempty():
    chunks = list(stream_tokens("hello"))
    assert len(chunks) >= 1
    assert "".join(chunks) == "hello"
```
