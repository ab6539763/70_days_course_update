## 2. Agent 工具环（mock 模式）

```text
用户: "查上海天气"
        │
        ▼
┌───────────────────┐
│ maybe_invoke      │── 关键词命中 "天气"
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ execute           │── get_weather(city=上海)
│ get_weather       │
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ add_tool_result   │── 写入 session
└─────────┬─────────┘
          ▼
┌───────────────────┐
│ stream_chat       │── 基于工具结果生成自然语言
└─────────┬─────────┘
          ▼
     打印给用户
```

## 3. 流式输出时序

```text
IntegratedClient.stream_chat
        │
        ├─ t0  yield "上"
        ├─ t1  yield "海"
        ├─ t2  yield "当"
        ├─ t3  yield "前"
        └─ ... StopIteration
                │
                ▼
        session.add_assistant_message(完整文本)
```

## 4. Session 消息生命周期

```mermaid
stateDiagram-v2
    [*] --> Empty
    Empty --> HasMessages: add_user_message
    HasMessages --> HasMessages: add_assistant / tool_result
    HasMessages --> Trimmed: 超过 max 自动 trim
    HasMessages --> Empty: /clear
    Trimmed --> HasMessages: 继续对话
```
