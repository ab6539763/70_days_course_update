## B1 · dict_hw.py 参考

```python
# -*- coding: utf-8 -*-
"""B1 参考答案：字典 CRUD。"""

def main() -> None:
    emp: dict = {}
    emp["name"] = "陈晓"
    emp["employee_id"] = "ST-2026-001"
    emp["department"] = "大模型应用开发部"
    emp["onboard_date"] = "2026-07-05"
    emp["phone"] = "13800138000"
    emp["need_dorm"] = True

    print("email:", emp.get("email", "未填写"))

    emp.pop("need_dorm", None)
    emp["need_dorm"] = False

    print("字段数:", len(emp))
    for key, value in emp.items():
        print(f"  {key} = {value!r}")


if __name__ == "__main__":
    main()
```

**讲评**：`pop` 第二个参数避免键不存在时报错；`items()` 同时拿键值适合日志。

## B3 · get_pagination 参考

```python
def get_pagination(root: dict) -> dict:
    data = root.get("data") or {}
    pagination = data.get("pagination")
    if not isinstance(pagination, dict):
        return {"page": 0, "total": 0}
    return {
        "page": pagination.get("page", 0),
        "total": pagination.get("total", 0),
    }
```

## B4 · export 增强要点

- `export_meta` 应包在写出对象外层，例如：

```python
output_doc = {
    "export_meta": {
        "exported_at": datetime.now().isoformat(timespec="seconds"),
        "count": len(cleaned),
    },
    "employees": cleaned,
}
json.dump(output_doc, fp, ensure_ascii=False, indent=2)
```

- 电话变化检测：`before != after` 再打印，避免刷屏。

**常见失分**：只改了 list 没加 meta；`exported_at` 忘记 ISO 格式。

## B5 · json_roundtrip 参考

```python
import json

text = '{"name": "测试", "active": true, "score": null}'
obj = json.loads(text)
# active -> True (bool), score -> None

obj["score"] = 100
new_text = json.dumps(obj, ensure_ascii=False)
```

**讲评**：Python 源码里必须写 `True`/`None`；JSON 文本里才是 `true`/`null`。混用是初学者最高频错误。

## C1 · ast.literal_eval 分析

Mock 含 `true`/`false`/`null` 时 **`literal_eval` 无法解析**（它是 Python 字面量规则）。`json` 模块才遵循 JSON 规范。生产环境还用 `json` 因为：标准兼容、错误行号、`JSONDecoder` 可扩展。
