# Day 5 流程图与示意图

## 1. Mock API 解析主流程

```mermaid
flowchart TD
    Start([启动 export_employees_json.py]) --> Load[json.load mock 文件]
    Load --> Root[根 dict]
    Root --> Check{code == 200?}
    Check -->|否| Err[打印 message 并退出]
    Check -->|是| Extract[取 data.employees]
    Extract --> Loop[遍历每条 employee dict]
    Loop --> Clean[调用 cleaners 清洗字段]
    Clean --> Append[加入 cleaned_list]
    Append --> Loop
    Loop --> Done{遍历结束?}
    Done -->|是| Write[json.dump 写 output]
    Write --> Report[打印统计报告]
    Report --> End([结束])
```

## 2. 字典 CRUD 决策树

```mermaid
flowchart TD
    Q[需要操作字典] --> R{只读?}
    R -->|是| G[.get 带默认值]
    R -->|否| W{改单个键?}
    W -->|是| Assign[emp key = value]
    W -->|否| U{批量合并?}
    U -->|是| Update[.update]
    U -->|否| D{删除?}
    D -->|是| Pop[.pop 或 del]
```
