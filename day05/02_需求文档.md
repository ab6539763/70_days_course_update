## 3. 功能需求

### 3.1 输入：Mock API 结构

文件：`code/mock_api_response.json`

顶层字段（节选）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | int | 业务状态码，200 表示成功 |
| `message` | str | 提示信息 |
| `data` | object | 载荷 |
| `data.employees` | array | 员工对象列表 |
| `data.pagination` | object | 分页元数据（今日不处理翻页） |

单个 `employee` 对象字段（与 Day 1 卡片对齐）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | str | 是 | 姓名，需 strip |
| `employee_id` | str | 是 | 工号，需 upper |
| `department` | str/null | 否 | 缺省用默认部门 |
| `onboard_date` | str | 是 | `YYYY-MM-DD` |
| `phone` | str | 是 | 11 位，删除所有空白 |
| `need_dorm` | bool | 是 | 是否住宿 |

### 3.2 解析（`parse_api.py`）

| 编号 | 功能 | 规则 |
|------|------|------|
| P-01 | 读取 JSON 文件 | `json.load` + `encoding="utf-8"` |
| P-02 | 校验 `code == 200` | 非 200 抛出自定义错误或打印并退出 |
| P-03 | 返回 `list[dict]` | 仅 `data["employees"]` |
| P-04 | 安全访问 | 嵌套字段用 `.get()`，避免 KeyError |

### 3.3 清洗与导出（`export_employees_json.py`）

| 编号 | 功能 | 规则 |
|------|------|------|
| E-01 | 字段清洗 | `name`: strip；`employee_id`: upper；`phone`: remove_all_spaces |
| E-02 | 缺省处理 | `department` 为 null 时用 `大模型应用开发部` |
| E-03 | 输出路径 | `code/output/employees_clean.json`（自动创建目录） |
| E-04 | 序列化 | `json.dumps(..., ensure_ascii=False, indent=2)` |
| E-05 | 统计报告 | 打印处理条数、跳过条数（若有） |

### 3.4 教学演示（`dict_demo.py`）

分四节演示，每节 `if __name__` 可独立运行：

1. 字典 CRUD  
2. 嵌套字典访问  
3. `keys` / `values` / `items` 遍历  
4. 字典与 JSON 互转预览  

## 4. 非功能需求

- Python 3.10+，标准库 `json`  
- 不依赖 `requests`（Day 12 再引入 HTTP）  
- 所有 `.py` 文件 UTF-8，**中文注释**  
- 通过 `pathlib.Path` 处理路径，避免硬编码反斜杠
