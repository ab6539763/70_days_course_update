## 第一章 · 为什么需要字典

### 1.1 从多个变量到一条记录

Day 1 你可能这样存员工信息：

```python
name = "陈晓"
employee_id = "ST-2026-001"
department = "大模型应用开发部"
```

字段一多，参数传递、函数返回值都会变成灾难。dict 把 **键 key** 和 **值 value** 绑在一起：

```python
employee = {
    "name": "陈晓",
    "employee_id": "ST-2026-001",
    "department": "大模型应用开发部",
}
```

**业务对应**：OA 一行记录、API 一个对象、向量库一条 metadata——都是键值对集合。

### 1.2 dict 的基本性质

| 性质 | 说明 |
|------|------|
| 可变 | 可以增删改键值 |
| 无序（3.7+ 保持插入顺序） | 遍历顺序稳定，便于 diff |
| 键必须可哈希 | 一般用 `str`；列表不能当键 |
| 值任意类型 | 可以嵌套 dict、list |

▶ 实操：运行 `code/dict_demo.py` 第一节 `demo_crud()`。

## 第二章 · 字典 CRUD 详解

### 2.1 Create 创建

```python
# 字面量
emp = {"name": "陈晓", "employee_id": "ST-2026-001"}

# dict() 构造
emp2 = dict(name="李雷", employee_id="ST-2026-002")

# 从键列表 + 默认值
keys = ["name", "phone"]
blank = dict.fromkeys(keys, "")  # {'name': '', 'phone': ''}
```

### 2.2 Read 读取

```python
emp["name"]           # 键不存在 → KeyError
emp.get("name")       # 不存在 → None
emp.get("phone", "")  # 不存在 → 第二个参数作为默认值
```

**张工规范**：解析外部 JSON 时，优先 `.get()`，尤其是可选字段如 `department`。

### 2.3 Update 更新

```python
emp["department"] = "大模型应用开发部"   # 新增或覆盖
emp.update({"phone": "13800138000"})     # 批量合并
```

### 2.4 Delete 删除

```python
del emp["phone"]       # 键不存在 → KeyError
emp.pop("need_dorm", None)  # 安全删除，返回被删的值
```

### 2.5 成员检测

```python
"name" in emp      # True
"salary" not in emp
```

### 2.6 浅拷贝注意

```python
import copy
a = {"meta": {"version": 1}}
b = a.copy()              # 浅拷贝：内层 dict 仍共享
c = copy.deepcopy(a)      # 深拷贝：完全独立
```

批量清洗时建议 **构造新 dict**，不要原地改 Mock 源数据，便于对比清洗前后。

## 第三章 · 嵌套字典与列表

### 3.1 Mock API 真实结构

信息科给的响应（简化）：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "employees": [
      {"name": "陈晓", "employee_id": "ST-2026-001"},
      {"name": "李雷", "employee_id": "ST-2026-002"}
    ],
    "pagination": {"page": 1, "total": 5}
  }
}
```

加载后类型：

```text
根          → dict
data        → dict
employees   → list
employees[0]→ dict
```

### 3.2 安全取值模式

```python
def extract_employees(root: dict) -> list:
  data = root.get("data") or {}
  return data.get("employees") or []
```

### 3.3 遍历员工列表

```python
for emp in employees:
    print(emp.get("name"), emp.get("employee_id"))

for i, emp in enumerate(employees, start=1):
    print(f"第{i}条:", emp)
```

### 3.4 嵌套 dict 的 dict 推导式（选讲）

```python
# 只保留工号与姓名，用于日志
brief = [{k: e[k] for k in ("name", "employee_id")} for e in employees]
```

## 第四章 · JSON 格式详解

### 4.1 JSON 是什么

**JSON**（JavaScript Object Notation）是轻量级数据交换格式。HTTP API、配置文件、模型请求体普遍使用 JSON **文本**。

### 4.2 语法规则（与 Python 字面量对比）

| JSON | Python | 备注 |
|------|--------|------|
| `true` / `false` | `True` / `False` | 大小写不同 |
| `null` | `None` | |
| 字符串双引号 `"` | 单双引号均可 | JSON 只能用双引号 |
| 对象 `{...}` | dict | |
| 数组 `[...]` | list | |
| 无尾逗号 | 列表/字典允许尾逗号 | JSON 标准禁止尾逗号 |
| 无注释 | `#` 注释 | JSON 不支持注释 |

### 4.3 常见非法 JSON 示例

```text
{'name': '陈晓'}        # 单引号 —— 非法
{"name": "陈晓",}       # 尾逗号 —— 非法
{name: "陈晓"}          # 键无引号 —— 非法
{"active": True}        # Python 布尔 —— 非法
```

### 4.4 四个核心 API

| 函数 | 方向 | 入参 | 典型场景 |
|------|------|------|----------|
| `json.loads(s)` | 字符串 → Python | `str` | API `response.text` |
| `json.dumps(obj)` | Python → 字符串 | 任意可序列化对象 | 拼请求体、打日志 |
| `json.load(fp)` | 文件对象 → Python | 可读文件 | 读 `mock_api_response.json` |
| `json.dump(obj, fp)` | Python → 文件 | 可写文件 | 写 `employees_clean.json` |

记忆口诀：**带 s 的走字符串，不带 s 的走文件**。

### 4.5 dumps 常用参数

```python
json.dumps(
    data,
    ensure_ascii=False,  # 中文不转成 \uXXXX
    indent=2,            # 美化缩进
    sort_keys=True,      # 键排序（可选）
)
```

### 4.6 不可序列化对象

`datetime`、`set`、自定义 class 默认不能直接 `dumps`。Day 23 前常用做法：

```python
# 转成 ISO 字符串
"onboard_date": onboard_date.strftime("%Y-%m-%d")
```

## 第七章 · 踩坑记录

### 7.1 KeyError vs .get()

外部数据永远不要假设键存在。`emp["phone"]` 在缺字段时直接崩溃，生产环境一条坏数据会拖垮整批导入。

### 7.2 JSON null 与 Python None

`json.load` 后 `department: null` 变成 `None`。判断用 `if emp.get("department") is None`。

### 7.3 修改了原 dict 导致 diff 困难

清洗时 **返回新 dict**，保留 `raw` 便于打印对比报告。

### 7.4 忘记 encoding=utf-8

Windows 上默认 cp936 会导致中文乱码。读写 JSON 统一 `encoding="utf-8"`。

### 7.5 loads 与 load 混用

```python
# 错：把文件路径传给 loads
json.loads("mock_api_response.json")

# 对：文件用 load
with open(path, encoding="utf-8") as f:
    data = json.load(f)
```

## 第九章 · 自检问题答案

1. JSON 为 `true`/`false`；`json.loads` 后变为 Python `True`/`False`。  
2. `emp["phone"]` 缺键抛 `KeyError`；`emp.get("phone")` 返回 `None`，可给默认值 `""`。  
3. `ensure_ascii=False` 让中文以原文写入文件，方便王工阅读与 grep；若为 `True` 会得到 `\u5927\u6a21\u578b...` 转义串。
