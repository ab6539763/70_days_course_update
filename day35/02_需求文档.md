## 4. 功能需求

### 4.1 llamaindex_kb.py

| 符号 | 行为 |
|------|------|
| `MockKBEngine` | Markdown 切块 + Jaccard 检索 |
| `LlamaIndexKBEngine` | SimpleDirectoryReader + VectorStoreIndex |
| `create_kb_engine` | 按环境选择引擎 |
| `query(question)` | 返回 `QueryResult`（answer + chunks） |
| CLI | `--question` / `--repl` / `--force-mock` / `--json` |

### 4.2 compare_frameworks.md

必须包含：定位差异、RAG 组件映射、代码对比、选型建议、本日验收对照。

### 4.3 data/kb_docs/

至少 4 个 Markdown：退款、账号、物流发票、产品能力。
