## 第一章 · LlamaIndex 是什么（09:00–09:45）

### 1.1 定位

**LlamaIndex**（原 GPT Index）专注 **数据连接与索引**：

```text
  Data → Index → Query Engine → Answer
```

与 LangChain「编排一切」不同，LlamaIndex 把 RAG 路径做得更短。

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| Document | 原始文档对象 |
| Node | 切块后的节点 |
| Index | 向量索引结构 |
| QueryEngine | 检索 + 生成封装 |

## 第二章 · LangChain vs LlamaIndex（09:45–11:00）

▶ 精读 [code/compare_frameworks.md](./code/compare_frameworks.md)

### 2.1 代码行数对比（同一 PRD）

**LangChain（Day 33 回顾）**：

```python
loader = DirectoryLoader("data/", glob="**/*.md")
docs = loader.load()
splits = RecursiveCharacterTextSplitter(chunk_size=256).split_documents(docs)
vectorstore = Chroma.from_documents(splits, embeddings)
chain = create_retrieval_chain(vectorstore.as_retriever(), llm)
```

**LlamaIndex（Day 35）**：

```python
documents = SimpleDirectoryReader("data/kb_docs").load_data()
index = VectorStoreIndex.from_documents(documents)
query_engine = index.as_query_engine(similarity_top_k=3)
response = query_engine.query("如何申请退款？")
```

### 2.2 选型结论

- 纯 KB 问答 MVP → LlamaIndex 更快  
- 复杂 Agent + 多工具 → LangChain / LangGraph  
- 星火智服：**双栈并行**，评估统一走 Day 34

### 3.2 MockKBEngine（默认课堂模式）

无 `llama-index` 时：

1. 按 `##` 切分 Markdown  
2. Jaccard + 中文二元组检索  
3. 模板合成答案 + 来源  

```bash
python3 llamaindex_kb.py --force-mock
python3 llamaindex_kb.py --force-mock -q "忘记密码怎么办？"
python3 llamaindex_kb.py --repl --force-mock
```

### 3.3 LlamaIndexKBEngine（live）
