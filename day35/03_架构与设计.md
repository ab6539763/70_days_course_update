# Day 35 架构与设计 · LlamaIndex 知识库问答

## 1. 总体架构

```text
  data/kb_docs/*.md
         │
         ▼
  ┌──────────────────┐
  │  Reader / Loader │  SimpleDirectoryReader (live)
  │                  │  或 Markdown 章节切分 (mock)
  └────────┬─────────┘
           ▼
  ┌──────────────────┐
  │  Chunk / Node    │  SentenceSplitter (live)
  │                  │  ## 标题切分 (mock)
  └────────┬─────────┘
           ▼
  ┌──────────────────┐
  │  VectorStoreIndex│  embedding (live / mock)
  └────────┬─────────┘
           ▼
  ┌──────────────────┐
  │  Retriever       │  similarity_top_k=3
  └────────┬─────────┘
           ▼
  ┌──────────────────┐
  │  Synthesizer     │  LLM (live) / 模板拼句 (mock)
  └────────┬─────────┘
           ▼
     QueryResult
   (answer + chunks + source)
```

## 2. 双引擎设计

| 引擎 | 触发条件 | 实现 |
|------|----------|------|
| `MockKBEngine` | 无 llama-index 或 `LLAMAINDEX_FORCE_MOCK=1` | Jaccard + 模板回答 |
| `LlamaIndexKBEngine` | 已安装 llama-index | VectorStoreIndex + QueryEngine |

`create_kb_engine()` 统一工厂入口，对外 API 一致。

## 3. 与 LangChain Day 33 对照

| 层 | LangChain (Day 33) | LlamaIndex (Day 35) |
|----|--------------------|---------------------|
| 加载 | `DirectoryLoader` | `SimpleDirectoryReader` |
| 切块 | `RecursiveCharacterTextSplitter` | `SentenceSplitter` / `##` 切分 |
| 存储 | `Chroma` / `FAISS` | `VectorStoreIndex` 内置 |
| 检索 | `as_retriever(k=3)` | `as_retriever(similarity_top_k=3)` |
| 问答 | LCEL `rag_chain` | `as_query_engine()` |
