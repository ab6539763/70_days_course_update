## 1. 功能需求

### 1.1 checkpointer_demo.py
- 使用 `MemorySaver` 编译图  
- 同一 `thread_id` 连续 invoke，计数器累加  
- 不同 `thread_id` 互不影响  
- 输出 checkpoint 日志到 `code/data/checkpoint_threads.json`

### 1.2 human_in_loop.py
- `interrupt_before=["review"]` 在人工节点前暂停  
- `Command(resume="approve")` 或传入修改后全文  
- 状态含 `approved`、`revision_count`

### 1.3 writing_agent_graph.py
- 子图 `RESEARCH_SUBGRAPH` 封装检索摘要  
- 并行节点 `search` + `analyze`，`research_notes` 用 `operator.add` 合并  
- 质检 `quality_score < 0.8` 时重试写作，最多 3 次  
- 最终 `status` 为 `已发布` 或 `降级发布`

## 2. 非功能需求

- 无 `OPENAI_API_KEY` 时 mock 全绿  
- `verify_day42.py` 自动化验收  
- Python 3.10+
