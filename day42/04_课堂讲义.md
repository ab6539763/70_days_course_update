# Day 42 课堂讲义 · LangGraph 进阶

## 第一章 · Checkpointer 持久化（09:00–10:00）

### 1.1 为什么需要 Checkpointer

长事务 Agent（写作、审批、多轮工具）不能在内存里裸奔。进程重启、用户隔天继续，都需要 **按会话恢复图状态**。

### 1.2 MemorySaver 最小示例

```bash
python3 checkpointer_demo.py
```

核心代码：

```python
app = graph.compile(checkpointer=MemorySaver())
config = {"configurable": {"thread_id": "user-123"}}
app.invoke({"count": 0}, config)   # 首次
app.invoke({}, config)             # 续跑，从 checkpoint 恢复
```

**踩坑**：续跑时若再传 `count: 0`，会覆盖 checkpoint 中的 count。

## 第二章 · interrupt / resume（10:00–11:30）

### 2.1 编译时声明中断点

```python
app = graph.compile(
    checkpointer=MemorySaver(),
    interrupt_before=["review"],
)
```

### 2.2 暂停与恢复

```python
paused = app.invoke(initial, config)
# snapshot.next == ('review',)
final = app.invoke(Command(resume="approve"), config)
```

运行：

```bash
python3 human_in_loop.py
```

业务映射：公告发布、退款审批、敏感回复 —— 一律「AI 起草 + 人工放行」。

## 第三章 · 子图（14:00–14:45）

子图 = 独立 `StateGraph` compile 后，在主图节点内 `subgraph.invoke(...)`。

`writing_agent_graph.py` 中 `RESEARCH_SUBGRAPH` 可被 search / analyze 复用，避免主图臃肿。

## 第四章 · 并行节点（14:45–15:30）

从 `plan` 同时连到 `search` 和 `analyze`：

```python
graph.add_edge("plan", "search")
graph.add_edge("plan", "analyze")
```

状态字段用 `Annotated[list[str], operator.add]` 合并两路输出。
