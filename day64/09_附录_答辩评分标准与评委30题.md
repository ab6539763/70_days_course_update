## 第 2 节 · 毕业设计评委 30 题（按方向分类）

> 彩排要求：每人抽 5 题口述；正答评委随机追问 2–4 题。

### 2.1 通用开题与工程（1–8）

**Q1. 你的 `direction` 代号与 `project_meta.json` 字段？**  
须秒答；说明 `base_reference` 从何继承。

**Q2. 用 30 秒讲清业务价值。**  
结构：角色 + 痛点 + 方案 + 可验证结果；对照开题 elevator pitch。

**Q3. PRD v1.0.0 冻结后如何控制变更？**  
变更单 + 导师批准；P0 不可口头加。

**Q4. `verify_project.py` 证明了什么？**  
逐条对应 PRD AC；勿说「就是跑一下」。

**Q5. mock 与生产差距三条？**  
如：LLM 真网、并发、持久化高可用；须诚实。

**Q6. 为何选此方向而非另一备选？**  
引用 Day58 决策树路径，非随机。

**Q7. 技术债优先还哪一笔？**  
给一周排期与理由。

**Q8. `graduation-v1` tag 包含什么？**  
`workspace/<team>/` 可答辩快照 + README 说明。

---

### 2.2 RAG 与检索（9–14）· `rag_plus` / `multimodal_doc`

**Q9. 混合检索相对单向量的收益？**  
短词/专有名词 BM25 强；语义向量强；RRF 或 α 融合。

**Q10. chunk 策略如何影响 citations？**  
chunk 过大 citation 不精准；过小上下文碎。

**Q11. 如何评估 hit@k？**  
黄金集 query；k=3/5；与 Day55 评估思维一致。

**Q12. 多租户若做了，隔离在哪一层？**  
索引目录 / collection / metadata filter。

**Q13. multimodal OCR 错误如何传播？**  
错误文本入库→错误答案；需置信度或人工抽检。

**Q14. SSE citations 与 Day37 契约？**  
`event:citations` 先到；source 映射文件名。

---

### 2.3 Agent 与编排（15–20）· `agent_plus` / `lowcode_bridge`

**Q15. interrupt 与 `input()` 区别？**  
interrupt 持久化 checkpointer，可 HTTP resume。

**Q16. `thread_id` 作用？**  
隔离 Checkpointer 会话状态。

**Q17. 审批拒绝后状态机？**  
reject 后不得执行副作用工具（如 email_send）。

**Q18. 为何需要 ≥5 tools？**  
覆盖办公场景；工具 schema 供路由。

**Q19. lowcode 与自研边界？**  
Dify 编排运营流；自研 API 管核心数据与合规。

**Q20. MCP 与本课题关系？**  
若未用 MCP，说明工具直调；若用，讲跨进程复用。

---

### 2.4 数据、SQL 与微调（21–26）· `text2sql_bi` / `finetune_cs`

**Q21. Text-to-SQL 如何防注入？**  
只读连接 + `validate_sql` 黑名单 + 限制表。

**Q22. 图表类型如何选择？**  
时间序列折线；占比饼图；勿瞎选。

**Q23. LoRA 相对全量微调优势？**  
显存、速度、多 adapter 切换。

**Q24. 训练集与黄金集为何要隔离？**  
防过拟合评估虚假繁荣（Day55）。

**Q25. vLLM 部署价值？**  
吞吐、PagedAttention；课堂 mock 对标接口。

**Q26. 微调客服 Rubric 三维度？**  
tone / factuality / overall（Day55）。

---

### 2.5 合规、安全与综合（27–30）· `compliance_suite` / 全方向

**Q27. 护栏放哪几层？**  
输入前、输出后、工具前、写操作前 human_gate。

**Q28. 横切接入三项目难点？**  
统一 middleware、trace_id、策略版本。

**Q29. API Key 能放前端吗？**  
绝不；仅后端环境变量。

**Q30. 若 Demo 现场失败你的 B 计划？**  
录屏、mock 降级、explain 根因；体现工程素养。

## 第 8 节 · 评委追问深度示例（20 min）

以下三题为 **深度追问**，彩排须至少准备一道：

**追问 A（rag_plus）**：若 α=0 与 α=1 答案质量相同，说明什么？  
→ 可能 query 过短、语料单一或评估集无效；应检查 golden 集与 BM25 分词。

**追问 B（agent_plus）**：SqliteSaver 与 MemorySaver 重启行为差异？  
→ Memory 丢状态；Sqlite 可 resume；须结合 `thread_id` 与 checkpoint 路径说明。

**追问 C（compliance_suite）**：统一护栏是否增加延迟？如何量化？  
→ 每请求多一次策略匹配；可用 mock 压测 p95；生产可缓存编译后的策略树。
