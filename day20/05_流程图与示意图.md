```mermaid

    subgraph 离线索引
        FAQ[sample_questions.json] --> EMB[embed_batch]

    end

    subgraph 在线查询
        Q[用户问句] --> EQ[embed query]
        EQ --> COS[top_k_similar]
        MAT --> COS
        COS --> TH{score >= threshold?}
        TH -->|是| ANS[返回标准答]
        TH -->|否| MAN[转人工 + Top-K 参考]
    end
```

## 3. 余弦相似度几何示意

```text
        B
       /
      /  θ 越小 → cosine 越大
     /_____
    A      C

A 与 B 夹角小 → 语义相近
A 与 C 夹角大 → 语义无关
```

## 6. mock embedding 特征流

```text
输入文本
    ├─ 1~3 字符 n-gram ──哈希──▶ 维度桶 ±1
    └─ 主题词（退款/密码/物流）──▶ 桶 +2.5
              │
              ▼
         L2 归一化 → 单位向量
```
