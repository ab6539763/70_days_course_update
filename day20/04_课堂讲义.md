## 第一章 · Embedding 原理（09:00–10:00）

### 1.1 什么是 Embedding

把变长文本映射为 **固定维度浮点向量**，语义相近的文本向量距离更近。

```text
「如何申请退款？」  →  [0.12, -0.05, 0.33, ...]   (维度 D)
「退款流程是什么？」 →  [0.11, -0.04, 0.31, ...]   (相近)
「忘记密码怎么办？」 →  [-0.22, 0.18, 0.02, ...]  (较远)
```


## 第二章 · 余弦相似度（10:00–11:00）

### 2.1 公式

```text
cosine_similarity(A, B) = (A · B) / (||A|| × ||B||)
```

几何意义：两向量 **夹角余弦**，与长度无关（方向相似性）。

### 2.2 NumPy 实现

```python
def cosine_similarity(a, b):
    norm_a = np.linalg.norm(a)
    norm_b = np.linalg.norm(b)
    return float(np.dot(a, b) / (norm_a * norm_b))
```

打开 [code/cosine_similarity.py](./code/cosine_similarity.py)。

### 2.3 Top-K 检索

```python
scores = [cosine_similarity(query, row) for row in corpus]
top_indices = np.argsort(scores)[::-1][:k]
```

**讲师强调**：FAQ 量大时用矩阵乘法 `normalized @ normalized.T` 加速。

▶ 运行：`python3 cosine_similarity.py`
