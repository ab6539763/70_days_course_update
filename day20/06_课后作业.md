```json

  "question": "如何申请退款？",

  "answer": "..."
}
```

## 必做 B · 匹配评估（35 分）

### B1. 评估脚本

`homework/day20/eval_matcher.py`：

1. 加载 `my_questions.json`  
2. 用每个 `variant` 作为 query 调用 matcher  
3. 统计 **Recall@1**（Top-1 是否命中对应标准问）

目标：mock 模式下 Recall@1 ≥ 60%。

### B2. 阈值扫描

对 threshold `[0.4, 0.5, 0.6, 0.7, 0.8]` 输出命中率曲线（打印表格即可）。
