## 4. 功能需求

### 4.1 sample_questions.json

| 字段 | 说明 |
|------|------|
| id | 唯一标识 |
| category | 分类 |
| question | 标准问 |
| answer | 标准答 |

至少 10 条，覆盖退款/账号/物流/发票/产品。

### 4.2 cosine_similarity.py

| 函数 | 行为 |
|------|------|
| `cosine_similarity(a, b)` | 两向量余弦，[-1, 1] |
| `cosine_similarity_matrix(vectors)` | 两两矩阵 |
| `top_k_similar(query, corpus, k)` | Top-K 索引与分数 |

### 4.3 embedding_demo.py

| 符号 | 行为 |
|------|------|
| `EmbeddingClient` | `embed(text)` / `embed_batch` |
| `mock_embed_text` | n-gram + 关键词特征，L2 归一化 |
| live | `POST /embeddings` |

### 4.4 similar_question_matcher.py

| 符号 | 行为 |
|------|------|
| `SimilarQuestionMatcher.load()` | 加载 FAQ 并预计算向量矩阵 |
| `match(query)` | 返回 `MatchResult`（matched + top_k） |
| `threshold` | 默认 0.75，低于则转人工提示 |
| `explain(query)` | 人类可读输出 |

### 4.5 multimodal_demo.py

| 符号 | 行为 |
|------|------|
| `MultimodalClient.describe_image` | 图像 → 中文描述 |
| mock | 根据文件名确定性描述 |
| live | chat/completions + image_url |
