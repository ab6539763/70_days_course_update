## 必做 B 参考答案

### eval_matcher.py 核心

```python
def eval_recall_at_1(matcher: SimilarQuestionMatcher, items: list[dict]) -> float:
    hits = 0
    total = 0
    for item in items:
        expected_id = item["id"]
        for variant in item.get("variants", []):
            result = matcher.match(variant)
            total += 1
            if result.matched and result.matched.id == expected_id:
                hits += 1
    return hits / total if total else 0.0
```

### 阈值扫描

```python
for th in [0.4, 0.5, 0.6, 0.7, 0.8]:
    matcher.threshold = th
    print(th, eval_recall_at_1(matcher, items))
```

**讲评**：threshold 升高 → 命中更准但召回下降，需在业务上权衡。

```json
      "type": "object",
      "properties": {
        "query": {"type": "string"},
        "top_k": {"type": "integer", "default": 3}
      },
      "required": ["query"]
    }
  }
}
```

### faq_tool.py

```python
_matcher = SimilarQuestionMatcher(questions_path=Path("my_questions.json"))
_matcher.load()

def search_faq(query: str, top_k: int = 3) -> dict:
    result = _matcher.match(query, k=top_k)
    return result.to_dict()
```

**讲评**：注意 matcher 单例加载，避免每次调用重复 embed 全库。

## 挑战 F 要点

```python
def hybrid_score(cos: float, query: str, question: str) -> float:
    kw = 1.0 if any(w in question for w in query.split()) else 0.0
    return 0.7 * cos + 0.3 * kw
```
