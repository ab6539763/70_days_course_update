## 2. 相似问匹配数据流

```text
离线（load）:
  FAQ questions ──embed_batch──▶ vectors[N, D] ──存矩阵──▶ _matrix

在线（match）:
  user query ──embed──▶ q_vec[D]
       │
       ▼
  top_k_similar(q_vec, _matrix, k)
       │
       ▼
  best_score >= threshold ? 返回标准问+答 : 转人工
```

## 3. 余弦相似度

```text
cos(θ) = (A · B) / (||A|| × ||B||)
```

| 值 | 含义 |
|----|------|
| 1.0 | 方向完全相同 |
| 0.0 | 正交，无关 |
| -1.0 | 完全相反 |

**L2 归一化后**：cosine = 点积，检索可只用矩阵乘法。

## 4. mock embedding 设计

```text
文本
  ├─ 字符 1~3-gram → 哈希桶 ±1
  └─ 主题关键词（退款/密码/物流…）→ 加权 +2.5
        │
        ▼
    L2 normalize → 单位向量
```

教学用途：相近中文问句有更高相似度；**生产必须换真实 embedding 模型**。

## 5. 阈值策略

| threshold | 效果 |
|-----------|------|
| 过高 (0.9) | 漏召回，大量转人工 |
| 过低 (0.3) | 误匹配，答非所问 |
| 推荐起点 | 0.7~0.8（live）；mock 可调 0.5 演示 |

应随业务 A/B 调整，并按 category 分阈值。
