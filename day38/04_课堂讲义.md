## 第 2 节 · Demo 排错预案

| 故障 | 现场处理 |
|------|----------|
| 端口占用 | `BACKEND_PORT=8001` 并改 app.js |
| verify 失败 | 展示今早截图 + 说明环境差异 |
| 无 citations | 先 POST rebuild，再问退款 |
| 后端挂掉 | 重启 run.sh，口播 SSE 流程 |

## 第 3 节 · 必答题参考答案要点

### Q1 Hybrid 价值

- BM25：精确词项、SKU、错误码  
- 向量：口语化、同义表达  
- RRF：无需分数归一化  

### Q3 citations 事件顺序

- 先建立信任、减少等待焦虑  
- 检索完成即可返回，生成较慢  

### Q5 Key 安全

- 仅 `.env` + 服务端  
- `.gitignore` 排除 `.env`  
- 前端只调自家 API
