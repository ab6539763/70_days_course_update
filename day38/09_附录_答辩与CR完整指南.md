## 第 3 节 · 评委提问库（30 题 + 要点）

### 架构类

1. **为何选 FastAPI 而非 Flask？** — 类型校验、OpenAPI、异步。  
2. **Chroma 数据存在哪？** — 持久化目录 / 内存模式区别。  
3. **session 存在 SQLite 哪些表？** — ChatSession / ChatMessage。  

### RAG 类

4. **chunk_size 多少？为何？** — 结合 Day 31 实验表。  
5. **无相关知识时如何处理？** — 拒答模板 / score 阈值。  
6. **引用分数 0.82 含义？** — 相似度或 rerank 分，非概率。  

### 前端类

7. **为何不用 WebSocket？** — SSE 单向足够、HTTP 基础设施成熟。  
8. **fetch stream 与 EventSource 区别？** — POST、自定义头。  

### 安全类

9. **API Key 在哪？** — 仅后端 .env。  
10. **上传 PDF 会执行吗？** — 仅文本提取，不运行宏。  

（11–30 题详见 `07_作业参考答案.md` 答辩附录。）

## 第 4 节 · Code Review 工作坊（90 min 详细流程）

### 4.1 分组

2 人互评；A 评 B 的 `project2/backend/rag_service.py` + `frontend/app.js`。

### 4.2 使用 `08_补充讲义_CodeReview清单.md`

每项标记：

- ✓ 通过  
- ✗ 不通过（附行号）  
- N/A 不适用  

### 4.3 必查三项

1. **密钥**：`git log -p` 无 sk-  
2. **异常**：API 失败有 try/except 与用户提示  
3. **类型**：Pydantic schema 与 ORM 分离  

### 4.4 优秀代码片段讲解顺序

1. `hybrid_retriever.py` — RRF 公式  
2. `rag_service.py` — `async def stream_answer`  
3. `app.js` — citations 先至
