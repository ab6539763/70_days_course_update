## 第一章 · FastAPI 五分钟上手（09:00–09:30）

### 1.1 什么是 FastAPI

FastAPI 是基于 **Starlette**（ASGI）和 **Pydantic** 的现代 Python Web 框架：

| 特性 | 说明 |
|------|------|
| 类型注解驱动 | 参数类型即文档 |
| 自动 OpenAPI | `/docs` Swagger UI |
| 高性能 | 异步友好，性能接近 Node/Go |
| 数据校验 | Pydantic 自动 422 |

与 Flask 对比：Flask 更轻、生态老；FastAPI 更适合 **API 服务 + 自动文档**，LLM 项目常用。

### 1.2 最小应用

打开 [code/main.py](./code/main.py)：

```python
from fastapi import FastAPI

app = FastAPI(title="星火智服 API")

@app.get("/")
def root():
    return {"service": "星火智服"}
```

启动：

```bash
cd day23/code
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

- `main`：模块名（`main.py`）  
- `app`：FastAPI 实例变量名  
- `--reload`：改代码自动重启（仅开发）

浏览器访问 <http://127.0.0.1:8000/docs>，看到自动生成的交互文档。

## 第二章 · 路由、路径参数、查询参数（09:30–10:30）

### 2.1 路径参数

```python
@app.get("/items/{item_id}")
def read_item(item_id: int):
    return {"item_id": item_id}
```

- URL `/items/42` → `item_id=42`  
- 类型 `int`：非数字返回 422  

### 2.2 查询参数

```python
from fastapi import Query

@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = Query(default=None)):
    return {"item_id": item_id, "q": q}
```

- URL `/items/42?q=spark` → `q="spark"`  
- 省略 `q` → `None`  

### 2.3 HTTP 方法与状态码

| 装饰器 | 语义 | 今日用途 |
|--------|------|----------|
| `@app.get` | 查询 | `/health` |
| `@app.post` | 创建/提交 | `/api/chat` |
| `@app.delete` | 删除 | 清空会话 |

默认成功状态码：GET/POST → 200。  
用 `HTTPException(status_code=404)` 返回错误。

## 第三章 · Pydantic 模型与校验（10:30–12:00）

### 3.1 为什么需要 Pydantic

前端发来的 JSON 不可信：

- 字段可能缺失、类型错误、超长注入  
- Pydantic 在进业务逻辑前 **拦截脏数据**

### 3.2 ChatRequest 定义

打开 [code/models.py](./code/models.py)：

```python
from pydantic import BaseModel, Field, field_validator

class ChatRequest(BaseModel):
    message: str = Field(..., min_length=1, max_length=2000)
    session_id: str = Field(default="web-demo-001")
    stream: bool = False

    @field_validator("message")
    @classmethod
    def strip_message(cls, value: str) -> str:
        stripped = value.strip()
        if not stripped:
            raise ValueError("message 不能为空白")
        return stripped
```

**要点**：

- `Field(...)`：`...` 表示必填  
- `default`：缺省时填充  
- `@field_validator`：自定义规则（去空白）  

### 3.3 响应模型

```python
class ChatResponse(BaseModel):
    reply: str
    session_id: str
    tools_used: list[str] = Field(default_factory=list)
```

路由声明：

```python
@app.post("/api/chat", response_model=ChatResponse)
def api_chat(request: ChatRequest) -> ChatResponse:
    ...
```

`response_model` 作用：

1. 自动生成 OpenAPI 响应 schema  
2. 过滤未声明字段（安全）  
3. 序列化为 JSON  

### 3.4 422 校验错误

在 `/docs` 提交 `"message": "   "`，观察响应：

```json
{"detail": [{"loc": ["body", "message"], "msg": "..."}]}
```

前端应处理 422，提示用户「请输入有效内容」——Day 22 已在客户端 `trim()` 预防。

## 第四章 · POST /api/chat 实战（14:00–15:30）

### 4.1 路由实现

```python
@app.post("/api/chat", response_model=ChatResponse)
def api_chat(request: ChatRequest) -> ChatResponse:
    if request.stream:
        raise HTTPException(status_code=501, detail="Day 23 仅非流式")
    return chat_service.chat(request)
```

路由层 **只做**：

- 参数已由 Pydantic 校验  
- `stream` 开关判断  
- 委托 `chat_service.chat()`  

### 4.2 chat_service 走读

打开 [code/chat_service.py](./code/chat_service.py)，阅读顺序：

1. `ToolRegistry` — 关键词 → 工具（对齐 Day 21）  
2. `ConversationSession` — 多轮 messages  
3. `ChatService.chat()` — 主流程  

核心逻辑：

```python
def chat(self, request: ChatRequest) -> ChatResponse:
    session = self.get_session(request.session_id)
    session.add_user_message(request.message)

    tool_call = self._tools.maybe_invoke(request.message)
    if tool_call:
        raw = self._tools.execute(tool_call.name, tool_call.arguments)
        reply = _format_tool_reply(tool_call.name, raw)
        tools_used = [tool_call.name]
    else:
        reply = _pick_greeting_reply(request.message) or _default_mock_reply(...)
        tools_used = []

    session.add_assistant_message(reply)
    return ChatResponse(reply=reply, session_id=request.session_id, tools_used=tools_used)
```
