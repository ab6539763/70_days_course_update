## 3. POST /api/chat 详细时序

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant JS as app.js
    participant F as FastAPI
    participant P as Pydantic
    participant C as ChatService
    participant T as ToolRegistry

    U->>JS: 输入「上海天气」
    JS->>JS: appendMessage(user)
    JS->>F: POST /api/chat
    F->>P: 解析 ChatRequest
    alt 校验失败
        P-->>F: ValidationError
        F-->>JS: 422
    else 校验通过
        F->>C: chat(request)
        C->>C: session.add_user_message
        C->>T: maybe_invoke("上海天气")
        T-->>C: get_weather(city=上海)
        C->>T: execute → JSON
        C->>C: format → 自然语言
        C->>C: session.add_assistant
        C-->>F: ChatResponse
        F-->>JS: 200 JSON
        JS->>JS: typewriterEffect(reply)
    end
```

## 7. CORS 预检（浏览器）

```mermaid
sequenceDiagram
    participant B as 浏览器
    participant API as FastAPI :8000

    Note over B,API: 部分跨域 POST 会先发 OPTIONS
    B->>API: OPTIONS /api/chat
    API-->>B: Access-Control-Allow-Origin: *
    B->>API: POST /api/chat
    API-->>B: 200 + CORS 头
```

教学环境 `allow_origins=["*"]` 简化联调；生产应限制为前端域名。
