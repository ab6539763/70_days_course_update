## 4. 功能需求

### 4.1 models.py

| 模型 | 字段 | 说明 |
|------|------|------|
| `Message` | `role`, `content` | 单条消息 |
| `ChatRequest` | `message`, `session_id`, `stream` | 请求体 |
| `ChatResponse` | `reply`, `session_id`, `tools_used` | 响应体 |
| `HealthResponse` | `status`, `mode`, `version` | 健康检查 |

校验规则：

- `message`：去首尾空白后 `min_length=1`，`max_length=2000`  
- 空白消息 → HTTP 422  

### 4.2 main.py 路由

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 服务信息 |
| GET | `/health` | 健康检查，`response_model=HealthResponse` |
| GET | `/items/{item_id}` | 教学：路径参数 + `?q=` 查询参数 |
| POST | `/api/chat` | **主接口**，`response_model=ChatResponse` |
| GET | `/sessions/{session_id}/messages` | 调试：查看历史 |
| DELETE | `/sessions/{session_id}` | 清空会话 |

CORS：

```python
app.add_middleware(CORSMiddleware, allow_origins=["*"], ...)
```

### 4.3 chat_service.py

| 能力 | 说明 |
|------|------|
| 会话 | 按 `session_id` 内存存储，保留最近 20 条 |
| 工具 | `get_weather` / `lookup_order` / `calc` 关键词路由 |
| mock | `SPARKTECH_MOCK=1` 或缺 Key 时走 mock |
| live | 配置 Key 且 `SPARKTECH_MOCK=0` 时调 OpenAI |

### 4.4 POST /api/chat 契约（与 Day 22 对齐）

**请求**：

```json
{
  "message": "查上海天气",
  "session_id": "web-demo-001",
  "stream": false
}
```

**响应**：

```json
{
  "reply": "上海当前天气：晴，26°C，湿度 58%。（数据来源：mock_weather_api）",
  "session_id": "web-demo-001",
  "tools_used": ["get_weather"]
}
```

**stream=true**：HTTP 501，`detail` 说明 Day 24 实现。

### 4.5 mock 场景（至少 3 个）

| 用户输入含 | `tools_used` | `reply` 要点 |
|------------|--------------|--------------|
| 天气 | `["get_weather"]` | 城市、温度、湿度 |
| 订单 / ST- | `["lookup_order"]` | 订单号、状态、承运 |
| 你好 / hello | `[]` | 欢迎语 |
| 帮助 / help | `[]` | 能力列表 |
| 其他 | `[]` | 默认兜底提示 |
