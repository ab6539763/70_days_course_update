# Day 26 架构与设计 · LCEL 组合模式

## 1. LCEL 数据流

```text
输入 dict
    │
    ▼
┌─────────────┐
│ ChatPrompt  │  format_messages → ChatPromptValue
│ Template    │
└──────┬──────┘
       ▼
┌─────────────┐
│ ChatModel   │  invoke → AIMessage
└──────┬──────┘
       ▼
┌─────────────┐
│ OutputParser│  parse → str / dict
└──────┬──────┘
       ▼
    输出
```

## 2. Runnable 组合表

| 运算符/类 | 作用 | 示例 |
|-----------|------|------|
| `\|` | 顺序管道 | `prompt \| llm \| parser` |
| `RunnablePassthrough` | 原样传递输入 | 并行分支起点 |
| `RunnablePassthrough.assign` | 追加字段 | `assign(foo=lambda x: ...)` |
| `RunnableParallel` | 多路并行 | `{a: chain1, b: chain2}` |
| `RunnableLambda` | 任意函数 | mock 翻译 |

## 3. OutputParser 选型

| Parser | 输出类型 | 适用 |
|--------|----------|------|
| `StrOutputParser` | `str` | 翻译、摘要 |
| `JsonOutputParser` | `dict` | 松散 JSON |
| `JsonOutputParser(pydantic_object=...)` | `dict`（按模型校验） | 工单、意图 |

## 4. translation_chain 设计

```python
prepare = RunnablePassthrough.assign(
    source_lang=lambda x: x.get("source_lang", "中文"),
)
chain = prepare | prompt | llm | StrOutputParser()
```

mock 模式可用 `RunnableLambda(_mock_translate)` 替代 llm 段，保证测试确定性。
