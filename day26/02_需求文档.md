## 1. 目标

1. 掌握 LCEL：`prompt | llm | parser`  
2. 实现 `StrOutputParser`、`JsonOutputParser`、Pydantic 解析  
3. 实现 `RunnablePassthrough`、`RunnableParallel`  
4. 交付星火智服 `translation_chain.py`  
5. mock 模式无 Key 验收

## 2. 功能需求

### 2.1 lcel_chain_demo.py

| 函数 | 要求 |
|------|------|
| `build_simple_lcel_chain()` | 返回 str |
| `build_json_chain()` | 返回 dict |
| `build_pydantic_chain()` | 返回含 ticket_id/sentiment/summary 的 dict |
| `build_parallel_chain()` | 返回 `{question, length, upper}` |

### 2.2 translation_chain.py

| 函数 | 要求 |
|------|------|
| `build_translation_chain()` | LCEL 链，mock 可运行 |
| `translate(text, lang)` | 便捷封装 |

输入变量：`source_text`, `target_language`, `source_lang`

### 2.3 verify_day26.py

覆盖上述全部链的 `invoke` 断言。
