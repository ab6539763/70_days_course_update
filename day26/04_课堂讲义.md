## 第一章 · Runnable 与 LCEL（09:00–10:00）

### 1.1 什么是 LCEL

**LangChain Expression Language**：用 `|` 连接组件。

```python
chain = prompt | llm | StrOutputParser()
result = chain.invoke({"question": "你好"})
# result 是 str，不是 AIMessage
```

### 1.2 Runnable 接口

- `invoke(input)`  
- `batch(inputs)`  
- `stream(input)`  
- `ainvoke` / `astream`（异步）

所有 `Prompt`、`ChatModel`、`OutputParser` 均实现 `Runnable`。

## 第二章 · OutputParser（10:00–11:30）

打开 [code/lcel_chain_demo.py](./code/lcel_chain_demo.py)。

### 2.1 StrOutputParser

```python
from langchain_core.output_parsers import StrOutputParser

chain = prompt | llm | StrOutputParser()
```

从 `AIMessage` 提取 `.content` 字符串。

### 2.2 JsonOutputParser

```python
parser = JsonOutputParser()
prompt = prompt.partial(format_instructions=parser.get_format_instructions())
chain = prompt | llm | parser
```

mock LLM 需返回 **合法 JSON 字符串**。

### 2.3 Pydantic + JsonOutputParser

```python
from pydantic import BaseModel, Field

class TicketSummary(BaseModel):
    ticket_id: str
    sentiment: str
    summary: str

parser = JsonOutputParser(pydantic_object=TicketSummary)
```

## 第三章 · Passthrough 与 Parallel（11:30–12:00）

### 3.1 RunnablePassthrough.assign

```python
chain = RunnablePassthrough.assign(
    length=lambda x: len(str(x["text"])),
) | prompt | llm
```

输入 dict 增加 `length` 字段后进入 prompt。

### 3.2 RunnableParallel

```python
chain = RunnableParallel(
    question=RunnablePassthrough(),
    upper=RunnableLambda(lambda x: str(x).upper()),
)
chain.invoke("hi")  # {"question": "hi", "upper": "HI"}
```
