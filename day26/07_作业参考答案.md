## 必做 B · intent_lcel_chain 要点

```python
from pydantic import BaseModel, Field
from langchain_core.output_parsers import JsonOutputParser
from langchain_core.prompts import ChatPromptTemplate

class IntentResult(BaseModel):
    intent: str
    confidence: float = Field(ge=0, le=1)
    reason: str

parser = JsonOutputParser(pydantic_object=IntentResult)
prompt = ChatPromptTemplate.from_messages([
    ("human", "分类用户意图：{query}\n{format_instructions}"),
]).partial(format_instructions=parser.get_format_instructions())

llm = build_chat_model(responses=[
    '{"intent":"weather","confidence":0.9,"reason":"含天气关键词"}'
])
chain = prompt | llm | parser
```

## 必做 C · batch 要点

```python
items = [{"source_text": t, "target_language": "英文", "source_lang": "中文"} for t in skus]
results = chain.batch(items)
```

注意：mock `FakeListChatModel` 按序循环，batch 时需准备足够 responses 或继续用 `RunnableLambda`。

## 讲评要点

- `|` 两侧对象必须都是 Runnable  
- Json parser 失败常见原因：LLM 输出含 markdown 代码块  
- Parallel 各分支输入类型需一致
