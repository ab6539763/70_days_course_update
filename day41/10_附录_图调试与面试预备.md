## 二、现场 15 题（含答案）

1. **节点函数签名含义？** — 读 state，返回要 merge 的字段子集。  
2. **为何 TypedDict？** — LangGraph 惯例；可换 dataclass + reducer。  
3. **Day 42 interrupt 与 Day 41 approval 区别？** — 41 条件边同步模拟；42 `interrupt()` 真暂停。  
4. **`operator.add` 还能用什么？** — 自定义 reducer 函数。  
5. **entry_point 与 START 边？** — 等价入口声明，勿重复。  
6. **compile 返回什么？** — Runnable，可 invoke/stream。  
7. **多 conditional 出口怎么写？** — 路由函数返回 key，映射 dict 指节点。  
8. **reject 为何直连 END？** — 业务终止，无需 finalize。  
9. **reason 为何不回 act 当无 Action？** — should_continue 走 end 防悬空。  
10. **如何限制图步数？** — state.step + 条件边，或 LangGraph recursion_limit。  
11. **get_graph 用途？** — 可视化、调试、文档生成。  
12. **approval mock 默认 True 风险？** — 演示友好，生产必须 interrupt。  
13. **为何动态加载 day39？** — 避免包名冲突与错误 mock。  
14. **worker 回 supervisor 模式在 Day 43？** — 今日无 supervisor，仅双节点环。  
15. **图能嵌套吗？** — 可以，Day 42 子图。

## 四、面试题精选

**Q：LangGraph 相比 Airflow？**  
A：Airflow 偏批处理 DAG；LangGraph 偏 LLM 状态机与对话中间态，毫秒级交互。

**Q：State 过大怎么办？**  
A：拆字段、消息摘要、外存 artifact 只留引用 ID。

**Q：如何做 A/B 两版图？**  
A：compile 两 app，feature flag 选 invoke 目标。

## 八、LangGraph 版本差异备忘

| API | 旧版 | 新版 |
|-----|------|------|
| 入口 | `set_entry_point` | `add_edge(START, ...)` 亦可 |
| 中断 | `interrupt_before` 列表 | 节点内 `interrupt()` 函数 |
| 恢复 | `Command(resume=...)` | 同左，需 checkpointer |

课堂代码兼容 0.2.x 主线；若本地报错，先 `pip install -U langgraph langchain-core`。

## 十一、ReAct vs Approval 对照测验（10 题）
