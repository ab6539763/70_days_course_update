# Day 32 流程图与示意图

## Multi-Query 流程

```mermaid
flowchart TD
    Q[原始问题] --> G1[子查询 1]
    Q --> G2[子查询 2]
    Q --> G3[子查询 3]
    G1 --> S1[检索 top_k]
    G2 --> S2[检索 top_k]
    G3 --> S3[检索 top_k]
    S1 --> M[合并去重 max score]
    S2 --> M
    S3 --> M
    M --> F[final_k 文档]
```

## HyDE 流程

```ascii
  Query: "能退钱吗"
        │
        ▼
  LLM 生成假设文档:
  "用户可在7天内申请退款..."
        │
        ▼
  embed(假设文档) ──cosine──► 真实 chunks
        │
        ▼
  top_k 真实文档 → LLM
```

## 技术对比

| 方法 | 额外 LLM 调用 | 适合场景 |
|------|---------------|----------|
| Rewrite | 1 | 口语/错别字 |
| Multi-Query | 0~1 | 多角度召回 |
| HyDE | 1 | 短问句、答案型 KB |
