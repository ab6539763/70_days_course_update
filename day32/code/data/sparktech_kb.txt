# 星火智服知识库 · 产品与支持（教学样本）

## API Key 申请
API Key 在星火控制台「开发者 - 密钥管理」中申请。提交后由管理员审批，通常 1 个工作日内生效。每个 Key 绑定项目与配额，请勿在客户端硬编码。

## 退款政策
用户可在订单完成后 7 天内申请无理由退款。虚拟商品已激活或 API 调用量超过套餐 10% 时不可退款。退款原路返回，到账 3-5 个工作日。

## 企业版定价
企业版按年订阅，包含专属客服、SLA 99.9%、私有化部署选项。标准价 12 万/年起，100 并发以内。超并发按阶梯计费，联系销售获取报价。

## RAG 检索最佳实践
文档切块建议 300-800 字符，重叠 50-100 字符。检索 top_k 通常 3-5，过多噪声增加幻觉。生产环境建议 hybrid 检索 + rerank。

## 向量数据库选型
Chroma 适合本地原型；Milvus / Qdrant 适合百万级向量；pgvector 适合已有 PostgreSQL 团队。选型需考虑运维成本与过滤需求。

## 工单 SLA
P0 故障 15 分钟响应、4 小时恢复；P1 问题 2 小时响应、1 工作日解决；P2 咨询 1 工作日响应。节假日值班表见内部 wiki。

## 多轮对话上下文
系统保留最近 20 条消息；超长会话建议摘要压缩或向量记忆。工具调用结果应写入 assistant 消息供后续轮次引用。

## Embedding 模型对比
OpenAI text-embedding-3-small 维度 1536，英文优秀。BGE-small-zh 适合中文 FAQ，维度 512。多语言场景可试 multilingual-e5。
