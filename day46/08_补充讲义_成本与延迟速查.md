# Day 46 补充讲义 · 成本与延迟速查

## 1. Agent 成本构成

| 项 | 说明 |
|----|------|
| LLM 调用次数 | 每轮推理 + 总结 |
| Tool 调用 | 外部 API 计费 |
| 检索 | Embedding + 向量库 |
| Trace 存储 | LangSmith 按量 |

## 2. 延迟预算（生产参考）

| 步骤 | 典型耗时 |
|------|----------|
| 输入护栏 | < 5ms |
| LLM 首 token | 200–800ms |
| 工具 HTTP | 50–500ms |
| 输出护栏 | < 10ms |

## 3. 优化清单

1. 限制 `max_rounds`  
2. 合并多次检索为一次 batch  
3. 缓存高频 tool 结果  
4. 流式输出降低首字延迟  
5. 采样 trace（10%）降低存储成本  

## 4. 与 Day 47 衔接

Text-to-SQL 必须在执行前 `validate_sql`，避免恶意 SQL 拖垮数据库——属于 **fatal** 类错误，不应重试。
