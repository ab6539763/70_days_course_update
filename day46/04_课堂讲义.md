## 第二章 · 可观测性（10:30–12:00）

### 2.1 LangSmith 核心概念

- **Project**：项目命名空间  
- **Run**：一次完整调用  
- **Span**：子步骤（llm / tool / chain）  

### 2.2 运行 demo

```bash
cd day46/code
python3 observability_demo.py
```

观察终端 trace 树与 JSON 导出。

### 2.3 与 print 调试对比

| print | trace |
|-------|-------|
| 无结构 | 树形层级 |
| 难关联请求 | run_id 串联 |
| 生产不可用 | 可采样上报 |

## 第四章 · 重试与熔断（15:30–17:00）

```bash
python3 retry_agent_wrapper.py
```

`flaky_agent` 前两次抛 `RETRYABLE`，第三次成功——观察 `attempts >= 3`。

### 4.1 成本与延迟

- 每次重试 = 额外 LLM 调用成本  
- 退避避免 thundering herd  
- 熔断保护下游
