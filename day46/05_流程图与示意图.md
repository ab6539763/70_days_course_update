# Day 46 流程图与示意图

## 1. 稳定性分层

```mermaid
flowchart TB
    IN[用户输入] --> IG[InputGuard]
    IG -->|block| REJ1[拒绝回复]
    IG -->|allow| CB{CircuitBreaker}
    CB -->|open| REJ2[服务不可用]
    CB -->|closed| AG[Agent Core]
    AG --> RW[RetryWrapper]
    RW --> OG[OutputGuard]
    OG --> OUT[安全输出]
```
