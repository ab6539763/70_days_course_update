## A2. Tooltip 示例思路

```javascript
function showCitationDetail(cite) {
  const panel = document.getElementById('cite-panel');
  panel.innerHTML = `
    <h4>${escapeHtml(cite.source)}</h4>
    <p>${escapeHtml(cite.snippet)}</p>
    <small>score: ${cite.score.toFixed(3)}</small>
  `;
  panel.hidden = false;
}
```

在 `index.html` 增加 `<aside id="cite-panel">`。
