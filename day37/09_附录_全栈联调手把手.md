### 2.1 后端契约（先读 schemas）

```json
      "source": "refund_policy.md",
      "snippet": "7 日内可无理由退款...",
      "score": 0.82
    }
  ]
}
```

**PRD 要求**：source 必须可映射到用户上传文件名。

### 2.2 appendMessage 三参数设计

```javascript
function appendMessage(role, content, citations = []) {
  const row = document.createElement('div');
  row.className = `message ${role}`;
  const bubble = document.createElement('div');
  bubble.className = 'bubble';
  bubble.textContent = content; // 流式时后续追加
  if (role === 'assistant' && citations.length) {
    bubble.appendChild(buildCitationBadges(citations));
  }
  row.appendChild(bubble);
  messagesEl.appendChild(row);
  messagesEl.scrollTop = messagesEl.scrollHeight;
}
```

### 2.3 buildCitationBadges 详解

- 序号 `[1][2]` 对应脚注体验  
- `title` 属性放 snippet 预览  
- `click` → `alert` 或 modal（作业扩展）  

### 2.4 流式时 citations 先到

时序：

```text
用户发送 → POST /api/chat/stream
  → event citations  （立即渲染徽章骨架）
  → event delta × N  （追加文字）
  → event done
```

**UX 原理**：用户先看到「有依据」再读长答案，降低不信任感。

## 第 3 节 · SSE 协议与 buffer 解析（50 min）

### 3.1 为何不用 EventSource

`EventSource` 仅支持 **GET**。我们需要 POST 带 `session_id` 与 `message`，故用 `fetch` + `ReadableStream`。

### 3.2 parseSSEBuffer 逻辑

```javascript
function parseSSEBuffer(buffer, onEvent) {
  const parts = buffer.split('\n\n');
  const rest = parts.pop();
  for (const block of parts) {
    const line = block.split('\n').find(l => l.startsWith('data:'));
    if (!line) continue;
    const json = JSON.parse(line.slice(5).trim());
    onEvent(json);
  }
  return rest;
}
```

### 3.3 断行与粘包

TCP 可能在 JSON 中间切断；必须 **buffer 拼接** 再按 `\n\n` 分帧。

### 3.4 错误事件处理（作业）

建议后端增加：

```json
{"event":"error","message":"检索超时"}
```

前端 `toast` 提示，不白屏。

## 第 4 节 · 文档上传联调（50 min）

### 4.1 FormData 上传

```javascript
async function uploadFiles(files) {
  const form = new FormData();
  for (const f of files) form.append('files', f);
  const res = await fetch(`${API_BASE}/api/documents/upload`, {
    method: 'POST',
    body: form,
  });
  if (!res.ok) throw new Error(await res.text());
  return res.json();
}
```

**禁止** 设置 `Content-Type: multipart/form-data`（浏览器自动带 boundary）。

### 4.2 上传后 rebuild
