# Day 37 流程图与示意图

## 1. 用户发送消息全流程

```mermaid
sequenceDiagram
    participant U as User
    participant FE as app.js
    participant API as FastAPI
    participant RAG as RAGService

    U->>FE: 点击发送
    FE->>FE: appendMessage(user)
    FE->>FE: createStreamingAssistant()
    FE->>API: POST /api/chat/stream
    API->>RAG: stream_answer
    RAG-->>API: citations
    API-->>FE: SSE citations
    FE->>FE: buildCitationBadges()
    loop streaming
        RAG-->>API: delta
        API-->>FE: SSE delta
        FE->>FE: bubble.textContent += delta
    end
    API-->>FE: SSE done
    FE->>FE: remove .streaming class
```
