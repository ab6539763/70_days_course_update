## 3. SSE 前端解析要求

必须处理 **不完整 TCP 块**：使用 buffer + `\n\n` 分割（同 Day 24）。

事件处理顺序：

```javascript
if (evt.event === 'citations') { renderBadges(evt.citations); }
else if (evt.event === 'delta') { appendText(evt.delta); }
else if (evt.event === 'done') { finalize(); }
```
