# Day 37 架构与设计 · 前端数据流

## 1. 全栈架构

```text
Browser (8080)                    FastAPI (8000)
─────────────                    ─────────────
index.html ──fetch──► /health
app.js     ──fetch──► /api/documents
           ──FormData► /api/documents/upload
           ──SSE────► /api/chat/stream
           ──fetch──► /api/sessions/{id}/history
localStorage ◄──────► session_id
```

## 2. 组件映射

| UI 区域 | DOM ID | 模块 |
|---------|--------|------|
| 消息列表 | #message-list | appendMessage, createStreamingAssistant |
| 引用区 | .citations | buildCitationBadges |
| 文档列表 | #doc-list | loadDocuments |
| 状态 | #status-badge | checkHealth |

## 3. 流式消息状态机

```text
IDLE → USER_SENT → STREAMING_CITATIONS → STREAMING_DELTA → DONE
                      ↓ error
                    ERROR_MSG
```

`createStreamingAssistant` 创建空 bubble + 空 cite 容器；收到 citations 后替换 cite 容器。

## 4. CORS

后端 `CORS_ORIGINS` 需包含 `http://127.0.0.1:8080`。  
前端 `API_BASE` 默认 `http://127.0.0.1:8000`。

## 5. run.sh 流程

```text
venv → pip install → copy .env → uvicorn backend → http.server frontend
```

`PYTHONPATH` 指向 project2 根目录。

## 6. 样式约定

- 用户气泡：蓝色右对齐  
- 助手气泡：深色左对齐  
- 引用徽章：teal 边框，显示 `[n] filename`
