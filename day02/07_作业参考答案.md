## B3 remove_all_spaces

```python
def remove_all_spaces(text: str) -> str:
    return "".join(text.split())
```

## C1 split+join 版 collapse

```python
def collapse_spaces_no_re(text: str) -> str:
    parts = text.split()  # 任意空白分割并丢弃空段
    return " ".join(parts)
```
