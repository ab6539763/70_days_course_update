## 1. 目标

提供命令行工具，对单行或多行文本执行可配置的清洗流水线，解决 Day 1 入职数据导入失败问题，并沉淀可复用函数供后续模块 import。

## 2. 用户故事

| ID | 角色 | 故事 | 优先级 |
|----|------|------|--------|
| US-01 | 王工 | 粘贴多行脏数据，一次性输出清洗结果 | P0 |
| US-02 | 培训生 | 选择清洗项（去空格/大小写/敏感词） | P0 |
| US-03 | 张工 | 清洗函数独立在 `cleaners.py`，便于单元测试 | P1 |
| US-04 | 培训生 | 用 f-string 打印清洗前后对比 | P1 |

## 3. 功能需求

### 3.1 清洗能力

| 编号 | 功能 | 规则 | 示例 |
|------|------|------|------|
| F-01 | 去首尾空白 | `str.strip()` | `" 陈晓 "` → `陈晓` |
| F-02 | 合并连续内部空格 | 正则或 split+join | `"a  b   c"` → `"a b c"` |
| F-03 | 大小写模式 | `lower` / `upper` / `title` / `keep` | `CHENXIAO` → `Chenxiao`（title） |
| F-04 | 敏感词替换 | 默认 `*` 等长替换 | `傻瓜` → `**` |
| F-05 | 删除所有空白 | 手机号场景 | `138 0013 8000` → `13800138000` |

### 3.2 交互

1. 启动后展示菜单：输入原始文本（支持多行，空行结束）  
2. 勾选清洗选项（数字多选，如 `1,3,4`）  
3. 输出「清洗前 / 清洗后」对照  
4. 询问是否继续处理下一批  

### 3.3 敏感词表（v1.0 内置）

```text
傻瓜,笨蛋,违禁测试词
```

文件路径：`code/data/sensitive_words.txt`（一行一词）

## 4. 非功能需求

- Python 3.10+，标准库为主；F-02 可用 `re` 模块（Day 11 预习）  
- 单文件运行：`python3 text_cleaner.py`  
- 每个清洗函数 ≤30 行，带类型注解与 docstring
