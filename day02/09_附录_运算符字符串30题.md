## 七、DeepSeek API 账单心算模板（f-string 作业扩展）

```python
def estimate_cost(prompt_tokens: int, completion_tokens: int, price_in: float, price_out: float) -> str:
    cost = prompt_tokens / 1000 * price_in + completion_tokens / 1000 * price_out
    return f"输入 {prompt_tokens} + 输出 {completion_tokens} token，合计 {cost:.4f} 元"
```

背诵：费用 = 输入 token/1000×输入单价 + 输出 token/1000×输出单价。
