## 第一章 · 运算符基础

### 1.1 算术运算符

| 运算符 | 含义 | 示例 | 结果类型 |
|--------|------|------|----------|
| `+` | 加 | `3 + 2` | int |
| `-` | 减 | `3 - 2` | int |
| `*` | 乘 | `3 * 2` | int |
| `/` | 真除 | `10 / 4` | **float** 2.5 |
| `//` | 地板除 | `10 // 4` | int 2 |
| `%` | 取余 | `10 % 3` | int 1 |
| `**` | 幂 | `2 ** 10` | int 1024 |

**业务场景**：

```python
total_tokens = 12500
price_per_1k = 0.002
cost = total_tokens / 1000 * price_per_1k  # API 账单估算，Day 15 会真算
```

### 1.2 比较运算符

返回 **bool**：`==` `!=` `>` `<` `>=` `<=`

```python
user_input == "exit"   # Day 14 指令判断
score >= 60            # 周测及格线
```

**注意**：字符串比较按字典序，`"10" < "2"` 为 True（字符 '1' < '2'）。数字比较先 `int()`。

### 1.3 逻辑运算符

| 运算符 | 含义 | 短路 |
|--------|------|------|
| `and` | 与 | 左假则不算右 |
| `or` | 或 | 左真则不算右 |
| `not` | 非 | — |

```python
raw = "y"
need_dorm = raw.lower() in ("y", "yes") and len(raw) > 0
```

### 1.4 运算优先级（从高到低）

1. `**`  
2. `*` `/` `//` `%`  
3. `+` `-`  
4. 比较  
5. `not`  
6. `and`  
7. `or`  

不确定就加括号——企业代码宁可多括号，不要靠记忆赌优先级。

## 第二章 · 字符串深度

### 2.1 字符串是不可变序列

```python
s = "星火"
# s[0] = "x"  # TypeError，不能改单个字符
s = "X" + s[1:]  # 只能生成新字符串
```

**意义**：每次 `replace` 都产生新对象；大批量清洗要考虑性能（Day 28 再优化）。

### 2.2 索引与切片

```python
phone = "13800138000"
phone[0]      # '1'，正向从 0 开始
phone[-1]     # 末位 '0'
phone[0:3]    # '138'，含头不含尾
phone[::2]    # 步长 2
```

切片记忆口诀：**含头不含尾，负索引从尾数**。

### 2.3 常用方法速查

| 方法 | 作用 | 典型用途 |
|------|------|----------|
| `strip()` | 去首尾空白 | input 后第一步 |
| `lstrip/rstrip` | 去左/右空白 | 日志解析 |
| `lower/upper/title` | 大小写 | 统一工号、实体名 |
| `replace(old, new)` | 替换 | 敏感词 |
| `split(sep)` | 分割为 list | CSV、按行切 |
| `join(iterable)` | 拼接 | 还原字符串 |
| `find/sub in` | 查找 | 是否含关键词 |

```python
"  hello  ".strip()           # 'hello'
"a,b,c".split(",")            # ['a','b','c']
"-".join(["2026","07","06"])  # '2026-07-06'
```

### 2.4 成员运算

### 3.3 多行输入技巧

```python
def read_multiline_input() -> str:
  lines = []
  print("请输入文本（单独一行 END 结束）：")
  while True:
      line = input()
      if line.strip().upper() == "END":
          break
      lines.append(line)
  return "\n".join(lines)
```

## 第四章 · 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `strip` 后中间仍有双空格 | strip 只管首尾 | 用 collapse_spaces |
| `replace` 只换第一次 | 默认 count=1 | `replace(old, new)` 或循环 |
| f-string 花括号报错 | JSON 需转义 | `{{` `}}` |
| `None` 拼接 | input 空未处理 | 先 `or ""` |
