## 案例 1：strip 救不了中间空格

**现象**：王工导入后手机号仍是 `138 0013 8000`  
**学员代码**：

```python
phone = input("手机：").strip()
```

**根因**：`strip` 只处理首尾。  
**修复**：

```python
from cleaners import remove_all_spaces
phone = remove_all_spaces(input("手机：").strip())
```

## 案例 2：f-string 里写 JSON 花括号爆炸

**现象**：`ValueError: Invalid format specifier`

```python
# 错误
data = {"name": "陈晓"}
print(f"{data}")  # 其实可以
print(f"{"name": "陈晓"}")  # 语法错误
```

**修复**：

```python
import json
print(json.dumps(data, ensure_ascii=False))
# 或预览一行
print(f'{{"name": "{name}"}}')  # 花括号加倍
```

## 案例 3：敏感词替换顺序

**词表**：`["傻", "傻瓜"]`  
**文本**：`傻瓜`  
若先替换 `傻` → `**瓜`，再替换 `傻瓜` 失效。  
**生产做法**：按词长降序排序后替换（Day 11 正则一次完成）。

```python

"st-2026-001".upper()  # 'ST-2026-001'  正确
```

## 案例 5：bool 与字符串混淆

```python
need = input("住宿 y/n: ")
if need:  # 即使用户输入 n，非空字符串也为 True！
    print("要住宿")
```

**正确**：

```python
need = input("住宿 y/n: ").strip().lower() in ("y", "yes")
```

## 案例 9：多行 END 与 Windows 换行

Windows `\r\n` 在 Linux 服务器可能显式露出 `\r`。  
`strip()` 可去掉 `\r`，但文件读写应用 `newline="\n"`（Day 11）。

## 案例 10：运算符优先级笔试真题

表达式 `3 + 2 * 2 ** 2` 的值？  
**解析**：`**` → `*` → `+` → `2**2=4` → `2*4=8` → `3+8=11`。
