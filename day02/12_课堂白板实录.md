# Day 2 课堂白板实录 · 字符串方法逐项演示

以下为讲师下午板书的完整展开版，供缺席学员补课。

## strip 家族

```python
>>> "  \n  hi \t ".strip()
'hi'
>>> ">>>comment".lstrip(">")
'comment'
>>> "file.txt".removesuffix(".txt")  # Py3.9+
'file'
```

## 查找

```python
>>> "星火智服".find("智")
1
>>> "星火智服".find("AI")
-1
>>> "智" in "星火智服"
True
```

## 判断类

```python
>>> "13800138000".isdigit()
True
>>> "ST-2026-001".isalnum()  # 含连字符为 False
False
>>> "  ".isspace()
True
```

手机号校验 v1 可用 `isdigit()` 且 `len==11`；Day 11 用正则更严。

## 对齐（报表列打印）

```python
>>> f"{'姓名':<8}{'工号':<12}"
'姓名      工号          '
>>> f"{123:>5}"
'  123'
```

## 编码 bytes（部署常见）

```python
>>> "星火".encode("utf-8")
b'\xe6\x98\x9f\xe7\x81\xab'
>>> b'\xe6\x98\x9f\xe7\x81\xab'.decode("utf-8")
'星火'
```

HTTP 请求体 bytes ↔ str 转换在 Day 12。

## 遍历字符

```python
for ch in "ABC":
    print(ch, end="-")
# A-B-C-
```

## 累加构建（低效，仅教学）

```python
result = ""
for word in ["星火", "科技", "智服"]:
    result += word
# 大量拼接用 list + join 更快
"".join(["星火", "科技", "智服"])
```
