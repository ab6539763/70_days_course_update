# Day 2 流程图与示意图

## 1. 清洗流水线

```mermaid
flowchart TD
    Start([启动 text_cleaner]) --> Menu[显示清洗选项菜单]
    Menu --> Input[read_multiline_input]
    Input --> Parse[解析用户勾选项]
    Parse --> Pipe[apply_pipeline]
    Pipe --> Report[format_report 打印]
    Report --> Again{继续?}
    Again -->|y| Input
    Again -->|n| End([结束])
```

## 2. 字符串方法决策树

```mermaid
flowchart TD
    Q[有一段脏文本] --> A{仅首尾空格?}
    A -->|是| strip
    A -->|否| B{要删所有空白?}
    B -->|是| remove_all_spaces
    B -->|否| collapse_spaces
    strip --> C{要统一大小写?}
    collapse_spaces --> C
    C -->|是| normalize_case
    C -->|否| D{含敏感词?}
    normalize_case --> D
    D -->|是| mask_sensitive
    D -->|否| Out[输出]
    mask_sensitive --> Out
```
