## 一、Agent 基础（1–8）

**Q1. ReAct 三字母含义？**  
Thought（推理）/ Action（调工具）/ Observation（环境反馈）。对照 Day39 `react_agent.py`。

**Q2. Agent 与 Chain 区别？**  
Chain 固定 DAG；Agent 每轮 **动态** 选工具，适合路径不确定任务。

**Q3. Day 39 手写 vs Day 40 Executor？**  
前者文本解析 ReAct；后者 OpenAI `tool_calls` + schema，生产首选。

**Q4. max_iterations 作用？**  
防死循环与成本爆炸；对照 Day46 `guard_max_rounds` trace。

**Q5. 工具描述为何用中文？**  
与星火智服用户/运营语言一致，提高路由准确率。

**Q6. intermediate_steps 用途？**  
调试、审计、前端 steps 时间线（Project3 `state.steps`）。

**Q7. 何时不用 Agent？**  
规则 100% 确定、无工具需求 → 普通 Chain 或 SQL 模板即可。

**Q8. Function Calling 与 MCP 关系？**  
FC 是模型能力；MCP 是 **工具供应协议**，跨进程/跨语言复用工具。

## 二、LangGraph（9–16）

**Q9. StateGraph 与 State 关系？**  
图节点函数读写共享 `OfficeState`，边决定执行顺序。

**Q10. interrupt 与 input() 区别？**  
interrupt 持久化到 checkpointer，可跨 HTTP `resume`；input() 阻塞单进程。

**Q11. thread_id 作用？**  
`configurable.thread_id` 隔离 Checkpointer 中的会话状态。

**Q12. Command(resume=) 何时用？**  
人工审批后，`OfficeGraphService.resume_task` 传入 approval dict。

**Q13. 子图好处？**  
模块复用、团队分工（如 Researcher 子图独立测试）。

**Q14. 并行节点场景？**  
多章节同时写作、多数据源并行检索（本课图为串行教学）。

**Q15. Project3 几个节点？**  
planner → researcher → writer → human_gate → executor（五节点）。

**Q16. 图死循环如何检测？**  
max_steps + trace 重复 tool；条件边避免回边无终止。

## 三、多 Agent 与 MCP（17–22）

**Q17. Supervisor 模式一句话？**  
中央调度子 Agent，分配子任务并汇总（Day43–44）。

**Q18. Searcher/Analyst/Writer 分工？**  
搜资料 / 分析 / 成稿 —— 对照 Project3 researcher/writer。

**Q19. MCP Server 暴露什么？**  
tools + resources（文件、schema）。

**Q20. 为何 Agent 需要 MCP？**  
工具跨语言、跨进程复用，避免每个 Agent 重复封装 HTTP。

**Q21. Dify 与本项目关系？**  
低代码 PoC（Day45）vs 代码定制审批流与 verify 回归。

**Q22. Coze 适用场景？**  
运营配置、轻量 Bot、字节生态；核心 ERP 仍自研。

## 四、工程与安全（23–28）

**Q23. 护栏放哪层？**  
输入前 InputGuard、输出后 OutputGuard、工具前参数校验、写操作前 human_gate。

**Q24. LangSmith 解决什么？**  
Trace 树、评测数据集、回归对比（Day46 MockTracer 对标）。

**Q25. Text-to-SQL 如何防注入？**  
只读 + 关键字黑名单 + 只读 DB 用户（Day47 `validate_sql`）。

**Q26. API Key 在前端吗？**  
绝不；仅后端 `mock_llm` / 环境变量。

**Q27. verify_project3 测什么？**  
8 tools、三 Agent、图 compile、interrupt、API 冒烟。

**Q28. 成本优化三招？**  
减迭代轮次、小模型路由简单意图、缓存工具/RAG 结果。

## 五、开放题（29–30）扩展参考答案

**Q29. Project3 最大技术债？**

参考答案（任选 2–3 点展开）：

1. **MemorySaver** — 进程重启丢状态，无法横向扩展审批队列。  
2. **mock_llm 启发式** — plan/research 非真实推理，live 需重测全图。  
3. **无鉴权** — 任何人可 resume 审批，生产不可接受。  
4. **单租户 RAG** — sample_docs 固定，未接 Project2 混合检索。  

**Q30. 若上线生产先做哪三件事？**

标准答法（STAR 结构）：

1. **持久化 checkpointer**（Redis/Postgres）+ 审批审计表。  
2. **鉴权与 RBAC** — 仅 `approver` 角色可 resume approve。  
3. **稳定性套件** — Day46 护栏 + 限流 + LangSmith 采样 trace。  

加分：提及 **写操作幂等**（email_send 带 idempotency-key）。
