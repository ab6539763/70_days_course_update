## 第一章 · 装饰器原理（09:00–10:00）

### 1.1 装饰器是什么

装饰器是 **接收函数、返回函数** 的高阶函数。`@decorator` 语法糖等价于：

```python
def add(a, b):
    return a + b

add = decorator(add)
```

打开 [code/decorator_demo.py](./code/decorator_demo.py) 对照 §1。

### 1.2 functools.wraps

不用 `wraps` 时，`add.__name__` 会变成 `wrapper`，调试和文档丢失：

```python
@functools.wraps(func)
def wrapper(*args, **kwargs):
    ...
```

**讲师强调**：生产代码装饰器 **必须** `wraps`。

### 1.3 带参数的装饰器（三层嵌套）

```python
def retry(max_attempts=3):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            ...
        return wrapper
    return decorator
```

记忆口诀：**装饰器有参 → 多一层 `decorator` 函数**。

### 1.4 类装饰器

`@singleton` 装饰 **类** 而非函数，返回替代的可调用对象。见 `decorator_demo.py` §5。

## 第二章 · 生成器与 yield（10:00–11:00）

### 2.1 yield 暂停/恢复

```python
def count_up_to(n):
    i = 1
    while i <= n:
        yield i      # 产出值并暂停
        i += 1       # 下次 next() 从这里继续
```

与 `return` 对比：

| | `return` | `yield` |
|---|----------|---------|
| 次数 | 结束函数 | 可多次产出 |
| 返回值 | 单个对象 | 生成器对象 |
| 内存 | 一次性构造列表 | 惰性，按需产出 |

### 2.2 yield from

委托给子生成器，避免手写 for 循环：

```python
def chain(*iterables):
    for it in iterables:
        yield from it
```

## 第四章 · asyncio 入门（14:45–15:30）

### 4.1 coroutine 与 event loop

```python
async def say_after(delay, msg):
    await asyncio.sleep(delay)
    return msg

asyncio.run(say_after(1, "hi"))
```

`async def` 定义协程；`await` 让出控制权给事件循环。

### 4.2 gather 并发

```python
results = await asyncio.gather(task1(), task2(), task3())
```

三个 0.15s 的 IO 并发 ≈ 0.15s，而非 0.45s。

### 4.3 阻塞 IO：to_thread

Day 12 `requests` 是阻塞的。在 async 代码里：

```python
text = await asyncio.to_thread(blocking_llm_mock, prompt)
```

**不要** 在 async 函数里直接 `requests.post`——会卡死整个 event loop。

### 4.4 与 @timeout 装饰器的关系

| 层级 | 机制 |
|------|------|
| asyncio | `wait_for(coro, timeout=)` |
| 同步函数 | `api_decorators.timeout` + ThreadPoolExecutor |
| requests | `timeout=` 参数（连接/读取超时） |

三层可叠加，各司其职。

## 第六章 · api_decorators 实战（16:00–16:45）

### 6.1 @retry 设计

```python
@retry(max_attempts=3, delay=0.5, backoff=2.0, exceptions=(LLMHTTPError,))
def call(): ...
```

- **指数退避**：0.5s → 1s → 2s  
- **jitter**：随机抖动避免惊群  
- **exceptions 白名单**：只捕获指定类型  

### 6.2 @timeout 设计

用 `ThreadPoolExecutor` + `future.result(timeout=)` 实现跨平台超时。

抛出 `APITimeoutError`，与 `asyncio.TimeoutError` 区分。

### 6.3 装饰器叠加顺序

```python
@timeout(2.0)       # 外层
@retry(max_attempts=3)  # 内层
def _live_chat(...): ...
```

每次重试独立受 2s 限制。

▶ 运行：`python3 api_decorators.py`

## 附录 · 自检答案

1. **401/403 为何不重试？** 鉴权/权限错误，重试不会自愈，只会放大请求量。  
2. **timeout 在外、retry 在内？** 每次 attempt 独立计时，避免一次慢调用耗尽总预算。  
3. **生成器读大文件？** 逐行 `yield`，内存 O(1) 行缓冲而非 O(文件大小)。
