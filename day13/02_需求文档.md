## 4. 功能需求

### 4.1 api_decorators.py

| 符号 | 行为 |
|------|------|
| `@retry(...)` | 可配置 `max_attempts`、`delay`、`backoff`、`exceptions` |
| `@timeout(seconds)` | 超时抛出 `APITimeoutError` |
| `APIRetryExhaustedError` | 重试耗尽时抛出，保留 `last_error` |
| 演示 | 模拟 `ConnectionError` 恢复、慢调用超时 |

### 4.2 llm_client.py（Day 12 基线，本日依赖）

| 符号 | 行为 |
|------|------|
| `LLMClient` | `chat(messages) -> ChatResponse` |
| `load_dotenv_file()` | 加载 `code/.env` 或上级 `.env` |
| `resolve_api_key()` | 显式参数 > 环境变量 > 空 |
| mock 模式 | 无 Key 时 `_mock_chat`，不发起 HTTP |
| live 模式 | `requests.post` 调 OpenAI 兼容接口 |

### 4.3 resilient_llm_client.py

| 符号 | 行为 |
|------|------|
| `ResilientLLMClient` | 继承 `LLMClient`，live 路径叠加 retry+timeout |
| `_validate_config()` | live 模式校验 Key 长度；mock 打印提示 |
| `SimulatedFlakyClient` | 教学用，模拟 503 验证 retry |
| mock 路径 | 不经过装饰器，保持快速确定性 |

### 4.4 演示脚本

| 文件 | 必须演示 |
|------|----------|
| `decorator_demo.py` | 无参/带参装饰器、`wraps`、类装饰器 |
| `generator_demo.py` | `yield`、`yield from`、流式 token |
| `typing_demo.py` | TypedDict messages、Protocol、TypeVar |
| `asyncio_intro.py` | `gather`、`to_thread`、`wait_for` |
