## 1. 目标

1. **教学完整**：覆盖 schema、tool_call、执行、回填全链路。  
2. **无框架**：禁止 LangChain / LlamaIndex，纯 `requests` + 手写循环。  
3. **三工具**：天气 `get_weather`、计算 `calculate`、产品库 `query_products`。  
4. **mock 可跑**：无 Key 时启发式返回 `tool_calls`，CI 零配置验收。

## 4. 功能需求

### 4.1 schemas/

| 工具名 | 文件 | 必填参数 |
|--------|------|----------|
| `get_weather` | weather.json | city |
| `calculate` | calculator.json | expression |
| `query_products` | db_query.json | keyword |

`load_all_schemas()` 返回 OpenAI `tools` 数组。

### 4.2 tools.py

| 函数 | 行为 |
|------|------|
| `get_weather(city, unit?)` | 返回温湿度、天气状况（mock 库） |
| `calculate(expression)` | AST 白名单安全计算，拒绝字母 |
| `query_products(keyword, category?, limit?)` | 检索 `mock_products.json` |
| `TOOL_REGISTRY` | 名称 → 函数映射 |

### 4.3 tool_runner.py

| 符号 | 行为 |
|------|------|
| `run_tool_call(call)` | 执行单个 tool_call dict |
| `run_tool_calls(calls)` | 批量执行，返回 `ToolRunReport` |
| `ToolCallResult.to_tool_message()` | 生成 `role=tool` 消息 |

### 4.4 llm_client.py

| 符号 | 行为 |
|------|------|
| `ToolCallingLLMClient` | `chat_with_tools(messages, tools)` |
| mock 模式 | 启发式规划 tool_calls；tool 结果后生成最终文本 |
| live 模式 | `POST /chat/completions` 带 `tools` |

### 4.5 function_calling_agent.py

| 符号 | 行为 |
|------|------|
| `FunctionCallingAgent.run(query)` | 完整 Agent 循环，返回 `AgentTrace` |
| `max_rounds` | 默认 5，防止无限 tool 循环 |
| system prompt | 指导模型在需要时调用工具 |

## 5. 非功能需求

| 项 | 要求 |
|----|------|
| 安全 | `calculate` 禁止任意代码执行 |
| 可测 | mock 模式确定性输出 |
| 日志 | Agent 每轮打印 tool_call 与结果 |
| 依赖 | 仅 requests、python-dotenv |

| 风险 | 缓解 |
|------|------|
| live 模型不调工具 | 调低 temperature；system prompt 强调必须用工具 |
