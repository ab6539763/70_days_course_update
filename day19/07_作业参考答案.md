### A2. tools_extra.py（节选）

```python
RATES = {"USD": 1.0, "CNY": 7.2, "EUR": 0.92}

def convert_currency(amount: float, from_currency: str, to_currency: str) -> dict:
    fr, to = from_currency.upper(), to_currency.upper()
    if fr not in RATES or to not in RATES:
        raise ValueError("不支持的货币")
    usd = amount / RATES[fr]
    converted = usd * RATES[to]
    return {
        "amount": amount,
        "from": fr,
        "to": to,
        "result": round(converted, 2),
    }
```

**讲评**：汇率表 mock 即可；live 可接真实 API 作为挑战。

### C1. export_trace

```python
def export_trace(self, trace: AgentTrace, path: Path) -> None:
    path.write_text(
        json.dumps(trace.to_dict(), ensure_ascii=False, indent=2),
        encoding="utf-8",
    )
```

### C2. run_demo.py 结构

```python
agent = FunctionCallingAgent()
for q in ["北京天气", "(10+5)*4", "上海天气并算 3**5"]:
    trace = agent.run(q)
    agent.export_trace(trace, Path(f"trace_{hash(q)}.json"))
```

**讲评**：trace JSON 是调试 Agent 的神器，生产环境可接 OpenTelemetry。
