## 2. Function Calling 时序

```mermaid
sequenceDiagram
    participant U as 用户
    participant A as Agent
    participant L as LLM API
    participant T as tool_runner
    participant W as get_weather

    U->>A: 北京天气怎么样？
    A->>L: messages + tools schema
    L-->>A: tool_calls: get_weather(北京)
    A->>T: run_tool_calls
    T->>W: get_weather(city=北京)
    W-->>T: {temp:28, condition:晴}
    T-->>A: role=tool message
    A->>L: messages + tool result
    L-->>A: content: 北京当前晴，28°C...
    A-->>U: 最终回答
```

## 3. Agent 状态机

```text
        ┌─────────────┐
        │   START     │
        └──────┬──────┘
               │ append user message
               ▼
        ┌─────────────┐
   ┌───▶│  CALL LLM   │
   │    └──────┬──────┘
   │           │
   │     ┌─────┴─────┐
   │     ▼           ▼
   │  tool_calls?   no → FINAL_ANSWER → END
   │     │
   │     ▼ yes
   │  ┌─────────────┐
   │  │ RUN TOOLS   │
   │  └──────┬──────┘
   │         │ append tool messages
   │         ▼
   │    round < max?
   │         │
   └─────────┘ yes
             no → TIMEOUT_MSG → END
```
