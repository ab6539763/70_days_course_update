## 4. 方法分派（谁接收第一个参数）

```mermaid
flowchart LR
    subgraph instance [实例方法]
        I1[contact.update] --> I2[self = 该 contact]
    end
    subgraph classmethod [类方法]
        C1[Contact.from_dict] --> C2[cls = Contact 类]
    end
    subgraph static [静态方法]
        S1[Contact.normalize_phone] --> S2[无 self/cls]
    end
```

| 装饰器 | 第一个参数 | 典型用途 |
|--------|------------|----------|
| 无 | `self` | 改自己的字段 |
| `@classmethod` | `cls` | 工厂、`from_json` |
| `@staticmethod` | 无 | 纯工具、与类概念相关但不访问类/实例状态 |

## 11. 常见误区示意图

```text
  误区 1：把类当函数库，全是 @staticmethod
         → 应把「改自己状态」写成实例方法

  误区 2：__init__ 里 return 对象（错误）
         → __init__ 应 return None，构造由 Python 完成

  误区 3：contact.name 写成 contact["name"]
         → 对象用点号访问属性

  误区 4：classmethod 里用 self
         → 第一个参数是 cls
```
