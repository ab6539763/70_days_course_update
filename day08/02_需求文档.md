## 3. 数据模型

### 3.1 Contact 类（对齐 Day 7 dict）

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | int | 是 | 与 JSON 中 `id` 一致 |
| `name` | str | 是 | strip 后非空 |
| `phone` | str | 是 | 去空格后 ≥7 位数字 |
| `email` | str | 否 | 小写，默认 `""` |
| `department` | str | 否 | 默认 `未分配` |
| `notes` | str | 否 | 默认 `""` |
| `created_at` | str | 否 | ISO 8601，新建时自动生成 |
| `updated_at` | str | 否 | 修改时更新 |

### 3.2 ChatMessage 类

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `role` | str | 是 | 仅允许 `system` / `user` / `assistant` |
| `content` | str | 是 | strip 后非空 |
| `created_at` | str | 否 | 可选时间戳，默认构造时生成 |

### 3.3 与 Day 14 消息 JSON 对齐（预览）

```json
{
  "role": "user",
  "content": "星火智服，帮我查一下入职流程",
  "created_at": "2026-07-08T09:15:00+00:00"
}
```

## 4. 功能需求

### 4.1 Contact 类方法

| 方法 | 类型 | 行为 |
|------|------|------|
| `__init__` | 实例 | 赋值并校验 name / phone |
| `__str__` | 实例 | 返回与 Day 7 `format_contact` 风格一致的字符串 |
| `update(...)` | 实例 | 按参数更新字段，刷新 `updated_at` |
| `to_dict` | 实例 | 转为 Day 7 兼容的 dict |
| `from_dict` | classmethod | 从 dict 构造 `Contact`，键缺失用默认值 |
| `normalize_phone` | staticmethod | 复用 Day 7 手机号清洗逻辑 |

### 4.2 ChatMessage 类方法

| 方法 | 类型 | 行为 |
|------|------|------|
| `__init__` | 实例 | 校验 role 枚举与 content 非空 |
| `__str__` | 实例 | 如 `[user] 星火智服，帮我…`（过长截断） |
| `to_dict` / `from_dict` | 实例 / classmethod | JSON 互转 |
| `is_user` / `is_assistant` | 实例 | 便捷判断（可选实现） |
| `preview` | staticmethod | 截断 content 用于日志 |

### 4.3 教学 demo 文件

| 文件 | 必须演示 |
|------|----------|
| `oop_demo.py` | 定义类、创建对象、访问属性、调用实例方法 |
| `classmethod_demo.py` | 同一业务场景下三种方法的调用方式与 `self`/`cls` 区别 |

## 5. 校验规则

| 编号 | 规则 |
|------|------|
| V-01 | `Contact.name` strip 后非空 |
| V-02 | `Contact.phone` 规范化后至少 7 位数字 |
| V-03 | `ChatMessage.role` 不在白名单则 `ValueError` |
| V-04 | `ChatMessage.content` strip 后非空 |
| V-05 | `from_dict` 对未知字段忽略，不崩溃 |
