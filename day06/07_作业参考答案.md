## 必做 A 参考答案

### A1. format_employee_summary

```python
def format_employee_summary(
    name: str,
    employee_id: str,
    *,
    department: str = "大模型应用开发部",
    show_dorm: bool = False,
    need_dorm: bool = False,
) -> str:
    base = f"{name} ({employee_id}) @ {department}"
    if show_dorm:
        dorm_text = "是" if need_dorm else "否"
        return f"{base} | 住宿：{dorm_text}"
    return base


# 调用示例
assert format_employee_summary("陈晓", "ST-001", department="交付组") == "陈晓 (ST-001) @ 交付组"
assert format_employee_summary("李雷", "ST-002", department="产品组", show_dorm=True, need_dorm=True).endswith("是")
```

**讲评要点**：`department` 必须用 `department="..."` 调用，体会 keyword-only 前的 `*` 在函数定义里的位置。

### A2. join_non_empty

```python
def join_non_empty(*parts: str, sep: str = " | ") -> str:
    return sep.join(p for p in parts if p)
```

### A3. 可变默认参数

`def f(items=[])` 时，默认值 `[]` 在 **函数定义时创建一次**，所有未传 `items` 的调用共享同一列表。  
**正确**：`def f(items=None): items = items if items is not None else []`

### B3. count_char 递归

```python
def count_char(text: str, ch: str) -> int:
    if not text:
        return 0
    head, tail = text[0], text[1:]
    return (1 if head == ch else 0) + count_char(tail, ch)
```

**讲评**：强调基线 `not text`；可讨论尾递归与迭代版本效率。

## 挑战 F 参考答案

```python
def flatten_deep(nested: list) -> list:
    result: list = []
    for item in nested:
        if isinstance(item, list):
            result.extend(flatten_deep(item))
        else:
            result.append(item)
    return result


assert flatten_deep([[1, [2, [3]]], 4]) == [1, 2, 3, 4]
assert flatten_deep([]) == []
```
