## 3. 与大模型开发的隐性联系

| 今日知识点 | 日后场景 |
|------------|----------|
| 纯函数（输入→输出，无副作用） | LLM Tool 函数、可单测的清洗管道 |

| 包与模块 | `langchain`/`openai` SDK 的 import 结构 |
