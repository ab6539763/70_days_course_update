## 1. 背景与目标

Day 1–5 交付了五个可运行的单文件脚本。为支撑 Day 14「命令行 AI 助手」多模块集成，需将核心逻辑拆为可 `import` 的 Python 包，消除 `sys.path.insert` 跨日引用。

**目标**：在 `day06/code/` 下建立四个包，行为与 Day 1–5 原脚本等价。

## 3. 功能需求

### 3.1 包结构（F-01）

```
day06/code/
├── sparktech_onboard/      # Day 1 入职卡片
├── sparktech_cleaners/     # Day 2 字符串清洗
├── sparktech_todo/         # Day 4 待办 CRUD
├── sparktech_export/       # Day 5 JSON 导出
├── data/mock_api_response.json
├── output/                 # 导出目录（自动创建）
├── demo_functions.py
├── refactor_verify.py
├── run_onboard_card.py
├── run_todo_cli.py
└── run_export_json.py
```

每个包必须包含 `__init__.py`，并在 `__all__` 中声明公开 API。

### 3.2 sparktech_onboard（F-02）

| 函数/类 | 说明 | 追溯 |
|---------|------|------|
| `EmployeeCard` | dataclass 数据载体 | Day 1 |
| `collect_inputs()` | 终端采集六字段 | Day 1 |
| `render_card(card)` | 渲染卡片字符串 | Day 1 |
| `format_bool_display(bool)` | 是/否 映射 | Day 1 |
| `card_to_dict(card)` | 转 dict（新增，供导出） | Day 5 衔接 |

### 3.3 sparktech_cleaners（F-03）

| 函数 | 说明 | 追溯 |
|------|------|------|
| `strip_edges` | 去首尾空白 | Day 2 F-01 |
| `collapse_spaces` | 合并空白 | Day 2 F-02 |
| `normalize_case` | 大小写 | Day 2 F-03 |
| `mask_sensitive` | 敏感词 | Day 2 F-04 |

### 3.4 sparktech_todo（F-04）

| 模块 | 职责 |
|------|------|

| 函数 | 说明 |
|------|------|
| `add_todo` | 添加 |

| `delete_todo` | 删除，返回 `(bool, str)` |

### 3.5 sparktech_export（F-05）

| 模块 | 职责 |
|------|------|
| `api.py` | Mock JSON 解析 |
| `employee.py` | 清洗 + 写文件 + 报告 |

| 函数 | 说明 |
|------|------|
| `parse_employees_from_file` | 解析 employees 列表 |
| `clean_employee` | 单条清洗，调用 `sparktech_cleaners` |
