## 1. 纯函数（Pure Function）是什么

满足两条：

1. **相同输入 → 相同输出**（不依赖外部可变状态）  
2. **无副作用**（不改全局、不写文件、不 print、不请求网络）  

`sparktech_cleaners.strip_edges` 是纯函数；`collect_inputs` 不是（依赖 `input()`）。

| 函数 | 纯？ | 原因 |
|------|------|------|
| `strip_edges` | ✅ | str → str |
| `clean_employee` | ✅ | 返回新 dict |
| `add_todo` | ⚠️ | 修改传入的 `todos` list |
| `write_employees_json` | ❌ | 写文件 |
| `run_cli` | ❌ | 交互循环 |

**张工口径**：业务 core 层尽量纯；IO 和 CLI 边界集中。

## 2. 闭包在 Agent 里的影子

Day 48 Planner Agent 维护任务列表，可抽象为：

```python
def make_task_store():
    tasks: list[dict] = []

    def add(title: str) -> dict:
        item = {"id": len(tasks) + 1, "title": title, "done": False}
        tasks.append(item)
        return item

    def list_all() -> list[dict]:
        return list(tasks)

    return add, list_all
```

外层 `tasks` 被内层函数「封住」——与 `make_counter` 同构。  
LangChain 的 `RunnableWithMessageHistory` 底层也是 **闭包 + 可变状态**，只是框架帮你写了。

## 3. 函数即 LLM Tool Schema

OpenAI 兼容 API 的 tool 定义（简化）：

```json
{
  "type": "function",
  "function": {
    "name": "add_todo",
    "description": "向待办列表添加一条任务",
    "parameters": {
      "type": "object",
      "properties": {
        "title": {"type": "string"},
        "priority": {"enum": ["P0", "P1", "P2"]}
      },
      "required": ["title"]
    }
  }
}
```

与 Python 对照：

```python
def add_todo(todos: list[dict], next_id: int, title: str, priority: str = "P1", ...) -> int:
    """向待办列表添加一条任务。"""
```

**name** ← 函数名；**description** ← docstring 首行；**parameters** ← 类型注解 + 默认值。  
Day 34 会用库自动从函数签名生成 schema；今天手写注解就是在攒素材。

## 4. `lambda` vs `def` 决策树

```text
逻辑是否超过一行？
  ├─ 是 → def
  └─ 否 → 是否只在一处用作 key/callback？
            ├─ 是 → lambda 可接受
            └─ 否 → def 并命名
```

可读性优先于行数。`list_todos` 里若排序规则变复杂，应提取 `def priority_key(t): ...`。

## 5. 递归 vs 迭代选型

| 场景 | 建议 |
|------|------|
| 树/图遍历、嵌套 JSON | 递归或显式栈 |
| 简单累加、计数 | 迭代 |
| Python 默认递归深度 ~1000 | 深嵌套用 `while` + 栈 |

`flatten_deep` 在极深嵌套下可能 `RecursionError`；生产代码常用迭代 + 显式 `stack = [nested]`。

## 6. 包 import 的三种姿势（预习 Day 10）

```python
# 1. 绝对 import（今日入口脚本）
from sparktech_cleaners import strip_edges

# 2. 相对 import（包内模块）
from .constants import CaseMode

# 3. 包运行（Day 10）
# python -m sparktech_export.employee
```

避免 **循环导入**：`a.py` import `b`，`b.py` 又 import `a`。  
设计时保持依赖单向：`export → cleaners → (无反向)`。
