## 4. 参数种类对照

```text
def demo(a, b, c=1, *args, key_only, **kwargs):

调用示例：
    demo(1, 2)                    → a=1, b=2, c=1
    demo(1, 2, 3)                 → a=1, b=2, c=3
    demo(1, 2, c=3)               → 关键字改 c
    demo(1, 2, 3, 4, 5)           → args=(4, 5)
    demo(1, 2, key_only="x")      → 必须关键字
    demo(1, 2, extra="y")         → kwargs={'extra':'y'}
```

## 6. 递归 factorial(3) 展开

```text
factorial(3)
  → 3 * factorial(2)
        → 2 * factorial(1)

        → 2 * 1 = 2

```
