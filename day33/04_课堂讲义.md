# Day 33 课堂讲义 · Hybrid 与增强 RAG

## 第一章 · BM25 与向量互补（09:00–10:00）

- **BM25**：词频稀疏匹配，擅长 SKU、错误码、专有名词  
- **向量**：语义匹配，擅长 paraphrase  
- 单一路径无法覆盖全部查询类型  

运行：`python3 hybrid_retriever.py`

## 第二章 · RRF 融合（10:00–10:30）

```python
reciprocal_rank_fusion([bm25_ids, vec_ids], k=60, top_n=5)
```

不讲分数绝对值，只讲 **排名**——避免 BM25 与 cosine 量纲不一致。

## 第三章 · Reranker（10:30–12:00）

Cross-encoder 对 `(query, doc)` 联合编码，比 bi-encoder 更准、更慢。

mock：`mock_cross_encoder_score` 用 token 重叠模拟。

