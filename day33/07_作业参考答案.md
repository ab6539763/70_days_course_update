# Day 33 作业参考答案

## Hybrid vs 纯向量

| 查询 | 纯向量可能 | Hybrid 优势 |
|------|------------|-------------|
| P0 15 分钟 | 语义相近段 | BM25 命中「P0」「15」 |
| API Key | 取决于 embedding | 双路互补 |
| 退款 7 天 | 可能命中定价 | BM25 强化「退款」「7」 |

## RRF

`k=60` 为论文常用默认值；`k` 越小，排名靠前项权重越大。

## Parent Document

child 提供精细召回；parent 保证 LLM 看到完整政策段落，避免断章取义。

## Pipeline

`enhanced_rag_pipeline` 输出应含：`rewritten_query`, `parent_docs`, `answer` 非空。
