## 全链路时序

```mermaid
sequenceDiagram
    participant U as User
    participant P as Pipeline
    participant H as Hybrid
    participant R as Reranker
    participant L as LLM

    U->>P: query
    P->>P: rewrite
    P->>H: retrieve children
    H-->>P: RRF hits
    P->>P: resolve parents
    P->>R: rerank parents
    R-->>P: top docs
    P->>L: compress + generate
    L-->>U: answer
```
