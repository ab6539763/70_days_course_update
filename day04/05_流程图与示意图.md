# Day 4 流程图与示意图

## 1. 待办管理器主流程

```mermaid
flowchart TD
    Start([启动 todo_manager]) --> Init[todos=[], next_id=1]
    Init --> Menu[打印菜单 1-4,0]
    Menu --> Input[读取用户选择]
    Input --> Branch{choice}
    Branch -->|1| Add[add_todo: append]
    Branch -->|2| List[list_todos: 过滤+排序+打印]
    Branch -->|3| Complete[complete_todo: done=True]
    Branch -->|4| Delete[delete_todo: pop]
    Branch -->|0| Quit[提示未持久化并退出]
    Branch -->|其他| Invalid[打印无效选项]
    Add --> Menu
    List --> Menu
    Complete --> Menu
    Delete --> Menu
    Invalid --> Menu
    Quit --> End([结束])
```

## 2. 列表 CRUD 与待办业务映射

```mermaid
flowchart LR
    subgraph Create
        A1[input 标题] --> A2[构造 dict]
        A2 --> A3[todos.append]
    end
    subgraph Read
        R1[选择 filter] --> R2[推导式或循环]
        R2 --> R3[f-string 打印]
    end
    subgraph Update
        U1[输入 id] --> U2[find_index]
        U2 --> U3[改 done 字段]
    end
    subgraph Delete
        D1[输入 id] --> D2[find_index]
        D2 --> D3[pop 索引]
    end
```

## 4. 排序决策树

```mermaid
flowchart TD
    Q[需要排序展示] --> A{能否改原 list?}
    A -->|不能| sorted[使用 sorted 返回新列表]
    A -->|能| sort[使用 list.sort 原地]
    sorted --> B{按什么排?}
    sort --> B
    B -->|优先级| K1[key=priority_key]
    B -->|id| K2[key=lambda t: t id]
    B -->|标题| K3[key=lambda t: t title]
```
