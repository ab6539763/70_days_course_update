## B4 stats 示例

```python
def print_stats(todos: list[dict]) -> None:
    total = len(todos)
    done = sum(1 for t in todos if t["done"])
    rate = (done / total * 100) if total else 0.0
    print(f"总计 {total}，已完成 {done}，完成率 {rate:.1f}%")
```

## C1 冒泡排序示意

```python
RANK = {"P0": 0, "P1": 1, "P2": 2}
arr = ["P2", "P0", "P1"]
n = len(arr)
for i in range(n):
    for j in range(0, n - i - 1):
        if RANK[arr[j]] > RANK[arr[j + 1]]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]
```

def tool_list_pending(todos: list[dict]) -> list[dict]:

## 讲评要点

1. **查找**：统一 `find_index_by_id`，避免多处复制 for 循环。  
2. **排序**：展示用 `sorted` + `key`，别原地 sort 除非有意为之。  
3. **推导式**：超过两层嵌套建议改 for 循环。  
4. **业务**：complete 保留审计痕迹；delete 仅纠错。
