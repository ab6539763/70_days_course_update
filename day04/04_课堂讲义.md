## 第一章 · 为什么需要列表

### 1.1 从单个变量到一批数据

Day 1 你存一个人的姓名；Day 2 清洗一段文本。若产品给出 **12 条 Sprint 待办**，用 12 个变量 `task1, task2, ...` 不可维护。

```python
# 反例：不可扩展
task1 = "写接口文档"
task2 = "补单元测试"
# task13 怎么办？
```

```python
# 正例：有序可变序列
tasks = ["写接口文档", "补单元测试", "验收登录"]
```

**list 的核心特征**：

| 特征 | 含义 | 业务联想 |
|------|------|----------|
| 有序 | 有先后，可用下标访问 | 对话历史、任务队列 |
| 可变 | 可增删改元素 | 动态追加 Agent 子任务 |
| 可重复 | 同一值可出现多次 | 日志行（去重用 set） |
| 异构 | 可混存不同类型 | 一般不推荐，待办用统一 dict |

### 1.2 创建列表

```python
todos = []                          # 空列表，最常见初始化
nums = [1, 2, 3]
mixed = ["P1", 42, True]            # 教学用，业务代码避免
from_str = list("abc")              # ['a', 'b', 'c']
repeat = [0] * 5                    # [0, 0, 0, 0, 0]
```

**星火场景**：程序启动时 `todos = []`，每 add 一次 `append` 一条。

### 1.3 长度与成员检测

```python
len(todos)           # 待办总数
3 in [1, 2, 3]       # True
"P0" in ("P0", "P1")  # tuple 同样支持 in
```

## 第二章 · 列表 CRUD

### 2.1 查（Read）

```python
tasks = ["接口文档", "单元测试", "验收登录"]

tasks[0]      # '接口文档'  第一个
tasks[-1]     # '验收登录'  最后一个
tasks[1:3]    # ['单元测试', '验收登录']  切片：含头不含尾
```

**按 id 找待办**（线性查找，v1.0 足够）：

```python
def find_index_by_id(todos: list[dict], todo_id: int) -> int | None:
    for i, item in enumerate(todos):
        if item["id"] == todo_id:
            return i
    return None
```

`enumerate` 同时给出索引和元素——比 `range(len(todos))` 更 Pythonic。

### 2.2 增（Create）

| 方法 | 作用 | 示例 |
|------|------|------|
| `append(x)` | 尾部加一个 | `todos.append(new_item)` |
| `insert(i, x)` | 指定位置插入 | 插队高优先级 |
| `extend(iterable)` | 尾部合并多个 | `todos.extend(batch)` |
| `+` | 拼接新列表 | `a = a + [x]` 产生新对象 |

```python
new_todo = {"id": 1, "title": "写 PRD", "done": False, "priority": "P1", "tags": []}
todos.append(new_todo)
next_id = 2
```

### 2.3 改（Update）

```python
todos[0]["done"] = True           # 改 dict 的字段
todos[0]["title"] = "新标题"      # 改标题
```

**注意**：改的是 list **里那个 dict 对象**的内容，不是替换整个 list。

### 2.4 删（Delete）

| 方法 | 作用 |
|------|------|
| `pop()` | 删最后一个并返回 |
| `pop(i)` | 删索引 i |
| `remove(x)` | 删第一个等于 x 的值 |
| `del todos[i]` | 语句删除索引 i |
| `clear()` | 清空 |

```python
idx = find_index_by_id(todos, 3)
if idx is not None:
    todos.pop(idx)
```

**业务选择**：`complete` 改状态保留记录；`delete` 用于录错、重复项。

### 2.5 遍历

```python
# 只要标题
for t in todos:
    print(t["title"])

# 需要编号
for i, t in enumerate(todos, start=1):
    print(f"{i}. {t['title']}")
```

## 第三章 · 切片深度

### 3.1 切片语法

```text
list[start:stop:step]
```

| 写法 | 含义 |
|------|------|
| `[:3]` | 前 3 个 |
| `[2:]` | 从索引 2 到末尾 |
| `[::-1]` | 反转 |
| `[::2]` | 步长 2 取样 |
| `[:]` | 浅拷贝整个列表 |

### 3.2 切片不改原列表

```python
original = [1, 2, 3, 4, 5]
head = original[:2]    # [1, 2]
# original 仍是 [1, 2, 3, 4, 5]
```

**大模型场景**：`messages[-10:]` 取最近 10 轮对话拼进 Prompt（Day 15）。

### 3.3 切片赋值（进阶）

```python
nums = [1, 2, 3, 4, 5]
nums[1:4] = [20, 30]   # [1, 20, 30, 5]
```

初学阶段了解即可；待办删除更常用 `pop`。

## 第四章 · 排序

### 4.1 `list.sort()` 原地排序

```python
nums = [3, 1, 4, 1, 5]
nums.sort()              # nums 变为 [1, 1, 3, 4, 5]
nums.sort(reverse=True)  # 降序
```

**返回值是 `None`**——不要写 `x = nums.sort()`。

### 4.2 `sorted()` 返回新列表

```python
original = [3, 1, 2]
ordered = sorted(original)   # [1, 2, 3]
# original 不变
```

待办展示推荐 `sorted`，避免打乱内存中的插入顺序，除非产品明确要求原地排序。

### 4.3 按 key 排序

```python
PRIORITY_RANK = {"P0": 0, "P1": 1, "P2": 2}

def priority_key(todo: dict) -> int:
    return PRIORITY_RANK.get(todo.get("priority", "P1"), 1)

for t in sorted(todos, key=priority_key):
    print(t["title"])
```

多级排序：

```python
sorted(todos, key=lambda t: (priority_key(t), t["id"]))
```

先按优先级，再按 id。

### 4.4 稳定排序

Python 的排序是**稳定**的：key 相同时保持原有相对顺序。对任务队列很重要。

## 第五章 · 列表推导式

### 5.1 基本形式

```python
# 等价于 for 循环 + append
squares = [x * x for x in range(6)]
# [0, 1, 4, 9, 16, 25]
```

展开写法：

```python
squares = []
for x in range(6):
    squares.append(x * x)
```

推导式更简洁，适合**映射**（每个 x 变形成新值）。

### 5.2 带条件过滤

```python
pending_titles = [t["title"] for t in todos if not t["done"]]
p0_tasks = [t for t in todos if t.get("priority") == "P0"]
```

### 5.3 嵌套推导（适度使用）

```python
# 所有标签扁平化
all_tags = [tag for t in todos for tag in t["tags"]]
```

嵌套超过两层时改回 for 循环，可读性优先。

### 5.4 与 set 推导对照（下午）

```python
unique_tags = {tag for t in todos for tag in t["tags"]}
```

花括号 `{}` 生成 set，自动去重。

### 5.5 业务禁忌

- 推导式里避免副作用（不要在里面 `append` 到外部 list）  
- 逻辑超过一行条件时，用普通 for 循环  

▶ 实操：`list_demo.py` → `demo_comprehensions()`。

## 第六章 · 元组 tuple

### 6.1 不可变有序序列

```python
point = (10, 20)
PRIORITIES = ("P0", "P1", "P2")
single = (42,)    # 单元素 tuple 必须逗号
not_tuple = (42)  # 这是 int
```

不能 `point[0] = 5`，会 `TypeError`。

### 6.2 何时用 tuple

| 场景 | 示例 |
|------|------|
| 固定配置 | `PRIORITIES = ("P0", "P1", "P2")` |
| 函数返回多个值 | `return todos, next_id` |
| dict 的 key | `cache[("gpt-4", 0.7)] = result` |
| 保护数据不被改 | 传给其他模块的只读坐标 |

### 6.3 打包与解包

```python
pair = ("星火", 2026)
name, year = pair

todos, next_id = load_state()   # Day 5 从 JSON 加载
```

交换变量：

```python
a, b = b, a   # 底层用 tuple 打包解包
```

### 6.4 命名元组（了解）

```python
from typing import NamedTuple

class Point(NamedTuple):
    x: int
    y: int

p = Point(3, 4)
print(p.x, p.y)
```

## 第七章 · 集合 set

### 7.1 无序、不重复

```python
tags = {"api", "doc", "api"}   # {"api", "doc"}
ids = set([1, 2, 2, 3])        # {1, 2, 3}
```

**无下标**：`tags[0]` 报错。用途是成员检测与集合运算。

### 7.2 增删

```python
s = {1, 2, 3}
s.add(4)
s.remove(2)      # 不存在会 KeyError
s.discard(99)    # 不存在不报错
```

### 7.3 交并差

```python
a = {"api", "doc", "qa"}
b = {"api", "frontend"}

a | b    # 并集 {'api', 'doc', 'qa', 'frontend'}
a & b    # 交集 {'api'}
a - b    # 差集 {'doc', 'qa'}
```

**RAG 场景**：`retrieved_ids & allowed_ids` 过滤无权限文档（Day 37 预习）。

### 7.4 待办标签去重

```python
def parse_tags(raw: str) -> list[str]:
  parts = [p.strip() for p in raw.split(",") if p.strip()]
  return sorted(set(parts))   # 去重 + 稳定展示顺序
```

### 7.5 list vs tuple vs set 选型

| 需求 | 选用 |
|------|------|
| 有序、要改、允许重复 | `list` |
| 有序、不改、可重复 | `tuple` |
| 不关心顺序、要去重 | `set` |
| 按键查找 | `dict`（Day 5） |

▶ 实操：`tuple_set_demo.py` → `demo_set()`。

## 第八章 · 待办管理器实现

### 8.1 全局状态

```python
todos: list[dict] = []
next_id: int = 1
```

程序退出后数据消失——PRD 刻意为之，Day 5 用 JSON 解决。

### 8.2 添加待办

```python
def add_todo(
    todos: list[dict],
    next_id: int,
    title: str,
    priority: str = "P1",
    tags: list[str] | None = None,
) -> int:
    title = title.strip()
    if not title:
        raise ValueError("标题不能为空")
    if priority not in ("P0", "P1", "P2"):
        priority = "P1"
    item = {
        "id": next_id,
        "title": title,
        "done": False,
        "priority": priority,
        "tags": tags or [],
    }
    todos.append(item)
    return next_id + 1
```

### 8.3 列表展示

```python
def format_todo(item: dict) -> str:
    mark = "[x]" if item["done"] else "[ ]"
    tag_str = ",".join(item["tags"]) if item["tags"] else "-"
    return f"[#{item['id']}] {mark} {item['priority']} | {item['title']} | tags: {tag_str}"
```

### 8.4 完成与删除

```python
def complete_todo(todos: list[dict], todo_id: int) -> bool:
    idx = find_index_by_id(todos, todo_id)
    if idx is None:
        return False
    todos[idx]["done"] = True
    return True

def delete_todo(todos: list[dict], todo_id: int) -> bool:
    idx = find_index_by_id(todos, todo_id)
    if idx is None:
        return False
    todos.pop(idx)
    return True
```

## 第九章 · 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| `IndexError` | 下标越界 | 先 `0 <= i < len(todos)` |
| `sort` 后顺序「乱」 | 对含 dict 的 list 直接 sort | 提供 `key=` |
| 切片没生效 | 误以为切片会改原列表 | 用 `sort` 或赋值 |
| `tuple` 改不了 | 不可变 | 新建 tuple 或改用 list |
| `set` 无序导致「跳动」 | 展示前 `sorted(s)` | 仅去重用 set |
| 删错项 | `remove(dict)` 比较引用 | 按 id 找索引再 `pop` |

## 第十一章 · 课堂习题

1. `[1, 2, 3][1:]` 的结果？  
2. `sorted([3,1,2])` 与 `[3,1,2].sort()` 对原列表的影响有何不同？  
3. `{x % 3 for x in range(6)}` 的值是什么？  
4. 为什么 Agent 的 `messages` 用 list 而不是 set？  

<details><summary>答案</summary>

1. `[2, 3]`  
2. `sorted` 返回新列表，原列表不变；`.sort()` 原地修改，返回 `None`  
3. `{0, 1, 2}`  
4. 对话有严格先后顺序，且允许结构重复；set 无序且去重  

</details>

## 第十二章 · 业务背景习题解析

1. 多条任务需要统一遍历、排序、过滤 → 必须用容器；`list` 最合适。  
2. 完成应保留历史便于复盘；删除用于纠错。Sprint 燃尽图依赖「已完成仍可见」。  
3. 配置项、多返回值、当 dict key 时用 tuple，防止被误改。
