# Day 4 架构与设计 · 待办列表与 CLI 分层

## 1. 总体架构

```text
┌──────────────────────────────────────────────────────┐
│                   todo_manager.py                      │
│  ┌─────────────┐   ┌──────────────┐   ┌────────────┐ │
│  │ CLI 菜单    │──▶│ TodoService  │──▶│ 格式化输出 │ │
│  │ input 循环  │   │ CRUD 纯逻辑  │   │ f-string   │ │
│  └─────────────┘   └──────┬───────┘   └────────────┘ │
└───────────────────────────┼──────────────────────────┘
                            │
                            ▼
                    todos: list[dict]
                    next_id: int
```

**设计原则**：`list` 是单一数据源；所有修改通过函数完成，不散落裸 `todos[i] = ...` 在 CLI 里——方便 Day 6 抽成模块、Day 48 换成 Agent tool 调用。

## 2. 内存数据流

```mermaid
flowchart TD
    Start([启动]) --> Init[todos=[], next_id=1]
    Init --> Menu[显示菜单]

    Choice -->|4 delete| Delete[按 id 删除元素]
    Choice -->|0 quit| End([退出])
    Add --> Menu
    List --> Menu
    Complete --> Menu
    Delete --> Menu
```

## 3. 模块职责

| 模块 / 函数 | 职责 |
|-------------|------|
| `add_todo(todos, next_id, title, ...)` | 构造 dict、`append`、返回新 `next_id` |
| `find_todo_by_id(todos, todo_id)` | 线性查找，返回索引或 `None` |
| `complete_todo(todos, todo_id)` | 改 `done` 字段 |
| `delete_todo(todos, todo_id)` | `pop` 或切片重建 |
| `list_todos(todos, filter_mode, sort_key)` | 过滤 + 排序 + 格式化 |
| `parse_tags(raw: str) -> list[str]` | 逗号分割 → set 去重 → sorted list |
| `main()` | `while True` 菜单循环 |

## 4. 列表操作映射（教学对照）

| 业务操作 | list 操作 | 注意 |
|----------|-----------|------|
| 新增待办 | `append(item)` | 尾部 O(1) |
| 查看前 5 条 | `todos[:5]` | 切片不改原列表 |
| 删除 id=3 | 查索引后 `pop(i)` | 删中间 O(n) |
| 按优先级排序 | `sorted(todos, key=...)` | 不改原列表 |
| 批量取标题 | `[t["title"] for t in todos]` | 列表推导式 |
| 未完成列表 | `[t for t in todos if not t["done"]]` | 过滤推导 |

## 5. 元组与集合在本项目中的位置

```text
  PRIORITY_ORDER = ("P0", "P1", "P2")     # tuple：不可变配置
  tags = list(set(parts))                  # set：输入去重
  return (todos, next_id)                  # tuple：多返回值
```

| 类型 | 本项目用法 | 为何不用 list |
|------|------------|---------------|
| tuple | 优先级枚举顺序、函数返回多值 | 防止被意外 `.append` 篡改 |
| set | 标签去重、已见 id 集合（作业） | 自动去重、O(1) 成员检测 |
