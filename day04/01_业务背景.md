### 1.1 现场情况

周四上午站会，李姐展示了一张混乱的协作现状：

| 来源 | 内容示例 | 问题 |
|------|----------|------|

张工在白板上画了一条线：

```text
  产品需求条目  ──▶  研发待办列表  ──▶  Sprint 承诺  ──▶  验收勾选
```

然后转向培训生：

> 「李姐不需要你们今天做 Jira 竞品，她要一个**能 add、能 list、能 complete、能 delete** 的命令行工具。数据先放内存里——**就是一个 Python list**。  
> 六周后 Planner Agent 也要维护这样一个 list，只是到时候任务来自模型解析，而不是你手敲。今天把数据结构练扎实。」

## 3. 与大模型开发的隐性联系

| 今日知识点 | 日后场景 |
|------------|----------|
| `list` 有序、可变 | `messages` 对话历史、`tools` 调用序列 |
| `list.append` / 切片 | 截取最近 N 轮上下文（Day 15 上下文窗口） |
| `sorted` / `sort` | 按优先级、截止时间排列 Agent 子任务 |
| 列表推导式 | 批量构造 Prompt 片段、过滤检索结果 |
| `tuple` 不可变 | 配置常量、函数多返回值、dict 的 key |
| `set` 去重 / 交并差 | 用户标签、已检索文档 ID、去重 chunk |

李姐补充了一句业务话：

> 「我们以后要让 Agent 自动从会议纪要里抽任务写进列表。你们今天手写的 `add`，将来就是 `tool_call: create_task`。」
