# Day 43 流程图与示意图

## 1. Supervisor 循环

```ascii
    +-------------+
    | supervisor  |
    +------+------+
           |
    +------+------+------+
    |      |      |      |
    v      v      v      v
searcher analyst writer FINISH
    |      |      |
    +------+------+ (回到 supervisor)
```

## 2. 消息流

```mermaid
sequenceDiagram
    participant S as Supervisor
    participant R as Searcher
    participant A as Analyst
    participant W as Writer
    S->>R: route searcher
    R-->>S: search_result
    S->>A: route analyst
    A-->>S: analysis_result
    S->>W: route writer
    W-->>S: report
    S->>S: FINISH
```
