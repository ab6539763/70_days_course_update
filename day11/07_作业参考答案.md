### A1. log_append.py

```python
from datetime import datetime
from pathlib import Path


def append_log(message: str, log_path: str = "output/homework.log") -> None:
    path = Path(log_path)
    path.parent.mkdir(parents=True, exist_ok=True)
    stamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    line = f"[{stamp}] {message}\n"
    with open(path, "a", encoding="utf-8") as f:
        f.write(line)


def main() -> None:
    append_log("第一次写入：星火智服")
    append_log("第二次写入：关键词统计")


if __name__ == "__main__":
    main()
```

**讲评**：模式 `"a"` 追加；`mkdir(parents=True, exist_ok=True)` 避免目录不存在。

### A2. CSV 汇总思路

```python
import csv
from collections import Counter
from pathlib import Path

def main() -> None:
    src = Path(__file__).resolve().parents[2] / "day11" / "code" / "data" / "sample_contacts.csv"
    counts: Counter[str] = Counter()
    with open(src, encoding="utf-8", newline="") as f:
        for row in csv.DictReader(f):
            counts[row["department"]] += 1
    out = Path("output/summary.csv")
    out.parent.mkdir(parents=True, exist_ok=True)
    with open(out, "w", encoding="utf-8", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=["department", "count"])
        writer.writeheader()
        for dept, n in sorted(counts.items()):
            writer.writerow({"department": dept, "count": n})
```

### B1. dir_stats.py

```python
from collections import defaultdict
from pathlib import Path


def count_by_suffix(root: Path) -> dict[str, int]:
    stats: dict[str, int] = defaultdict(int)
    for path in root.rglob("*"):
        if path.is_file():
            stats[path.suffix.lower()] += 1
    return dict(stats)
```

### B2. 相对路径说明（要点）

- JSON 报告若在多台机器间交换，绝对路径 `/home/user/...` 无意义。  
- `relative_to(docs_dir)` 保留「知识库内位置」，与 Day 28 `metadata["source"]` 一致。  
- 便于 Git 与代码评审时人类阅读。

### C1. mask_phone.py

```python
import re

PATTERN = re.compile(r"(?<!\d)(1\d{10})(?!\d)")


def mask_phone_text(text: str) -> str:
    def repl(match: re.Match[str]) -> str:
        phone = match.group(1)
        return f"{phone[:3]}****{phone[-4:]}"

    return PATTERN.sub(repl, text)
```

## 常见失分点

| 现象 | 扣分原因 |
|------|----------|
| CSV 无 `newline=""` | Windows 多空行 |
| JSON 中文 `\u` 转义 | 未 `ensure_ascii=False` |
| 坏文件导致程序崩溃 | 未做 `read_document` 错误隔离 |
| 报告用绝对路径 | 可移植性差 |
