## 1. 目标

1. **文件 IO 工程化**：txt/csv/json 读写统一 `with` + UTF-8。  
2. **目录批处理**：递归扫描指定目录下 `.txt` / `.md` 文件。  
3. **关键词统计**：按配置关键词列表输出每文档、每关键词命中次数及汇总。  
4. **可验收报告**：JSON 含扫描时间、文件数、明细与总计。  
5. **教学完整**：三个 demo 脚本覆盖当日全部标准库知识点。

## 4. 功能需求

### 4.1 file_io_demo.py

| 演示块 | 必须包含 |
|--------|----------|
| txt | `with open(..., "w"/"r", encoding="utf-8")` 读写中文 |
| csv | `csv.reader` / `csv.DictWriter` |
| json | `json.load` / `json.dump`，`ensure_ascii=False`, `indent=2` |

### 4.2 pathlib_demo.py

| 演示块 | 必须包含 |
|--------|----------|
| Path | 拼接、`suffix`、`stem`、`parent` |
| 遍历 | `iterdir`、`rglob` 过滤 `.txt`/`.md` |
| os 对照 | `os.getenv`、`os.makedirs` 与 Path 等价操作 |

### 4.3 regex_demo.py

| 演示块 | 必须包含 |
|--------|----------|
| datetime | `datetime.now()`、`strftime` |
| random | `random.choice`、`random.randint` |
| re | `search`、`findall`、`sub`；中文关键词统计示例 |

### 4.4 doc_keyword_stats.py（主工具）

#### CLI 参数

| 参数 | 短选项 | 默认 | 说明 |
|------|--------|------|------|
| `--docs-dir` | `-d` | `data/sample_docs` | 文档根目录 |
| `--keywords` | `-k` | `data/keywords.txt` | 关键词文件（每行一词） |
| `--output-dir` | `-o` | `output` | 报告输出目录 |
| `--case-sensitive` | — | `False` | 是否区分大小写 |

#### 核心函数

| 函数 | 行为 |
|------|------|
| `load_keywords(path)` | 读关键词文件，去空行、去首尾空白 |
| `iter_text_files(root)` | 递归 yield `.txt`/`.md` 的 `Path` |
| `read_document(path)` | UTF-8 读全文；失败返回 `(None, error_msg)` |
| `count_keyword(text, keyword, case_sensitive)` | `re.findall` 计数 |
| `scan_documents(docs_dir, keywords, ...)` | 返回统计 dict |
| `save_report(report, output_dir)` | 写入 `keyword_report_YYYYMMDD_HHMMSS.json` |
| `main()` | 解析参数、执行、打印摘要 |

#### 报告 JSON 结构

```json
{
  "scanned_at": "2026-08-01T15:30:00",
  "docs_dir": "data/sample_docs",
  "total_files": 4,
  "keywords": ["退款", "大模型", "工单", "星火智服"],
  "summary": {
    "退款": 5,
    "大模型": 8
  },
  "documents": [
    {
      "path": "faq_refund.txt",
      "char_count": 1200,
      "hits": {"退款": 3, "大模型": 0},
      "error": null
    }
  ]
}
```

### 4.5 样例文档内容要求

- 至少 4 个文件，扩展名覆盖 `.txt` 与 `.md`  
- 内容围绕星火智服业务：客服、退款、工单、大模型  
- 关键词「退款」「大模型」在多样例中均有命中，便于验收
