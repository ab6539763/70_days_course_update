## 1. UTF-8 BOM 与 utf-8-sig

部分 Windows 编辑器保存 UTF-8 时带 **BOM**（字节序标记 `\ufeff`），首行可能出现隐形字符：

```python
# 读带 BOM 的 UTF-8
text = path.read_text(encoding="utf-8-sig")
```

| encoding | 行为 |
|----------|------|
| `utf-8` | 严格，BOM 可能变成内容首字符 |
| `utf-8-sig` | 自动去掉 BOM |

知识库治理建议：**统一导出为无 BOM 的 UTF-8**；代码侧可防御性使用 `utf-8-sig`。

## 2. 大文件：不要一次 read()

```python
def iter_lines(path: Path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line.rstrip("\n")
```

| 文件规模 | 策略 |
|----------|------|
| < 几 MB | `read_text()` 可接受 |
| 数十 MB+ | 按行或按块迭代 |
| GB 级日志 | 倒序读、mmap（超出今日范围） |

Day 28 分块时，`TextSplitter` 常在全文字符串上操作——今日 `char_count` 帮助判断是否需流式预处理。

## 5. 正则进阶速查

### 5.1 原始字符串

```python
pattern = r"\d+"    # 推荐：反斜杠不二次转义
pattern = "\\d+"    # 等价但易错
```

### 5.2 分组与命名

```python
m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})", "2026-08-01")
if m:
    print(m.group("year"), m.group("month"))
```

### 5.3 非贪婪

```python
re.findall(r"<title>(.*?)</title>", html, re.DOTALL)
```

### 5.4 编译复用

扫描同一关键词列表时：

```python
compiled = [(kw, re.compile(re.escape(kw), re.IGNORECASE)) for kw in keywords]
for pattern in compiled:
    ...
```

200 文件 × 20 关键词时，编译一次比每次 `findall` 传字符串略快。

## 8. 安全提示

- 不要对 **不可信路径** 做 `read_text` 后 `eval`。  
- 报告 JSON 若对外展示，注意文档内 **手机号、身份证** — 用 `re.sub` 脱敏后再写入（作业 C1 预习）。  
- 遍历目录时避免跟随 **符号链接** 跳出根目录（`path.resolve().is_relative_to(root)`，Python 3.9+）。
