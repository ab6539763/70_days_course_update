# 星火智服产品使用指南

## 概述

**星火智服**是企业级智能客服与知识库平台，集成大模型问答、工单流转与质检能力。

## 大模型问答

- 支持接入多种大模型 API，统一路由与限流
- 知识库文档经 RAG 检索增强后，由大模型生成回答
- 管理员可配置大模型温度、最大 Token 等参数

## 工单系统

用户问题无法由大模型直接解决时，可一键转**工单**，分配至人工坐席。
工单状态包括：待处理、处理中、已关闭。

## 知识库维护

建议定期对 txt、md 格式制度文档做关键词统计，评估主题覆盖。
Day 28 将上线批量 Document Loader。

## 客服质检

客服对话可抽样质检，结合关键词命中报表做主题分析。
