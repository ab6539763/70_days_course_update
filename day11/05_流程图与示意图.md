## 5. 单文档处理状态机

```text
    [开始处理文件]
          │
          ▼
    read_document(path)
          │
    ┌─────┴─────┐
    │ 成功？     │
    └─┬───────┬─┘
      │否     │是
      ▼       ▼
  error≠null  对每个 keyword
  hits={}     count_keyword
  char_count=0     │
      │            ▼
      └────► 写入 documents[]
```

## 6. re.findall 计数示意

```text
文本: "大模型可处理工单，大模型需审核。"
关键词: "大模型"

re.findall(re.escape("大模型"), text)
    │
    ▼
["大模型", "大模型"]  → len = 2
```

## 7. JSON 报告结构树

```text
report
├── scanned_at: str
├── docs_dir: str
├── total_files: int
├── keywords: list[str]
├── summary: dict[str, int]
└── documents: list
    └── item
        ├── path: str
        ├── char_count: int
        ├── hits: dict[str, int]
        └── error: str | null
```

## 9. 编码决策简图

```text

       │
       ▼
  指定 encoding=utf-8 ？ ──否──► 系统默认（风险）
       │
      是
       ▼
  仍 UnicodeDecodeError？
       │
      是 ──► 记录 error，跳过（批处理）
       │
      否
       ▼

```
