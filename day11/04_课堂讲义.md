## 第一章 · 文本文件读写与 UTF-8（09:00–10:00）

### 1.1 为什么必须显式指定 encoding

```python
# ❌ 不推荐：依赖系统默认编码
with open("notes.txt") as f:
    text = f.read()

# ✅ 推荐：星火智服规范
with open("notes.txt", encoding="utf-8") as f:
    text = f.read()
```

| 环境 | 常见默认编码 | 风险 |
|------|--------------|------|
| Linux / macOS | 常接近 UTF-8 | 仍应以显式为准 |
| Windows 中文版 | 可能是 GBK | 读 UTF-8 文件乱码 |
| CI 容器 | UTF-8 | 与本地不一致时「我这能跑」 |

**业务对应**：知识库文档统一 UTF-8；读写不写 encoding = 线上偶发乱码。

### 1.2 上下文管理器 `with`

```python
with open("output/report.txt", "w", encoding="utf-8") as f:
    f.write("星火智服 · 关键词统计报告\n")
    f.write("生成时间: 2026-08-01\n")
# 此处文件已自动 close，即使 write 中途抛异常
```

| 没有 `with` | 有 `with` |
|-------------|-----------|
| 异常时可能不 `close` | 保证释放句柄 |
| 容易忘关文件 | 代码更短 |

`with` 背后是 **上下文协议**：`__enter__` 返回资源，`__exit__` 负责清理（Day 9 魔术方法已预告）。

### 1.3 读写的常见模式

```python
# 一次读完
text = path.read_text(encoding="utf-8")

# 按行迭代（大文件更省内存）
with open(path, encoding="utf-8") as f:
    for line in f:
        process(line.rstrip("\n"))

# 写入
path.write_text("你好，星火智服", encoding="utf-8")
```

## 第二章 · CSV 与 JSON 文件 IO（10:00–10:30）

### 2.1 CSV：表格型数据

```python
import csv

# 读取
with open("data/sample_contacts.csv", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], row["phone"])

# 写入
rows = [{"name": "陈晓", "phone": "13800138001"}]
with open("output/contacts_out.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "phone"])
    writer.writeheader()
    writer.writerows(rows)
```

> **`newline=""`**：Python 文档要求，避免 Windows 下多余空行。与 `encoding` 是两回事。

### 2.2 JSON：结构化配置与报告

```python
import json

# 读取
with open("data/sample_config.json", encoding="utf-8") as f:
    config = json.load(f)

# 写入（中文不转义为 \uXXXX）
with open("output/config_out.json", "w", encoding="utf-8") as f:
    json.dump(config, f, ensure_ascii=False, indent=2)
```

| 参数 | 作用 |
|------|------|
| `ensure_ascii=False` | 中文直接写入文件 |
| `indent=2` | 人类可读缩进 |
| `json.load` vs `loads` | 文件 vs 字符串 |

Day 10 `sparktech.load_json_file` 内部即 `read_text` + `json.loads`；今日掌握 **手写版** 便于定制错误处理。

## 第三章 · os 与 pathlib（10:30–12:00）

### 3.1 为何推荐 pathlib

```python
from pathlib import Path

root = Path("data/sample_docs")
file_path = root / "faq_refund.txt"   # 跨平台拼接

print(file_path.suffix)    # .txt
print(file_path.stem)      # faq_refund
print(file_path.parent)    # data/sample_docs
print(file_path.exists())
```

| `os.path` 老写法 | `pathlib` 新写法 |
|------------------|------------------|
| `os.path.join(a, b)` | `Path(a) / b` |
| `os.path.exists(p)` | `Path(p).exists()` |
| `os.path.splitext(p)` | `p.suffix`, `p.stem` |

公司新代码规范：**优先 pathlib**；`os.getenv`、`os.makedirs` 仍常用。

### 3.2 遍历目录

```python
def iter_text_files(root: Path):
    for path in sorted(root.rglob("*")):
        if path.is_file() and path.suffix.lower() in {".txt", ".md"}:
            yield path
```

| 方法 | 范围 |
|------|------|
| `iterdir()` | 仅当前层 |
| `rglob("*.txt")` | 递归所有子目录 |
| `glob("*.md")` | 当前层匹配 |

### 3.3 os 仍有用的地方

```python
import os

os.makedirs("output", exist_ok=True)  # 等价 Path("output").mkdir(parents=True, exist_ok=True)
api_key = os.getenv("SPARKTECH_API_KEY", "")
```

### 4.3 re 正则入门

```python
import re

text = "星火智服支持大模型问答，大模型工单可转人工。"

# 查找所有子串
hits = re.findall(re.escape("大模型"), text)
print(len(hits))  # 2

# 忽略大小写（英文）
re.findall("rag", text, re.IGNORECASE)

# 替换（脱敏预习）
masked = re.sub(r"\d{11}", "***PHONE***", "手机 13800138001")
```

| 函数 | 作用 |
|------|------|
| `re.search` | 找第一个匹配 |
| `re.findall` | 找所有非重叠匹配 |
| `re.sub` | 替换 |
| `re.escape` | 关键词字面量安全 |

**讲师强调**：今日统计 = **子串计数**；不是 NLP 分词。`re.escape("退款")` 即可。

## 第六章 · 常见踩坑

### 6.1 UnicodeDecodeError

```text
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0
```

**原因**：文件非 UTF-8（如 GBK、带 BOM 处理不当）。  
**今日策略**：记录 `error`，继续下一文件。  
**进阶**：补充讲义 `utf-8-sig` 与 `chardet`。

### 6.2 路径写死反斜杠

```python
# ❌
path = "data\\sample_docs\\a.txt"

# ✅
path = Path("data") / "sample_docs" / "a.txt"
```

### 6.3 json.dump 中文变 \u

忘记 `ensure_ascii=False` 时，刘姐打开 JSON 满屏 `\u9000\u6b3e`。

### 6.4 关键词含正则元字符

搜索 `C++` 或 `价格(元)` 时必须 `re.escape`。

## 附录 · 自检答案

1. **默认 encoding**：Windows 中文环境常见 GBK，与 UTF-8 文件不兼容。  
2. **`read_text` vs `with open`**：小文件 `read_text` 简洁；大文件或逐行处理用 `with` 迭代。  
3. **`re.escape`**：防止关键词中的正则特殊字符被误解析。
