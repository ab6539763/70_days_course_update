# Day 49 需求文档 · API 与 Human-in-the-loop

## 1. API 契约

### POST /api/tasks

**Body**

```json
{
  "request": "请起草退款说明邮件",
  "thread_id": "optional-uuid"
}
```

**Response**：`thread_id`, `status`, `pending_approval`（若中断）

### GET /api/tasks/{thread_id}

返回完整 `steps`, `plan`, `pending_approval`, `result`

### POST /api/tasks/{thread_id}/resume

```json
{
  "approval": {
    "decision": "approve",
    "comment": "已核对收件人"
  }
}
```

### GET /api/health

返回 `agents[]`, `tools[]`, `mode`

## 2. 状态机

| status | 含义 |
|--------|------|
| started | 初始 |
| planned | Planner 完成 |
| researched | Researcher 完成 |
| awaiting_approval | interrupt 等待 |
| approved | 用户批准（瞬时） |
| completed | Executor 完成 |
| rejected | 用户拒绝 |

## 3. interrupt 恢复

- 使用 `MemorySaver` checkpointer（教学默认）  
- `configurable.thread_id` 与 API `thread_id` 一致  
- resume payload：`{"decision": "approve"|"reject", "comment": "..."}`  

## 4. 前端需求（简易）

- 任务输入框 + 提交  
- steps 时间线  
- 审批区：preview JSON + 批准/拒绝 + 备注  
- 结果区 JSON
