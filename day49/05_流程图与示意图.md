## 2. interrupt / resume 时序

```mermaid
sequenceDiagram
    participant C as Client
    participant API as FastAPI
    participant G as LangGraph
    participant H as Human

    C->>API: POST /api/tasks
    API->>G: invoke(initial)
    G->>G: planner→researcher→writer
    G-->>API: awaiting_approval
    API-->>C: pending_approval
    H->>C: 审阅预览
    C->>API: POST /resume approve
    API->>G: Command(resume)
    G->>G: executor
    G-->>API: completed
    API-->>C: result
```

## 3. API 路由图

