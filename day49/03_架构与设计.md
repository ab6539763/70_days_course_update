# Day 49 架构与设计 · LangGraph + FastAPI

## 1. Graph 拓扑

```python
planner → researcher → writer → human_gate → (approve?) → executor → END
                              ↘ reject → END
```

`human_gate_node` 内：

```python
decision = interrupt({...})
if decision["decision"] != "approve":
    return {"status": "rejected", ...}
```

`route_after_gate` 条件边：`approve → executor`，否则 `END`。

## 2. OfficeGraphService

| 方法 | 作用 |
|------|------|
| `start_task(request, thread_id?)` | `graph.invoke(initial)` |

## 5. 任务中断恢复

| 场景 | 行为 |
|------|------|
