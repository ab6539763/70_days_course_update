## 1. 目标

1. **技术迁移**：用 LangChain `ChatModel` + `ChatPromptTemplate` 重写 Day 14 CLI。  
2. **行为兼容**：`/help` `/clear` `/save` `/exit` 与 JSON 会话格式保持一致。  
3. **mock 优先**：无 `OPENAI_API_KEY` 时使用 `FakeListChatModel`。  
4. **教学覆盖**：`PromptTemplate`、`ChatPromptTemplate`、`MessagesPlaceholder`。

## 4. 功能需求

### 4.1 mock_llm.py

| 函数 | 说明 |
|------|------|
| `is_mock_mode()` | `SPARKTECH_MOCK=1` 或无 Key → True |
| `build_chat_model()` | mock → `FakeListChatModel`；live → `ChatOpenAI` |
| `mock_reply_for_user()` | 与 Day 14 mock 文案风格一致 |

### 4.2 prompt_templates_lc.py

| 组件 | 说明 |
|------|------|
| `PromptTemplate` | 单字符串模板（翻译示例） |
| `ChatPromptTemplate` | system + `MessagesPlaceholder` + human |
| `DEFAULT_SYSTEM_PROMPT` | 与 Day 14 system 对齐 |

### 4.3 langchain_chat.py

| 功能 | 验收 |
|------|------|
| REPL 主循环 | 支持多轮对话 |
| `/help` | 打印命令帮助 |
| `/clear` | 清空历史，保留 system |
| `/save` | 写入 `data/sessions/*.json` |
| `/exit` | 正常退出 |
| `build_chat_chain()` | `prompt \| llm` 组合 |

### 4.4 会话 JSON 格式

与 Day 14 兼容：

```json
{
  "session_id": "abc123",
  "title": "未命名会话",
  "created_at": "...",
  "updated_at": "...",
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ]
}
```

## 5. 非功能需求

- Python 3.10+  
- 依赖见 `requirements.txt`（langchain 0.3.x）  
- 代码注释使用中文  
- 禁止在 mock 模式调用外部 API  

## 6. 验收脚本

`verify_day25.py` 必须覆盖：

1. `is_mock_mode()` 为 True  
2. `PromptTemplate` / `ChatPromptTemplate` 格式化  
3. `LangChainSession` clear/history  
4. `run_turn` 链式调用  
5. `save_session` 写 JSON
