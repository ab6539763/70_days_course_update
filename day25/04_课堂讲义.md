## 第一章 · LangChain 是什么（09:00–09:45）

### 1.1 定位

LangChain 是 **LLM 应用开发框架**，提供：

| 能力 | 说明 |
|------|------|
| 模型抽象 | `ChatModel` 统一 invoke/stream |
| Prompt 管理 | 模板化、可组合 |
| LCEL | `|` 管道声明式链（Day 26） |
| Memory | 多轮历史（Day 27） |
| 集成 | RAG、Agent、Tools（后续周） |

### 1.2 包结构（0.3.x）

```bash
pip install langchain langchain-core langchain-community langchain-openai
```

- **langchain-core**：核心抽象，版本最稳定  
- **langchain-community**：FakeListChatModel、各类 History  
- **langchain-openai**：`ChatOpenAI`  

### 1.3 与 Day 14 的关系

打开 [Day 14 project1/llm_client.py](../day14/project1/llm_client.py) 与 [code/mock_llm.py](./code/mock_llm.py) 对照：

- Day 14：`client.chat(list[dict])`  
- Day 25：`llm.invoke(list[BaseMessage])`  

消息结构本质相同，LangChain 用 **类型化 Message** 替代裸 dict。

```python
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage

messages = [
    SystemMessage(content="你是助手"),
```

### 2.2 FakeListChatModel

```python
from langchain_community.chat_models.fake import FakeListChatModel

llm = FakeListChatModel(responses=["回复一", "回复二"])
result = llm.invoke([HumanMessage(content="任意输入")])
```

## 第三章 · PromptTemplate（10:30–11:15）

打开 [code/prompt_templates_lc.py](./code/prompt_templates_lc.py)。

### 3.1 字符串模板 PromptTemplate

适用于 **单轮、非对话** 任务：

```python
from langchain_core.prompts import PromptTemplate

tpl = PromptTemplate(
    input_variables=["product", "language"],
    template="将 {product} 翻译为{language}：",
)
text = tpl.format(product="星火智服", language="英文")
```

### 3.2 ChatPromptTemplate

适用于 **多轮对话**：

```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是星火智服助手"),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{user_input}"),
])

msgs = prompt.format_messages(
    user_input="LangChain 是什么？",
    history=[HumanMessage(content="hi"), AIMessage(content="hello")],
)
```

## 第四章 · 重写 Day 14 CLI（14:00–16:00）

### 4.1 核心链

[code/langchain_chat.py](./code/langchain_chat.py)：

```python
def build_chat_chain():
    prompt = build_chat_prompt()
    llm = build_chat_model()
    return RunnableLambda(_inject_history) | prompt | llm
```

今日尚未使用 `StrOutputParser`（Day 26 引入）；`invoke` 返回 `AIMessage`，取 `.content` 即可。

### 4.2 会话管理 LangChainSession

- `history` 属性：供 `MessagesPlaceholder` 使用（不含 system）  
- `clear(keep_system=True)`：对齐 Day 14  
- `to_dict()` / `save_session()`：JSON 兼容
