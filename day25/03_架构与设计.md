## 4. Prompt 设计

```python
ChatPromptTemplate.from_messages([
    ("system", DEFAULT_SYSTEM_PROMPT),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{user_input}"),
])
```

**设计理由**：

- `system`：全局角色，clear 时保留  
- `history`：多轮 Human/AI 消息，对应 Day 14 `to_api_messages()` 除最后 user 外部分  
- `human`：当前轮用户输入  

## 5. 数据流（单轮对话）

```text
用户输入 "你好"
    → session.add_user()
    → chain.invoke({user_input, history})
        → ChatPromptTemplate.format_messages()
        → ChatModel.invoke(messages)
    → session.add_assistant(reply)
    → 打印 "助手> ..."
```

## 6. Mock 策略

| 条件 | 行为 |
|------|------|
| 无 `OPENAI_API_KEY` | `FakeListChatModel` |
| `SPARKTECH_MOCK=1` | 强制 mock |
| mock 模式 | `mock_reply_for_user()` 增强上下文文案 |

**说明**：`FakeListChatModel` 按预设列表循环返回，不解析 history；课堂用 `mock_reply_for_user` 模拟 Day 14 体验，Day 26+ 将用 LCEL 统一处理。
