## 1. 目标

1. **教学完整**：覆盖 NLP 简史、Transformer 类比、预训练/SFT/RLHF、Token、tiktoken、模型格局。  
2. **可计量**：提供 `tiktoken_demo.py` 与 `token_cost_estimator.py` 实操工具。  
3. **商务可用**：输出 JSON 成本表，可直接贴入星火智服立项材料。  
4. **无 Key 可跑**：mock 模式用本地分词 + 固定单价表，CI 零配置验收。

## 4. 功能需求

### 4.1 tiktoken_demo.py

| 符号 | 行为 |
|------|------|
| `count_tokens(text, encoding)` | 返回 Token 数与编码名 |
| `demo_compare_languages()` | 中英同样主题句子对比 Token |
| `demo_messages()` | 模拟 `messages` 列表累计 Token |
| 降级 | 未安装 tiktoken 时用 `len(text)//4` 估算并打印警告 |

### 4.2 token_cost_estimator.py

| 符号 | 行为 |
|------|------|
| CLI `--scenario` | 读取方案文本文件 |
| CLI `--daily-requests` | 日均请求次数，默认 500 |
| CLI `--output-tokens` | 假设单次输出 Token，默认 300 |
| `estimate_cost()` | 返回 dict：input_tokens, output_tokens, models[] |
| 输出 | `output/cost_estimate_*.json` |
| mock/live | live 模式可选调用 Day 13 客户端对比 usage |

### 4.3 model_landscape_quiz.md

| 内容 | 要求 |
|------|------|
| 选择题 ≥ 8 道 | 覆盖 GPT/Claude/DeepSeek/开源 |
| 简答题 ≥ 2 道 | 预训练 vs SFT、Token 计费原因 |
| 答案区 | 文末折叠或独立章节 |

### 4.4 llm_compat.py

| 符号 | 行为 |
|------|------|
| `get_llm_client()` | 优先 Day 13 `ResilientLLMClient`，回退 Day 12 `LLMClient` |
| `CLIENT_SOURCE` | 字符串标明导入来源路径 |
| mock | 无 Key 时不发起 HTTP |

## 5. 非功能需求

| 项 | 要求 |
|----|------|
| 注释 | 全部 demo 脚本含详细中文注释 |
| 编码 | UTF-8，中文输出 `ensure_ascii=False` |
| 依赖 | `tiktoken`, `requests`, `python-dotenv` |
| 安全 | 不硬编码 API Key |

## 6. 验收标准

```bash
cd day15/code
python3 tiktoken_demo.py
python3 token_cost_estimator.py --scenario data/xinghuo_proposal.txt
python3 verify_day15.py
```

- 全部命令 exit code 0  
- `verify_day15.py` 输出 ≥ 5 条 `[OK]`  
- JSON 报告含 `models` 数组，每项含 `monthly_cost_cny` 或 `monthly_cost_usd`
