# 星火智服二期 · 智能客服 API 成本测算场景（样例）

## 背景
产品部拟在现有工单系统上增加「智能客服助手」，支持多轮问答、工单摘要与知识库检索增强（RAG）。

## 典型单次请求构成
1. 系统提示词（约 800 字）：角色定义、合规话术、拒答规则
2. 检索片段（Top-5，每段约 300 字）：来自制度文档与 FAQ
3. 用户问题（约 50–200 字）
4. 历史对话（最多 3 轮）

## 假设
- 试点阶段日均 500 次对话请求
- 全量阶段日均 2000 次
- 平均输出回复 300 Token（约 450 汉字）

## 示例用户问题
「你好，我上周提交的退款工单 #A8821 为什么还没到账？请根据退款政策说明处理时效。」

## 系统提示词摘要
你是星火智服官方客服助手。回答须基于检索到的知识库片段，不得编造政策。若信息不足，引导用户提交工单并给出链接。语气专业、简洁，禁止使用夸张承诺。

## 检索片段示例标题
- 《退款与退货管理办法》第 4.2 节
- 《工单 SLA 时效说明》
- 《常见问题：退款到账周期》
