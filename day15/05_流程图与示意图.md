## 2. Transformer 解码一步

```text
已有 Token:  [你] [好] [，] [请]
                │
                ▼
        ┌───────────────┐
        │ Self-Attention │  每个位置「看向」全文
        └───────┬───────┘
                ▼
        ┌───────────────┐
        │ 预测下一 Token │  概率最高可能是「问」
        └───────┬───────┘
                ▼
        采样/贪心 → 输出「问」→ 继续自回归
```

## 6. 中英文 Token 差异示意

```text
英文: "Hello, SparkTech support"     → 约 5–6 tokens
中文: "你好，星火智服客服"            → 约 8–12 tokens（视编码）
混合: "星火智服 SparkTech FAQ"       → 分别按子词切分

结论：立项书不能按「字数」估算，必须 tiktoken 或 API usage
```
