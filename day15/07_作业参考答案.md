### A1. token_compare.py（节选）

```python
import tiktoken

PAIRS = [
    ("你好，我想查询工单状态。", "Hello, I want to check my ticket status."),
    ("星火智服支持退款吗？", "Does SparkTech support refunds?"),
    ("请用三句话介绍大模型。", "Introduce LLMs in three sentences."),
]

def main() -> None:
    enc = tiktoken.encoding_for_model("gpt-4o-mini")
    print(f"{'句子':<40} {'字符':>6} {'Token':>8} {'比':>8}")
    for zh, en in PAIRS:
        for label, text in [("中", zh), ("英", en)]:
            n_tok = len(enc.encode(text))
            n_char = len(text)
            ratio = n_tok / n_char if n_char else 0
            print(f"{label}:{text[:18]:<38} {n_char:>6} {n_tok:>8} {ratio:>8.3f}")

if __name__ == "__main__":
    main()
```

**讲评**：中文往往每字接近 1 Token；英文常见词合并，单字符比更低。

### A2. messages 累计

```python
ROLE_OVERHEAD = 4  # 教学近似

def count_messages(enc, messages: list[dict]) -> int:
    total = sum(len(enc.encode(m["content"])) for m in messages)
    return total + ROLE_OVERHEAD * len(messages)
```
