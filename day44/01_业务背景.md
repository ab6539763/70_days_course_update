### 1.2 MCP 价值

**Model Context Protocol** 把工具、资源、提示词封装为 **独立 Server**，Client（Claude Desktop、Cursor、自研 Agent）通过标准 JSON-RPC 连接。

```text
  Agent (Client)  <--MCP-->  kb_server
                          └--> ticket_server
```

张工：

> 「Function Calling 是 **模型侧协议**；MCP 是 **应用侧工具总线**。项目三办公助手的外围系统，优先 MCP 接入。」
