# Day 44 流程图与示意图

## 1. MCP 连接模型

```ascii
 +----------+    JSON-RPC     +----------------+
 | MCP      | <-------------> | MCP Server     |
 | Client   |   list_tools    | (kb + ticket)  |
 | (Agent)  |   call_tool     +----------------+
 +----------+
```

## 2. Agent 工具调用序列

```mermaid
sequenceDiagram
    participant U as User
    participant A as Agent
    participant C as MCP Client
    participant S as MCP Server
    U->>A: 工单+政策问题
    A->>A: plan_tools
    A->>C: call kb_search
    C->>S: kb_search
    S-->>C: hits JSON
    A->>C: call ticket_status
    C->>S: ticket_status
    S-->>C: status JSON
    A->>A: LLM 汇总
    A-->>U: 最终回答
```

## 3. 与项目三映射

| MCP 工具 | 项目三场景 |
|----------|------------|
| kb_search | 制度 / FAQ 检索 |
| ticket_status | 请假 / 报销单进度 |
| （扩展）calendar | 会议室预定 |
