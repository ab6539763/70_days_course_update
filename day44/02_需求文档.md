## 1. 功能需求

### 1.1 simple_mcp_server.py
- 工具 `kb_search(query)` — 返回知识库命中 JSON  
- 工具 `ticket_status(ticket_id)` — 返回工单状态 JSON  
- 优先 FastMCP；无 SDK 时 `MockMCPServer` 等价行为  
- `--stdio` 可启动 stdio 传输（需 SDK）

### 1.2 mcp_client_demo.py
- `SparkTechMCPClient.list_tools()`  
- `call(tool, **args)` 返回 `ToolCallResult`

### 1.3 agent_with_mcp.py
- `plan_tools(question)` 规则选工具  
- `run_agent_with_mcp` 返回 `AgentTrace`（steps + tool_results + answer）

### 1.4 mcp_compat.py
- `MCP_AVAILABLE` 检测  
- `MockMCPServer` 供无 SDK 环境
