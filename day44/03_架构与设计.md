## 2. MCP 协议要素（课堂版）

| 概念 | 说明 |
|------|------|
| Server | 暴露 tools / resources |
| Client | 发现工具、发起 call |
| Tool | 具名函数 + JSON Schema 参数 |
| Transport | stdio / SSE（今日 stdio 选做） |

## 3. 兼容层设计

```python
if MCP_AVAILABLE:
    # FastMCP @mcp.tool()
```
