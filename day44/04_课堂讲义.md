# Day 44 课堂讲义 · MCP 协议与 Agent 接入

## 第一章 · MCP 是什么（09:00–10:00）

- **问题**：N 个 Agent × M 个后端 = 集成爆炸  
- **解法**：工具提供方实现 MCP Server，消费方实现 MCP Client  
- **对比 Day 19**：FC 是单次 LLM 请求内的 tool_calls；MCP 是 **进程级** 工具服务

## 第二章 · 开发 MCP Server（10:00–11:30）

```bash
python3 simple_mcp_server.py
```

FastMCP 示例：

```python
mcp = FastMCP("sparktech-simple-mcp")

@mcp.tool()
def kb_search(query: str) -> str:
    ...
```

无 SDK 时：`MockMCPServer` 保持相同 `list_tools` / `call_tool` 语义。

## 第三章 · Client 调用（11:30–12:00）

```bash
python3 mcp_client_demo.py
```

`SparkTechMCPClient` 封装课堂所需的 list + call，生产可换官方 `mcp` Client Session。

## 第四章 · Agent 编排（14:00–16:00）

```bash
python3 agent_with_mcp.py
```

流程：
1. `plan_tools` 根据关键词选工具  
2. 依次 `client.call`  
3. 工具 JSON 注入 LLM prompt  
4. 生成最终回答

```bash
python3 verify_day44.py
```
