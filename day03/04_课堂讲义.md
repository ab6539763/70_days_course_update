## 第一章 · 为什么需要分支与循环

### 1.1 从 Day 1 的痛点说起

Day 1 `personal_info_card.py` 里有一段注释：「v1.0 若为空暂用占位」。为什么不好？

```python
name = input("姓名: ")
if not name:
    name = "未填写"  # 掩盖问题，OA 仍会导入脏数据
```

企业级做法：**发现不合法就让用户重输**，而不是静默填默认值。这需要：

1. **判断**输入是否合法 → `if`  
2. **重复**询问直到合法 → `while`  

张工的要求：「空姓名、非法手机号，循环里拦住，别流到数据库。」

### 1.2 从 Day 2 的 while 预习说起

Day 2 `read_multiline_input()` 已经用了：

```python
while True:
    line = input()
    if line.strip().upper() == "END":
        break
    lines.append(line)
```

今天你要理解每一行的含义：`while True` 是「无限循环直到 break」；`if` 是退出条件。下午会把 `for`、`range`、`continue` 补齐。

### 1.3 与 LLM 应用的映射

| 语法 | 智服项目中的未来用法 |
|------|----------------------|
| `if/elif/else` | 路由用户消息：普通文本 vs `/命令` |
| 嵌套 `if` | 有 API Key 且余额充足才调用 |
| `while` | 多轮对话 REPL |
| `for` | 遍历 `messages`、检索到的 chunks |
| `break` | 用户 `/exit`、达到 max_tokens 停止 |
| `continue` | 跳过空行、跳过已删除会话 |

## 第二章 · if / elif / else 基础

### 2.1 布尔值与条件表达式

条件可以是：

- 比较运算：`score >= 60`、`name == ""`  
- 成员运算：`"y" in ("y", "yes")`  
- 逻辑组合：`age >= 18 and has_id`  

```python
score = 75
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

**执行规则**：自上而下，**第一个为真的分支**执行后，其余 `elif/else` **跳过**。

### 2.2 缩进是语法的一部分

Python 用缩进（通常 4 空格）表示块，**不要混用 Tab 和空格**。

```python
if guess == secret:
    print("猜对了")      # 属于 if 块
    attempts += 1
print("本局结束")        # 与 if 同级，总会执行
```

### 2.3 三元表达式（简洁赋值）

```python
label = "及格" if score >= 60 else "不及格"
```

适合简单二选一；复杂逻辑仍用多行 `if`。

### 2.4 猜数字中的三分支

```python
if guess < secret:
    print("太小了，再试试")
elif guess > secret:
    print("太大了，再试试")
else:
    print(f"恭喜！{guess} 就是答案")
    break
```

注意：`else` 对应「既不小于也不大于」→ 相等。不要写成三个独立 `if`，否则猜中时可能三个分支都误判（若用 `<` `>` 单独 if 则 else 仍安全，但 `elif` 链更清晰）。

### 2.5 真值测试（Truthiness）

以下在 `if` 中视为 **False**：

- `False`、`None`、数值 `0`、`0.0`  
- 空串 `""`、空容器 `[]`、`{}`、`()`  

```python
name = input("姓名: ").strip()
if not name:
    print("不能为空")
```

`if not name` 比 `if name == ""` 更 Pythonic。

## 第三章 · 嵌套条件

### 3.1 何时需要嵌套

当判断依赖**多个维度**时，一层 `if` 不够：

```python
score = 55
makeup = 62

if score >= 60:
    print("初试及格")
else:
    if makeup >= 60:
        print("初试不及格，但补考及格")
    else:
        print("仍需重修")
```

### 3.2 扁平化：用 and / or 减少嵌套

```python
if score >= 60:
    print("初试及格")
elif makeup >= 60:
    print("补考及格")
else:
    print("仍需重修")
```

能扁平就扁平——嵌套超过 3 层可读性急剧下降。

### 3.3 业务案例 · 菜单权限

预埋 Day 14 思路：

```python
raw = input(">>> ").strip()

if raw.startswith("/"):
    if raw == "/exit":
        break
    elif raw == "/clear":
        clear_screen()
    else:
        print("未知命令")
else:
    if raw == "1":
        run_guess_game()
    elif raw == "2":
        run_table()
```

外层：是否命令；内层：具体命令。**先判断大类，再判断细项**。

### 3.4 常见错误

| 现象 | 原因 | 修复 |
|------|------|------|
| 两个分支都执行 | 写了两个 `if` 而非 `elif` | 改用 `elif` |
| 永远进不了分支 | 比较错类型 `"5" == 5` | 先 `int()` |
| IndentationError | 缩进不一致 | 全文件 4 空格 |

## 第四章 · while 循环

### 4.1 基本形式

```python
while 条件:
    循环体
```

条件为 `True` 时重复；为 `False` 时退出。若条件恒真，需体内 `break`，否则死循环。

### 4.2 计数循环 vs 条件循环

**计数型**（次数明确）：

```python
attempt = 0
while attempt < 7:
    # ...
    attempt += 1
```

**条件型**（直到猜中）：

```python
while True:
    guess = read_int()
    if guess == secret:
        break
```

猜数字可结合二者：最多 7 次，猜中提前 `break`。

### 4.3 while-else（进阶）

```python
n = 0
while n < 3:
    print(n)
    n += 1
else:
    print("正常结束，未 break")
```

若 `break` 跳出，`else` **不执行**。猜数字里可用 `else` 表示「次数用尽仍未中」。

```python
for attempt in range(1, max_attempts + 1):
    guess = read_valid_int()
    if guess == secret:
        print("猜中了")
        break
else:
    print(f"次数用尽，答案是 {secret}")
```

（`for-else` 与 `while-else` 语义相同，今日九九表用 `for` 更自然。）

### 4.4 修复 Day 1 空输入

```python
def read_non_empty(prompt: str) -> str:
    """直到用户输入非空字符串。"""
    while True:
        value = input(prompt).strip()
        if value:
            return value
        print("输入不能为空，请重试。")
```

### 4.5 死循环排查

症状：程序卡住不动。检查：

1. 条件是否永远为真且无 `break`  
2. `continue` 是否跳过递增变量  
3. 是否等待 `input` 而你没注意到终端

## 第五章 · for 循环与 range

### 5.1 for 遍历序列

```python
departments = ["研发", "产品", "HR"]
for dept in departments:
    print(f"欢迎 {dept} 同事")
```

Day 4 会遍历 `list` 待办；Day 14 会遍历 `messages`。

### 5.2 range 详解

`range(stop)` → `0 .. stop-1`  
`range(start, stop)` → `start .. stop-1`  
`range(start, stop, step)` → 步长  

```python
list(range(5))        # [0, 1, 2, 3, 4]
list(range(1, 10))    # [1, 2, ..., 9]
list(range(0, 10, 2))  # [0, 2, 4, 6, 8]
```

**记忆**：`range` 永远是**含头不含尾**，与切片一致。

### 5.3 九九乘法表双重循环

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{i}×{j}={i * j}", end="\t")
    print()
```

- 外层 `i`：行号  
- 内层 `j`：从 1 到 `i`，形成下三角  
- `end="\t"`：同行分隔，最后 `print()` 换行  

### 5.4 enumerate（预告）

```python
for idx, dept in enumerate(departments, start=1):
    print(f"{idx}. {dept}")
```

需要下标时优先 `enumerate`，少用手写 `range(len())`。

### 5.5 性能直觉

九九表 9×9 共 45 项，循环可忽略。日后 RAG 遍历上万 chunk 时，算法与数据结构更重要（Day 28+）。

## 第六章 · break 与 continue

### 6.1 break：立即跳出循环

```python
while True:
    cmd = input(">>> ").strip()
    if cmd == "/exit":
        print("再见")
        break
    print(f"你输入了: {cmd}")
```

### 6.2 continue：跳过本次剩余代码

```python
attempt = 0
while attempt < 7:
    raw = input("猜: ").strip()
    if not raw.isdigit():
        print("请输入整数")
        continue          # 直接回到 while 顶部，attempt 不增加
    guess = int(raw)
    attempt += 1
    # ...
```

**区别**：`continue` 是「这一轮算没发生过」；`break` 是「整个循环结束」。

### 6.3 猜数字中的组合用法

- 非法输入 → `continue`（不占次数）  
- 猜中 → `break`（结束回合）  
- 用户放弃 → 外层 `break`  

### 6.4 避免 continue 造成死循环

错误示例：

```python
while attempt < 7:
    if invalid:
        continue
    attempt += 1   # 若 invalid 永远为真，attempt 永不增加 → 死循环
```

正确：非法时 `continue` 前不递增；合法后再 `attempt += 1`。

## 第八章 · 常见错误与调试

| 现象 | 原因 | 修复 |
|------|------|------|
| `UnboundLocalError` | 循环内赋值使变量变局部 | 先初始化 |
| 猜一次就退出 | `break` 缩进在错误层级 | 对齐到 `if guess==secret` |
| 九九表不对齐 | `end` 空格数不一致 | 用 `\t` 或 `f"{x:4}"` |
| `/exit` 无效 | 未 `strip()`，带了空格 | 先 `.strip()` |
| 整数比较失败 | `input` 是 str | `int()` 转换 |

**调试习惯**：在循环内临时 `print(f"debug attempt={attempt} guess={guess}")`，Day 9 学 logging 后替换。

### 11.1 LC 1 · 两数之和（Two Sum）

**题意**：数组 `nums` 和目标 `target`，找两数下标使和为 `target`。

**思路**：暴力双重 `for` —— 今日刚学嵌套循环：

```python
for i in range(len(nums)):
    for j in range(i + 1, len(nums)):
        if nums[i] + nums[j] == target:
            return [i, j]
```

Day 5 用 `dict` 可优化到 O(n)；今日先练循环正确性。

### 11.2 LC 412 · FizzBuzz

**题意**：`1..n`，被 3 整除输出 `Fizz`，被 5 整除 `Buzz`，同时 `FizzBuzz`，否则数字。

```python
for i in range(1, n + 1):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```

**与今日关系**：`if/elif` 链 + `for` + `range`，集训热身经典题。
