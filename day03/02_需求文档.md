## 1. 目标

交付三个可独立运行、也可被主菜单调用的命令行程序，让集训讲师在终端演示分支与循环，并预埋 Day 14 斜杠命令约定。

## 2. 用户故事

| ID | 角色 | 故事 | 优先级 |
|----|------|------|--------|
| US-01 | 刘姐 | 启动猜数字，学员多轮猜测直到猜中 | P0 |
| US-02 | 培训生 | 生成标准 9×9 乘法表或指定行 | P0 |
| US-03 | 张工 | 主菜单统一入口，支持 `/clear`、`/exit` | P0 |
| US-04 | 培训生 | 空输入、非法数字有友好提示并允许重试 | P1 |
| US-05 | 培训生 | 运行 `flow_control_demo.py` 复习语法 | P1 |

## 3. 功能需求

### 3.1 猜数字游戏（guess_number.py）

| 编号 | 功能 | 规则 |
|------|------|------|
| G-01 | 随机目标 | `random.randint(1, 100)`，每局重新生成 |
| G-02 | 回合循环 | `while` 直到猜中或达到最大次数（默认 7 次） |
| G-03 | 大小提示 | 猜错输出「太大了」/「太小了」 |
| G-04 | 输入校验 | 非整数提示重试，不计入次数（`continue`） |
| G-05 | 再来一局 | 结束后询问，用 `break` 退出外层循环 |

### 3.2 九九乘法表（multiplication_table.py）

| 编号 | 功能 | 规则 |
|------|------|------|
| M-01 | 标准表 | 双重 `for`，`i` 从 1 到 9，`j` 从 1 到 `i` |
| M-02 | 指定行 | 输入 `n`，只打印第 `n` 行（1≤n≤9） |
| M-03 | 对齐 | 使用 `f-string` 宽度对齐，列整齐 |
| M-04 | 菜单 | 1=全表 2=指定行 0=退出 |

### 3.3 主菜单壳（simple_menu.py）

| 编号 | 功能 | 规则 |
|------|------|------|
| S-01 | 数字菜单 | 1 猜数字 2 九九表 3 流程演示 4 帮助 |
| S-02 | `/exit` | 任意时刻输入，立即退出程序 |
| S-03 | `/clear` | 打印清屏序列（终端 `\033[2J\033[H` 或换行占位） |
| S-04 | `/help` | 列出可用命令与菜单项 |
| S-05 | 未知命令 | 提示「未知命令，输入 /help」 |

### 3.4 流程演示（flow_control_demo.py）

分四段演示，每段 `input` 继续：

1. `if/elif/else` 与嵌套条件（成绩等级）  
2. `while` 空输入重试（模拟 Day 1 姓名）  
3. `for` + `range` 遍历  
4. `break` / `continue` 对比  

## 4. 非功能需求

- Python 3.10+，标准库（`random` 即可）  
- 单文件可运行：`python3 guess_number.py`  
- 函数 ≤40 行，关键循环带中文注释  
- 命令前缀 `/` 与 Day 14 PRD 保持一致  

## 5. 验收标准

| 编号 | 条件 |
|------|------|
| AC-01 | 猜数字 7 次内可结束，非法输入不扣次数 |
| AC-02 | 九九表第 5 行格式：`5×1=5  5×2=10 ...` |
| AC-03 | `simple_menu.py` 识别 `/exit`、`/clear`、`/help` |
| AC-04 | 主菜单选 1/2 可进入子功能（子进程或函数调用均可） |
| AC-05 | `flow_control_demo.py` 四段均可运行 |
| AC-06 | 代码注释说明与 Day 14 的衔接点 |
