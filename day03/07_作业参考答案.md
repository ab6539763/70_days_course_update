## B1 grade_hw.py

```python
def read_score() -> int:
    while True:
        raw = input("成绩 (0-100): ").strip()
        if not raw.isdigit():
            print("请输入整数")
            continue
        score = int(raw)
        if 0 <= score <= 100:
            return score
        print("超出范围")


def grade(score: int) -> str:
    if score >= 90:
        return "A"
    if score >= 80:
        return "B"
    if score >= 60:
        return "C"
    return "D"


def main() -> None:
    s = read_score()
    print(f"等级：{grade(s)}")


if __name__ == "__main__":
    main()
```

## B2 read_nonempty.py

```python
def read_nonempty(prompt: str) -> str:
    while True:
        value = input(prompt).strip()
        if value:
            return value
        print("输入不能为空，请重试。")


def main() -> None:
    name = read_nonempty("姓名: ")
    print(f"你好，{name}！")


if __name__ == "__main__":
    main()
```

## B6 Two Sum 暴力

```python
def two_sum(nums: list[int], target: int) -> list[int]:
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
    return []
```

复杂度 O(n²)；Day 5 哈希表 O(n)。

## C2 菱形（n=3）

```python
n = int(input("行数(半高): "))
for i in range(1, n + 1):
    print(" " * (n - i) + "*" * (2 * i - 1))
for i in range(n - 1, 0, -1):
    print(" " * (n - i) + "*" * (2 * i - 1))
```

## 讲评要点

1. `elif` 链顺序必须从大到小（先 90 再 60），否则逻辑错误  
2. `continue` 前不要 `attempt += 1`  
3. `/` 命令建议统一 `lower()` 比较：`raw.lower() == "/exit"`  
4. 列表 `guesses` 作业可先不判空，Day 4 再规范
