### 离线提示条

`index.html` 增加：

```html
<div id="offline-banner" class="offline-banner hidden" role="alert">
  后端未连接，请运行 <code>bash run.sh</code>
</div>
```

`app.js`：

```javascript
async function checkHealth() {
  const banner = document.getElementById('offline-banner');
  try {
    const res = await fetch(`${API_BASE}/health`);
    if (!res.ok) throw new Error('bad status');
    banner.classList.add('hidden');
    // ...原有徽章逻辑
  } catch {
    banner.classList.remove('hidden');
    setStatusBadge('后端离线', 'offline');
  }
}
```

## A3. 会话导出

```javascript
async function exportSession() {
  const res = await fetch(
    `${API_BASE}/api/sessions/${encodeURIComponent(sessionId)}/history`
  );
  const data = await res.json();
  const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = `xinghuo-chat-${sessionId}.json`;
  a.click();
  URL.revokeObjectURL(a.href);
}
```

## B1. 会话列表 API（后端草图）

`chat.py`：

```python
@router.get("/sessions")
def list_sessions(db: Session = Depends(get_db)) -> list[dict]:
    rows = db.query(ChatSession).order_by(ChatSession.updated_at.desc()).all()
    result = []
    for s in rows:
        count = db.query(ChatMessage).filter(ChatMessage.session_id == s.id).count()
        result.append({"session_id": s.id, "title": s.title, "message_count": count})
    return result
```

前端切换 session 时更新 `localStorage` 并 `location.reload()` 或重新 `loadHistory()`。
