## 1. 产品概述

构建星火智服 **Web 对话演示**，对接 FastAPI 后端，支持 SSE 流式回复与 SQLite 会话持久化，用于客户现场演示。

## 2. 用户故事

| ID | 角色 | 故事 | 验收 |
|----|------|------|------|
| US-01 | 客户 | 输入问题后看到逐字回复 | 首字 < 1s（mock） |
| US-02 | 客户 | 刷新页面后看到之前对话 | 历史 API 加载 |
| US-03 | 销售 | 无 API Key 也能稳定演示 | mock 模式 |
| US-04 | IT | 跨域调用 API | CORS 配置 |
| US-05 | 开发 | 一键启动前后端 | `run.sh` |

## 3. 功能需求

### 3.1 P0（必须）

| 编号 | 功能 | 说明 |
|------|------|------|
| F-01 | SSE 流式聊天 | `POST /api/chat/stream`，`Content-Type: text/event-stream` |
| F-02 | 非流式聊天 | `POST /api/chat`，JSON 完整回复 |
| F-03 | 会话历史 | `GET /api/sessions/{session_id}/history` |
| F-04 | 清空会话 | `DELETE /api/sessions/{session_id}` |
| F-05 | SQLite 持久化 | 每条 user/assistant 消息入库 |
| F-06 | session_id | 请求体必传，前端 localStorage 持久化 |
| F-07 | CORS | 允许前端源 `http://127.0.0.1:8080` |
| F-08 | mock 模式 | 无 Key 时关键词路由（天气/订单/问候） |
| F-09 | 前端流式 UI | delta 实时追加 assistant 气泡 |
| F-10 | 健康检查 | `GET /health` 返回 `mode` |

### 3.2 P1（作业）

| 编号 | 功能 | 说明 |
|------|------|------|
| F-11 | live 模式 | 配置 `OPENAI_API_KEY` 后真实流式 |

## 4. API 契约

### 4.1 流式请求

```http
POST /api/chat/stream
Content-Type: application/json

{
  "message": "上海天气",
  "session_id": "web-demo-001",
  "stream": true
}
```

### 4.2 SSE 事件格式

```text
data: {"event":"delta","delta":"上海","session_id":"web-demo-001","mode":"mock"}

data: {"event":"done","delta":"","session_id":"web-demo-001","mode":"mock","tools_used":["get_weather"],"message_id":42}
```

### 4.3 错误事件

```text
data: {"event":"error","error":"LLM 调用失败","session_id":"web-demo-001"}
```

## 5. 数据模型

### chat_sessions

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(64) PK | session_id |
| title | VARCHAR(200) | 会话标题 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### chat_messages

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增 |
| session_id | VARCHAR(64) FK | 所属会话 |
| role | VARCHAR(20) | user / assistant |
| content | TEXT | 消息正文 |
| tools_used | TEXT | JSON 数组，可空 |
| created_at | DATETIME | 创建时间 |

## 6. 非功能需求

| 项 | 要求 |
|----|------|
| 性能 | mock 流式 chunk 间隔 30–50ms |
| 安全 | 不硬编码 API Key；`.env.example` 无真实密钥 |
| 可测 | `verify_day24.py` 无 Key 全通过 |
| 兼容 | Python 3.10+；现代浏览器 fetch SSE |

## 7. 不在范围

- WebSocket 双向通道
- 生产部署与 HTTPS
- 多模态图片上传
