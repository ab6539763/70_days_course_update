## 3. 与大模型开发的隐性联系

| 今日知识点 | 日后场景 |
|------------|----------|
| SSE `data:` 行协议 | OpenAI `stream=True` 同款体验 |
| `session_id` 会话 | 多用户客服、工单关联 |
| SQLite 消息表 | 轻量 PoC；生产可换 PostgreSQL |
| CORS | 前后端分离部署必备 |
| mock 流式分块 | 无外网彩排、CI 自动化 |

## 4. 今日学习目标（业务语言）

完成今日学习后，你应能向非技术同事解释：

1. **为什么用 SSE 而不是 WebSocket** —— 单向推流足够，实现更简单  
2. **消息存在哪** —— `day24/data/chat_history.db`  
3. **没 API Key 怎么演示** —— `SPARKTECH_MOCK=1` 关键词路由  
4. **前端怎么一个字一个字显示** —— 读 SSE delta 追加到 DOM  

## 5. 风险与应对

| 风险 | 应对 |
|------|------|
| CORS 报错 | 检查 `CORS_ORIGINS` 含前端端口 8080 |
| SSE 被 Nginx 缓冲 | 响应头 `X-Accel-Buffering: no` |
| 刷新无历史 | 确认 `session_id` 与 DB 中一致 |
| 流式卡住 | mock 模式检查 `stream_chat` 是否 yield |
