## 第一章 · SSE 服务端（09:00–10:30）

### 1.1 什么是 SSE

Server-Sent Events：服务器向浏览器 **单向** 推送文本事件。

| 对比 | SSE | WebSocket |
|------|-----|-----------|
| 方向 | 服务器 → 客户端 | 双向 |
| 协议 | 普通 HTTP | 升级协议 |
| 适用 | LLM 流式输出 | 实时游戏、协作编辑 |
| 实现难度 | 低 | 中 |

响应头：

```http
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive
```

每条消息格式：

```text
data: {"event":"delta","delta":"你"}

```

（注意：`data:` 后有一个空格，消息以 `\n\n` 结束。）

### 1.2 FastAPI StreamingResponse

打开 [backend/chat.py](./backend/chat.py)：

```python
@router.post("/chat/stream")
def chat_stream(body: ChatRequest, db: Session = Depends(get_db), ...) -> StreamingResponse:
    def event_generator() -> Iterator[str]:
        for chunk in llm.stream_chat(history, user_message):
            event = StreamDeltaEvent(event="delta", delta=chunk, ...)
            yield f"data: {event.model_dump_json()}\n\n"
        # done 事件 + 写 DB
        yield f"data: {done_event.model_dump_json()}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream", headers={...})
```

**要点**：

1. 使用 **同步生成器** + `time.sleep` mock 延迟（教学场景可接受）  
2. `done` 事件携带 `message_id`，便于前端调试  
3. `X-Accel-Buffering: no` 防止反向代理缓冲  

### 1.3 mock 分块 yield

## 第二章 · CORS 与跨域（10:30–11:00）

### 2.1 为何需要 CORS

前端 `http://127.0.0.1:8080` 调用后端 `http://127.0.0.1:8000` 属于 **跨源**。  
浏览器会先发 `OPTIONS` 预检，后端必须返回允许头。

### 2.2 FastAPI 配置

[backend/main.py](./backend/main.py)：

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=_parse_cors_origins(),
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 2.3 排错清单

| 现象 | 检查 |
|------|------|
| `blocked by CORS` | `CORS_ORIGINS` 是否含前端地址 |
| 预检 404 | 路由是否注册；middleware 顺序 |
| SSE 无数据 | Network 看 Response 是否 chunked |

## 第四章 · 前端 SSE 消费（14:00–15:00）

### 4.1 fetch + ReadableStream

[frontend/app.js](./frontend/app.js) 核心：

```javascript
async function fetchChatStream(message, onDelta) {
  const res = await fetch(`${API_BASE}/api/chat/stream`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message, session_id: sessionId, stream: true }),
  });
  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });
    const { events, remainder } = parseSSEBuffer(buffer);
    buffer = remainder;
    for (const evt of events) {
      if (evt.event === 'delta' && evt.delta) onDelta(evt.delta);
    }
  }
}
```

### 4.2 流式 UI

```javascript
const bubble = createStreamingBubble();
await fetchChatStream(userText, (delta) => {
  fullText += delta;
  bubble.textContent = fullText;
  scrollToBottom();
});
bubble.classList.remove('streaming');
```

与 Day 22 **本地 typewriter** 的区别：

- Day 22：拿到完整文本后前端逐字打印
