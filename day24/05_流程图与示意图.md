## 3. 单次对话状态机

```mermaid
stateDiagram-v2
    [*] --> Idle
    Idle --> Sending: 用户点击发送
    Sending --> Streaming: 收到 HTTP 200
    Streaming --> Streaming: delta 事件
    Streaming --> Done: done 事件
    Streaming --> Error: error 事件
    Done --> Idle
    Error --> Idle
```
