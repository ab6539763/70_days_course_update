## 4. 今日学习目标（业务语言）

完成今日学习后，你应能向非技术同事解释：

1. **Loader 做什么** —— 把磁盘上的 PDF/Word 等变成 AI 能处理的文本块  
2. **为什么要切块** —— 大模型上下文有限，整本书塞不进去  
3. **chunk_size 怎么选** —— 看文档类型与检索粒度，中文常从 300~500 字试起  
4. **和 Day 11 的关系** —— 同一批 `sample_docs`，今天换成 LangChain 标准接口  

## 5. 风险与应对

| 风险 | 应对 |
|------|------|
| PDF 扫描版无文字 | 教学样本用电子版；生产用 OCR |
| Word 编码乱码 | `Docx2txtLoader` + UTF-8 源文件 |
| 外网 Web 加载失败 | 默认 `BSHTMLLoader` 读本地 HTML |
| chunk 过多拖慢 embed | 调大 chunk_size 或减少 overlap |
