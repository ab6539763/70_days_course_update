## 必做 A 参考

### A1. JSONLoader 示例

```python
from langchain_community.document_loaders import JSONLoader

loader = JSONLoader(
    file_path="homework/day28/faq.json",
    jq_schema=".items[]",
    content_key="question",
    metadata_func=lambda record, meta: {
        **meta,
        "id": record.get("id"),
        "category": record.get("category"),
        "answer": record.get("answer"),
    },
)
docs = loader.load()
```

**讲评**：`content_key` 决定 embed 的正文；answer 放 metadata 便于生成阶段拼接，或拼进 page_content。
