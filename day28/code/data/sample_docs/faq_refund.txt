星火智服 · 退款常见问题（FAQ）

一、退款受理范围
客户在购买星火智服增值服务后，如遇重复扣费、未开通服务等情况，可在工单系统中提交退款申请。
客服会在 3 个工作日内审核退款材料。

二、退款流程
1. 登录星火智服客户端，进入「我的订单」
2. 选择需要退款的订单，点击「申请退款」
3. 填写退款原因，上传支付凭证
4. 工单流转至财务审核，退款原路返回

三、大模型相关说明
部分套餐包含大模型问答额度。若大模型功能未使用，可按比例申请退款。
已消耗的大模型 Token 额度不支持单独退款。

四、联系方式
如有疑问，请拨打客服热线 400-800-2026，或在工作时间通过在线客服咨询。
工单编号请妥善保存，便于查询退款进度。
