# 大模型在星火智服中的应用简介

## 什么是大模型

大模型（Large Language Model）是基于海量文本训练的神经网络，能够理解自然语言并生成回答。
星火智服将大模型与检索增强生成（RAG）结合，降低幻觉风险。

## 典型场景

1. **智能客服**：用户提问 → 检索知识库 → 大模型组织答案
2. **工单摘要**：长工单自动提取要点，辅助客服处理
3. **文档问答**：对内制度 txt/md 文档进行问答

## 与关键词统计的关系

在接入 RAG 之前，需对存量文档做批量关键词统计：
- 识别高频主题（如退款、工单）
- 发现冗余或过期文档
- 为切块策略提供字符数参考

## 技术栈预告

| 阶段 | 能力 |
|------|------|
| Day 11 | 文件读取、关键词计数 |
| Day 28 | Document Loader、Text Splitter |

## 注意事项

- 大模型输出需人工抽检
- 敏感信息不得写入 Prompt
- 客服转人工时保留完整上下文
