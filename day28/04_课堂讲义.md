## 第一章 · 为什么 RAG 要先 Loader 再 Split（09:00–09:45）

### 1.1 从关键词统计到向量检索

Day 11 的流程：

```text
遍历目录 → read 全文 → 正则数关键词 → 打印报表
```

Day 28~30 的 RAG 流程：

```text
Loader → Splitter → Embed → VectorStore → Retrieve → Generate
```

**今日只做到 Splitter**。若跳过 Loader 统一接口，每种格式都要写一套 `if pdf elif docx`，维护成本爆炸。

### 1.2 Document 对象

LangChain 核心数据结构：

```python
from langchain_core.documents import Document

doc = Document(
    page_content="星火智服支持 RAG 检索增强。",
    metadata={"source": "/data/faq_refund.txt", "format": "txt"},
)
```

| 字段 | 含义 |
|------|------|
| `page_content` | 送入 Splitter / Embedding 的正文 |
| `metadata` | 溯源、过滤、权限；**不**参与 embed（除非特意拼接） |

Day 30 回答里的「引用来源」就来自 `metadata["source"]`。

### 1.3 六种格式为何都要会

星火智服知识库真实构成（刘姐 Excel）：

- **PDF**：产品手册、扫描版制度  
- **Word**：法务审核过的政策原文  
- **Markdown**：研发写的技术说明  
- **网页**：内网公告 HTML 快照  
- **CSV**：订单、FAQ 结构化表  
- **TXT**：legacy 纯文本 FAQ

## 第二章 · Document Loader 实战（09:45–12:00）

### 2.1 环境准备

```bash
cd day28/code
pip install -r requirements.txt
python3 ensure_samples.py
```

`ensure_samples.py` 自动生成 `ebook.pdf` 与 `policy.docx`，避免仓库里塞二进制大文件。

### 2.2 Markdown / TXT：TextLoader

打开 [code/doc_loader_demo.py](./code/doc_loader_demo.py)：

```python
from langchain_community.document_loaders import TextLoader

loader = TextLoader("data/sample_docs/product_guide.md", encoding="utf-8")
docs = loader.load()
```

**要点**：

- 必须指定 `encoding="utf-8"`，中文不乱码  
- 一个文件通常 → 一个 Document（除非按行加载）  
- `metadata["source"]` 自动为文件路径  

### 2.3 PDF：PyPDFLoader

```python
from langchain_community.document_loaders import PyPDFLoader

loader = PyPDFLoader("data/sample_docs/ebook.pdf")
docs = loader.load()  # 每页一个 Document
```

- 多页 PDF → 多个 Document，`metadata["page"]` 为页码  
- 扫描版 PDF 无文字层时 `page_content` 为空——生产需 OCR（paddleocr、tesseract）  
- 教学样本若提取失败，`process_pdf_ebook.py` 回退 `ebook.pdf.txt`

### 2.4 Word：Docx2txtLoader

```python
from langchain_community.document_loaders import Docx2txtLoader

loader = Docx2txtLoader("data/sample_docs/policy.docx")
docs = loader.load()
```

提取纯文本，**不保留**加粗、表格样式。若需结构保留，用 `UnstructuredWordDocumentLoader`（依赖更重）。

### 2.5 CSV：CSVLoader

```python
from langchain_community.document_loaders import CSVLoader

loader = CSVLoader(
    file_path="data/sample_docs/orders_sample.csv",
    encoding="utf-8",
)
docs = loader.load()  # 每行一个 Document
```

每行 CSV 变成一条可检索记录，适合订单号、状态查询类 RAG。

### 2.6 Web：本地 HTML

CI 环境常无外网，今日用 **BSHTMLLoader** 读本地快照：

```python
from langchain_community.document_loaders import BSHTMLLoader

loader = BSHTMLLoader("data/sample_docs/sparktech_web.html", open_encoding="utf-8")
docs = loader.load()
```

有外网时可设 `WEB_DEMO_URL` 用 `WebBaseLoader`——**作业里对比二者差异**。

## 第三章 · Text Splitter 原理（14:00–15:00）

### 3.1 为什么要切块

| 限制 | 说明 |
|------|------|
| 上下文窗口 | GPT-4o 虽长，但检索常只塞 Top-K 块 |
| Embedding 质量 | 过长段落向量「语义平均」，检索变钝 |
| 成本 | Day 15 学过：Token 按块计费 |

**目标**：每块足够短能精准匹配 query，又足够长能回答完整问题。

### 3.2 CharacterTextSplitter

```python
from langchain_text_splitters import CharacterTextSplitter

splitter = CharacterTextSplitter(
    chunk_size=300,
    chunk_overlap=30,
    separator="\n",
)
chunks = splitter.split_documents(docs)
```

按 `\n` 机械累积到 300 字符切断——**可能把一句话切成两半**。

### 3.3 RecursiveCharacterTextSplitter（推荐）

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=300,
    chunk_overlap=30,
    separators=["\n\n", "\n", "。", "！", "？", "；", " ", ""],
)
chunks = splitter.split_documents(docs)
```

算法递归尝试分隔符列表：优先段落 → 行 → 中文句号 → 空格 → 硬切。

### 3.4 chunk_overlap

```text
块1: ...退款原路返回。
块2: 退款原路返回。四、联系方式...
      ^^^^^^^^ overlap 区域重复
```

overlap 避免关键句只出现在块边界而被截断。一般取 chunk_size 的 10%~20%。

## 第四章 · chunk_size 调参实验（15:00–16:00）

运行：

```bash
python3 text_splitter_demo.py
```

观察输出：

```text
recursive size= 100 overlap= 50 -> chunks= 28 avg=  95.2
recursive size= 200 overlap= 50 -> chunks= 15 avg= 178.4
recursive size= 400 overlap= 50 -> chunks=  8 avg= 352.1
recursive size= 800 overlap= 50 -> chunks=  4 avg= 701.0
```

**解读**：

- size 翻倍 → 块数大致减半  
- size 过小 → 块数爆炸，Day 29 embed 变慢  
- size 过大 → 「退款流程」与「联系方式」可能在同一块，检索不精准  

报告写入 `output/splitter_tuning_report.json`，交给刘姐存档。

### 4.1 星火智服推荐起点

| 场景 | chunk_size | overlap |
|------|------------|---------|
| FAQ | 250 | 30 |
| 制度政策 | 400 | 60 |
| 技术 Markdown | 350 | 50 |

**没有银弹**——用 20 条真实 query 做召回测试（Day 30 作业）。

## 第六章 · 常见问题排错

| 现象 | 原因 | 解决 |
|------|------|------|
| `UnicodeDecodeError` | 未指定 utf-8 | TextLoader 加 encoding |
| PDF 0 字符 | 扫描版 | 用 txt 回退或 OCR |
| 块数 = 0 | 空文件 | 检查 sample 路径 |
| ImportError langchain | 未装依赖 | pip install -r requirements.txt |
