## 2. Document 数据模型

```text
Document
├── page_content: str    # 正文
└── metadata: dict
    ├── source: str      # 文件路径（引用溯源）
    ├── page: int        # PDF 页码（可选）
    └── format: str      # pdf/docx/md/...
```

LangChain 各 Loader 负责填充 `source`；业务可扩展 `department`、`version` 等字段。

## 3. Loader 选型

| 格式 | 推荐 Loader | 备注 |
|------|-------------|------|
| PDF | PyPDFLoader | 扫描版需 OCR |
| Word | Docx2txtLoader | 轻量纯文本 |
| Markdown | TextLoader | 保留 `#` 标题利于切块 |
| HTML | BSHTMLLoader | 本地文件，无外网依赖 |
| CSV | CSVLoader | 每行一个 Document |
| TXT | TextLoader | encoding=utf-8 |

## 4. Splitter 设计

### 4.1 CharacterTextSplitter

按固定 `separator`（如 `\n`）机械切分，**不保证**在句号处断开。

### 4.2 RecursiveCharacterTextSplitter

按 `separators` 列表递归尝试：

```text
["\n\n", "\n", "。", "！", "？", "；", " ", ""]
```

优先大块语义边界，适合中文制度文档。

### 4.3 参数建议（星火智服知识库）

| 文档类型 | chunk_size | chunk_overlap |
|----------|------------|---------------|
| FAQ 短文 | 200~300 | 20~40 |
| 制度长文 | 400~500 | 50~80 |
| 技术 Markdown | 300~400 | 30~60 |
