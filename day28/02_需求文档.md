## 1. 目标

1. **统一加载**：PDF、Word、Markdown、Web(HTML)、CSV、TXT 六种格式 → `list[Document]`。  
2. **规范切块**：`CharacterTextSplitter` 与 `RecursiveCharacterTextSplitter` 对比教学。  
3. **可调参数**：`chunk_size`、`chunk_overlap` 实验并输出 JSON 报告。  
4. **PDF 流水线**：`process_pdf_ebook.py` 导出切块清单供 Day 29 消费。  
5. **离线可跑**：无 API Key、无外网时 `run.sh` 全绿。

## 4. 功能需求

### 4.1 doc_loader_demo.py

| 格式 | Loader | 样本文件 |
|------|--------|----------|
| Markdown | TextLoader | `product_guide.md` |
| TXT | TextLoader | `faq_refund.txt` |
| PDF | PyPDFLoader | `ebook.pdf`（自动生成） |
| Word | Docx2txtLoader | `policy.docx`（自动生成） |
| CSV | CSVLoader | `orders_sample.csv` |
| Web | BSHTMLLoader | `sparktech_web.html` |

输出：每种格式 Document 数量、前 3 条 preview、metadata.source。

### 4.2 text_splitter_demo.py

- 固定参数对比：Character vs Recursive，`chunk_size=300`, `overlap=30`  
- 调参扫描：`chunk_size` ∈ {100, 200, 400, 800}，`overlap=50`  
- 输出：`output/splitter_tuning_report.json`

### 4.3 process_pdf_ebook.py

- 输入：`data/sample_docs/ebook.pdf`  
- 默认：`chunk_size=400`, `overlap=60`  
- 输出：`output/ebook_chunks_*.json`，含 chunk_id、chars、source、page、preview

### 4.4 ensure_samples.py

- 若缺失则生成 `ebook.pdf`、`policy.docx`  
- PDF 文本过少时回退 `ebook.pdf.txt`
