# 零基础大模型应用开发 · 70 天企业实战培训课程

> **业务主线**：你将以「星火科技有限公司」大模型应用开发部新人的身份，从 Day 1 入职报到开始，历经 70 天，亲手把公司的智能客服与知识助手平台从 0 做到 1 并上线。

## 课程定位

| 项目 | 说明 |
|------|------|
| 周期 | 70 天（10 周），每日 6–8 小时 |
| 学员 | 零编程基础或少量基础的转行者、在校生、产品经理 |
| 产出 | 独立开发 RAG、Agent、微调小模型并部署上线 |
| 技术栈 | Python、LangChain、LlamaIndex、OpenAI/DeepSeek/Qwen API、FastAPI、向量库、Docker |
| 考核 | 每周小测 + 3 次阶段项目 + 1 个毕业设计 |

## 学习路径（六阶段）

| 阶段 | 天数 | 主题 | 企业级落地 |
|------|------|------|------------|
| 一 | 1–14 | Python 编程基础 | 命令行多轮对话 AI 助手 |
| 二 | 15–24 | 大模型理论与 Prompt + Web | 网页版 ChatGPT 克隆 |
| 三 | 25–38 | LangChain 与 RAG | 企业级知识库问答系统 |
| 四 | 39–50 | Agent 智能体 | 多 Agent 智能办公助手 |
| 五 | 51–57 | 微调与部署 | 垂直领域模型微调 + Docker 上线 |
| 六 | 58–70 | 毕业设计 + 就业冲刺 | 自选方向完整产品 |

## 如何使用本仓库

1. **按天学习**：进入 `dayNN/` 目录，先读 `README.md` 旁白，再按 01→07 顺序学习。
2. **动手编码**：所有代码在当日 `code/` 目录，建议逐文件运行、对照注释修改。
3. **Git 提交**：从 Day 1 晚自习起，每天作业完成后 `commit`，毕业时你将拥有完整 GitHub 作品集。
4. **累计代码量**：全课程目标约 20 万行（含注释与测试）；单日从数百行递增至数千行。
