## 4. 功能需求

### 4.1 intent_classifier.py

| 符号 | 行为 |
|------|------|
| `IntentClassifier.classify(text)` | 返回 `IntentResult` |
| `INTENT_LABELS` | 7 类固定枚举 |
| `route_by_intent()` | 映射到 bot/human 队列 |
| `extract_json_block()` | 剥离 markdown 围栏 |

### 4.2 injection_defense_demo.py

| 层级 | 行为 |
|------|------|
| 规则层 | 正则拦截常见注入短语 |
| LLM 层 | hardened system + JSON 响应 |

### 4.3 structured_output_demo.py

- JSON Mode：`response_format={"type": "json_object"}`  
- Function Calling：`query_order_status` 工具 mock  

### 4.4 cot_demo.py

- direct vs CoT 对比  
- Self-Consistency / ToT 概念模拟（不强制 live 多次采样）
