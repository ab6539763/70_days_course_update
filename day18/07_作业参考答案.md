## A2. 低置信度转人工（参考）

```python
class MyIntentClassifier(IntentClassifier):
    def classify(self, user_message: str) -> IntentResult:
        result = super().classify(user_message)
        if result.confidence < 0.6:
            result.need_human = True
            result.suggested_reply += "（低置信度，建议人工复核）"
        return result
```
