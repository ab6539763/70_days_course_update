## 1. 背景与目标

星火智服需同时支持 OpenAI 兼容接口与通义千问。业务层禁止散落 `if vendor == ...`，必须通过 **继承 + 多态** 提供统一 `generate(prompt)` 入口。

**目标**：在 `day09/code/` 交付可运行的 mock 类层次，为 Day 15 真实 API 替换预留扩展点。

## 3. 功能需求

### 3.1 文件结构（F-01）

```
day09/code/
├── base_model.py           # 基类 + GenerationResult
├── openai_model.py         # OpenAI 子类
├── qwen_model.py           # Qwen 子类
├── magic_methods_demo.py   # 继承 / 多态演示
├── property_demo.py        # property / 魔术方法演示
└── run_llm_demo.py         # 综合验收脚本
```

### 3.2 BaseModel（F-02）

| 成员 | 类型 | 说明 |
|------|------|------|
| `vendor` | 类属性 `str` | 厂商标识，子类覆盖 |
| `__init__` | 构造 | 接收 `model_name`, `api_key`, `temperature`, `max_tokens` |
| `model_name` | `@property` 只读 | 模型名 |
| `temperature` | `@property` + setter | 范围 0.0～2.0，越界 `ValueError` |
| `max_tokens` | `@property` 只读 | 最大生成长度 |
| `call_count` | `@property` 只读 | 调用次数统计 |
| `is_configured` | `@property` 只读 | 是否配置 api_key |
| `generate(prompt, **kwargs)` | 实例方法 | 默认 `NotImplementedError` |
| `_before_generate(prompt)` | 钩子 | strip 校验 + `call_count += 1` |
| `build_system_prefix()` | 钩子 | 子类可重写 |
| `__str__` / `__repr__` / `__call__` | 魔术方法 | 见 F-05 |

### 3.3 OpenAIModel（F-03）

| 要求 | 说明 |
|------|------|
| 继承 | `class OpenAIModel(BaseModel)` |
| 构造 | `super().__init__(...)` + `base_url` 属性 |
| 重写 | `generate()` 返回 mock 文本，含 `vendor=openai` |
| 默认模型 | `gpt-4o` |

### 3.4 QwenModel（F-04）

| 要求 | 说明 |
|------|------|
| 继承 | `class QwenModel(BaseModel)` |
| 构造 | `super().__init__(...)` + `region` 属性 |
| 重写 | `generate()` 返回中文口吻 mock |
| 扩展 | `generate_with_search()` 子类独有（课堂对比用） |
| 默认模型 | `qwen-plus` |

### 3.5 GenerationResult（F-05）

| 字段 | 类型 | 说明 |
|------|------|------|
| `text` | `str` | 生成正文 |
| `model` | `str` | 模型名 |
| `vendor` | `str` | 厂商 |
| `prompt_tokens` | `int` | mock 统计 |
| `completion_tokens` | `int` | mock 统计 |
| `latency_ms` | `float` | mock 耗时 |
| `created_at` | `str` | ISO 时间戳 |

实现 `__str__` 返回 `text`；`__repr__` 便于调试。

### 3.6 魔术方法与 property（F-06）

| 方法 | 行为 |
|------|------|
| `__str__` | 用户可读：`openai 模型 gpt-4o (temp=0.7, 已配置 Key)` |
| `__repr__` | 开发者可读，含类名与关键参数 |
| `__call__` | 委托 `generate()` |
| `temperature` setter | 赋值时校验，非法值抛 `ValueError` |

## 4. 非功能需求

| ID | 要求 |
|----|------|
| NF-01 | 全部脚本 `python3 xxx.py` 可直接运行，无第三方依赖 |
| NF-02 | 不发起真实网络请求，不使用真实 API Key |
| NF-03 | 类型注解完整，公开方法有 docstring |
| NF-04 | 业务路由函数参数类型为 `BaseModel` 或 `list[BaseModel]` |

## 5. 验收标准（AC）

| ID | 验收项 | 验证方式 |
|----|--------|----------|
| AC-01 | `OpenAIModel()` 是 `BaseModel` 实例 | `isinstance` |
| AC-02 | `list[BaseModel]` 可混放两家子类 | `run_llm_demo.py` |
| AC-03 | 空 prompt 抛 `ValueError` | 单元测试或手动 |
| AC-04 | `temperature=3` 抛 `ValueError` | `property_demo.py` |
| AC-05 | `model("x")` 与 `generate("x")` 文本一致 | `property_demo.py` |
| AC-06 | 每次 `generate` 后 `call_count` 递增 | `run_llm_demo.py` 末尾统计 |
| AC-07 | `repr(model)` 含类名与 `model_name` | 目视 / 脚本 assert |
