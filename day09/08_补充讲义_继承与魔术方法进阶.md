## 1. MRO（方法解析顺序）

多继承时，Python 按 **C3 线性化** 决定 `super()` 找谁：

```python
class A:
    def go(self):
        print("A")

class B(A):
    def go(self):
        print("B start")
        super().go()
        print("B end")

class C(A):
    def go(self):
        print("C start")
        super().go()
        print("C end")

class D(B, C):
    def go(self):
        print("D start")
        super().go()
        print("D end")

D().go()
# D start → B start → C start → A → C end → B end → D end
```

查看 MRO：

```python
print(D.__mro__)
# (<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>)
```

`magic_methods_demo.VerboseOpenAI` 继承 `OpenAIModel, LoggingMixin`，若两者都有 `generate`，MRO 决定 `super()` 链。

## 2. abc.ABC 与 @abstractmethod

今日 `BaseModel` 用 `NotImplementedError` 表达「子类必须实现」。标准库更严格写法：

```python
from abc import ABC, abstractmethod

class BaseModel(ABC):
    @abstractmethod
    def generate(self, prompt: str) -> GenerationResult:
        ...
```

效果：实例化未实现 `generate` 的子类时直接 `TypeError`。Day 12 重构时可选用。

| 方式 | 优点 | 缺点 |
|------|------|------|
| `NotImplementedError` | 简单，培训友好 | 运行时才暴露漏实现 |
| `ABC` + `@abstractmethod` | 实例化即失败 | 需理解元类 |

## 3. 继承 vs 组合

| | 继承 is-a | 组合 has-a |
|---|-----------|------------|
| 关系 | `OpenAIModel` 是一种 `BaseModel` | `ContactBook` 有一个 `list[Contact]` |
| 耦合 | 子类与父类生命周期绑定 | 更灵活替换内部对象 |
| 适用 | 统一接口、多态 | 复用功能块、避免深层继承树 |

**张工原则**：继承层次 **不超过 2～3 层**；超过则考虑组合或协议（`Protocol`）。

```python
class ContactBook:
    def __init__(self):
        self._contacts: list[Contact] = []   # 组合
```

## 5. `__call__` 与 functools.partial

类似效果：

```python
from functools import partial

model = OpenAIModel()
fn = partial(model.generate, temperature=0.2)
fn("hello")   # 等价 model.generate("hello", temperature=0.2)
```

`__call__` 更 OOP；`partial` 更函数式。星火智服内部规范：**模型实例统一 `__call__`**。

## 6. @property 性能说明

`property` 每次访问都执行 getter 函数。对 **O(1) 字段读取** 开销可忽略；若 getter 做重计算，应加缓存：

```python
@property
def expensive(self):
    if not hasattr(self, "_cache"):
        self._cache = self._compute()
    return self._cache
```

`call_count` 无需缓存——只是读整数。

## 7. 与 LangChain BaseChatModel 对照

```python
# LangChain 简化概念
class BaseChatModel:
    def invoke(self, input, config=None):
        ...

# 今日
class BaseModel:
    def generate(self, prompt: str, **kwargs):
        ...
    def __call__(self, prompt: str, **kwargs):
        return self.generate(prompt, **kwargs)
```

Day 28 接 LangChain 时，今日类可写 **Adapter**：

```python
class LangChainAdapter:
    def __init__(self, model: BaseModel):
        self._model = model

    def invoke(self, messages):
        prompt = messages[-1].content
        return self._model(prompt).text
```
