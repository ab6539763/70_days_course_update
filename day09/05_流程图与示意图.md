## 7. __str__ vs __repr__ 决策树

```text
  需要打印对象？
        │
        ├─ 给运维/用户看 → 实现 __str__（简短可读）
        │
        └─ 给开发/日志看 → 实现 __repr__（含类名与关键字段）
                │
                └─ 列表里显示 → 默认用 repr，故 __repr__ 不可省
```

## 8. 反模式 vs 推荐模式

```text

【推荐】

```
