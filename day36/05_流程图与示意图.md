# Day 36 流程图与示意图

## 1. 文档摄取流程

```mermaid
flowchart TD
    A[用户上传 txt/md/pdf] --> B{格式判断}
    B -->|txt/md| C[read_text UTF-8]
    B -->|pdf| D[pypdf 提取文本]
    C --> E[chunk_text 切块]
    D --> E
    E --> F[mock_embed 每块]
    F --> G[(documents + knowledge_chunks)]
    G --> H[rag.load_index 刷新内存]
```

## 2. 问答时序（非流式）

```mermaid
sequenceDiagram
    participant C as Client
    participant API as FastAPI
    participant RAG as RAGService
    participant DB as SQLite

    C->>API: POST /api/chat
    API->>DB: 保存 user message
    API->>RAG: ask(query)
    RAG->>DB: 读取 chunks
    RAG->>RAG: Hybrid + Rerank
    RAG-->>API: answer + citations
    API->>DB: 保存 assistant + citations_json
    API-->>C: JSON reply + citations
```

## 3. SSE 流式时序

```mermaid
sequenceDiagram
    participant FE as Frontend
    participant API as FastAPI
    participant RAG as RAGService

    FE->>API: POST /api/chat/stream
    API->>RAG: stream_answer()
    RAG-->>API: citations
    API-->>FE: SSE event=citations
    loop 逐块生成
        RAG-->>API: delta
        API-->>FE: SSE event=delta
    end
    RAG-->>API: done
    API-->>FE: SSE event=done
```
