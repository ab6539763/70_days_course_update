# Day 36 架构与设计 · Project 2 企业知识库问答

## 1. 系统架构

```text
┌─────────────┐     HTTP/SSE      ┌──────────────────────────────────┐
│  Frontend   │ ◄──────────────► │  FastAPI (main.py)                │
│  Day 37     │                   │  ├─ /api/documents/upload        │
└─────────────┘                   │  ├─ /api/chat[/stream]            │
                                  │  └─ /api/sessions/*               │
                                  └──────────┬───────────────────────┘
                                             │
                    ┌────────────────────────┼────────────────────────┐
                    ▼                        ▼                        ▼
           document_ingest.py        rag_service.py            SQLAlchemy
           txt/md/pdf 解析            Hybrid+Rerank+生成         SQLite
                    │                        │
                    └──────────► knowledge_chunks ◄──────────────┘
```

## 2. 模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| 入口 | `main.py` | 路由、CORS、生命周期 ingest 样本库 |
| 摄取 | `document_ingest.py` | 解析、切块、写 documents/chunks |
| 检索 | `hybrid_retriever.py` | BM25 + Vector + RRF |
| 重排 | `rerank.py` | mock 关键词重排 |
| 服务 | `rag_service.py` | ask / stream_answer / citations |
| 持久化 | `models.py` | sessions, messages, documents, chunks |
| 契约 | `schemas.py` | Pydantic 请求响应 |

## 3. 数据模型

```text
chat_sessions (id PK)
    └── chat_messages (id, session_id, role, content, citations_json)

documents (id, filename, file_type, file_path, chunk_count, status)
    └── knowledge_chunks (chunk_id UK, document_id, source, content, embedding_json)
```

**citations_json** 存 assistant 消息对应的引用快照，便于历史回放。

## 4. RAG 流水线

```text
Query
  → HybridRetriever.retrieve (BM25 top + Vector top → RRF)
  → rerank(query, hits, top_k=3)
  → CitationOut[] (chunk_id, source, snippet, score)
  → mock_generate / live_generate
  → Answer + Citations
```

## 5. SSE 事件设计

| event | 字段 | 时机 |
|-------|------|------|
| citations | citations[] | 生成前，前端先渲染引用徽章 |
| delta | delta | 流式文本块 |
| done | message_id, citations | 结束，触发 DB 持久化 |
| error | error | LLM 或检索异常 |

## 6. 配置项

| 变量 | 默认 | 说明 |
|------|------|------|
| SPARKTECH_MOCK | 1 | mock 模式 |
