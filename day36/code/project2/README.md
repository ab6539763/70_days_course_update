# Project 2 · 企业级知识库问答系统

全栈代码位于本目录，Day 36–38 共用。

## 快速开始

```bash
bash run.sh
# 前端 http://127.0.0.1:8080
# API  http://127.0.0.1:8000/docs
```

## 验收

```bash
python3 verify_project2.py
```

## 结构

- `backend/` — FastAPI + RAG + SQLite
- `frontend/` — 引用徽章 + 上传 + SSE
- `data/sample_docs/` — 样本知识库
