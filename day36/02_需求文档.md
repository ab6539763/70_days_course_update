## 1. 产品概述

**产品名称**：星火智服 · 企业知识库问答（Enterprise KB Q&A）  
**目标用户**：企业内部员工、客服坐席  
**核心价值**：基于企业私有文档的准确问答，**每条回答可溯源到源文件片段**。

## 3. 非功能需求

- **性能**：mock 模式单次问答 < 3s（教学环境）  
- **安全**：API Key 仅服务端 `.env`，禁止前端暴露  
- **可测**：`verify_project2.py` 自动化覆盖 ingest/ask/stream/citations  

## 4. API 契约（摘要）

### POST /api/documents/upload

- Content-Type: `multipart/form-data`  
- 字段：`files`（可多文件）  
- 响应：`uploaded[]`, `rebuilt_chunks`

### POST /api/chat

```json
{
  "message": "退款政策是什么？",
  "session_id": "kb-xxx",
  "stream": false
}
```

响应：

```json
{
  "reply": "...",
  "session_id": "kb-xxx",
  "mode": "mock",
  "citations": [
    {
      "chunk_id": "1-abc",
      "source": "refund_policy.md",
      "snippet": "用户可在订单完成后 7 天内...",
      "score": 0.42,
      "chunk_index": 0
    }
  ],
  "message_id": 2
}
```

### POST /api/chat/stream（SSE）

事件顺序：

1. `event: citations` — 检索到的引用列表  
2. `event: delta` × N — 答案逐块  
3. `event: done` — 含 `message_id` 与最终 `citations`  

## 5. 验收标准

- [ ] 三类格式文档均可上传并索引  
- [ ] 问「退款」类问题 citations 含 refund 相关 source

- [ ] verify 脚本 7 项全绿
