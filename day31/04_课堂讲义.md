## 第二章 · chunk_size 实验（10:30–11:30）

### 2.1 原理

`chunk_size` 控制单块最大字符数。过小 → 上下文碎片化；过大 → 检索粒度粗、无关内容混入。

打开 `rag_tuning_lab.py`，观察：

```python
CHUNK_SIZES = [256, 512, 1024]
```

课堂实验：固定 `top_k=5`、`model=text-embedding-3-small`，只改 chunk_size，比较 hit_rate。

### 2.2 重叠 overlap

```python
overlap = max(40, chunk_size // 8)
```

重叠避免「退款政策」被切成两半后各自丢失语义。

## 第三章 · top_k 实验（11:30–12:00）

### 3.1 权衡

| top_k | 优点 | 缺点 |
|-------|------|------|
| 3 | 上下文短、噪声少 | 可能漏召回 |
| 5 | 常用平衡点 | — |
| 10 | 召回更全 | LLM 上下文膨胀、幻觉风险 |

### 3.2 课堂演示

```bash
cd day31/code
python3 rag_tuning_lab.py
```

在报告中找同一 model+chunk 下 top_k 从 3→10 的 hit_rate 变化。
