## 4. 功能需求

### 4.1 llm_compat.py · ParametricLLMClient

| 符号 | 行为 |
|------|------|
| `chat(messages, **params)` | 支持 temperature/top_p/max_tokens/frequency_penalty |
| `chat_stream(messages, **params)` | 生成器 yield 文本片段；mock 模拟逐字 |
| `get_llm_client()` | 优先 Day 13，回退 Day 12 |
| mock | 无 Key 不 HTTP；流式 sleep 模拟 |

### 4.2 role_messages_demo.py

| 内容 | 要求 |
|------|------|
| 三角色示例 | system 人设 + user 提问 + assistant 历史 |
| 违规示例 | 展示缺少 system 时的漂移（mock 对比） |

### 4.3 stream_demo.py

| 符号 | 行为 |
|------|------|
| `typewriter_print(chunks)` | 逐 chunk 打印不换行错乱 |
| CLI | 可选 `--live` |
| mock | 将完整回复按 2–4 字切分 yield |

### 4.4 param_experiment.py

| 符号 | 行为 |
|------|------|
| `--param` | 扫描 temperature / top_p / max_tokens / frequency_penalty |
| 输出 | 终端表格 + `output/experiment_*.json` |

### 4.5 compare_params.py

| 符号 | 行为 |
|------|------|
| `--prompt-id` | 从 demo_prompts.json 读取 |
| `--presets` | 从 param_presets.json 读取多组配置 |
| 报告 | 每组：参数、回复全文、completion_tokens（mock 估算） |
| `--write-defaults` | 写入 `output/demo_defaults.json` |

## 5. 推荐演示默认参数（初稿）

```json
{
  "temperature": 0.3,
  "top_p": 0.9,
  "max_tokens": 512,
  "frequency_penalty": 0.3,
  "stream": true,
  "rationale": "偏低温度保证事实稳定；适度 frequency_penalty 减少套话；流式改善首字延迟"
}
```
