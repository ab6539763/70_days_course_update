## 必做 B · 流式耗时

```python
import time

start = time.perf_counter()
first = True
for chunk in client.chat_stream(messages, temperature=0.3):
    if first:
        print(f"\n首 chunk 延迟: {(time.perf_counter()-start)*1000:.0f} ms")
        first = False
    print(chunk, end="", flush=True)
```

mock 仍有 ~30ms/chunk sleep，首 chunk 应明显快于非流式总等待。
