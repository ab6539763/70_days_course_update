# Day 16 补充讲义 · presence_penalty、stop、seed 与 API 差异

## 1. presence_penalty vs frequency_penalty

| 参数 | 惩罚对象 | 效果 |
|------|----------|------|
| frequency_penalty | 已出现 **次数多** 的 token | 减重复词 |
| presence_penalty | **出现过** 的 token（不论次数） | 鼓励谈新话题 |

客服 FAQ 场景：常用 frequency_penalty；头脑风暴才考虑 presence_penalty。

## 2. stop 序列

```python
client.chat(messages, stop=["\n\n", "用户："])
```

遇到 stop 字符串即停止生成。可用于：

- 限制只生成一段  
- 防止模型模拟下一轮 user  

## 3. seed（可复现采样）

部分 API 支持 `seed` 固定随机源，**相近参数下**输出可复现。完全确定性仍需 `temperature=0`。

## 4. 流式协议注意点

OpenAI 兼容流式响应：

```text
data: {"choices":[{"delta":{"content":"你"}}]}

data: {"choices":[{"delta":{"content":"好"}}]}

data: [DONE]
```

解析要点：

- 按行读，`startswith("data: ")`  
- `[DONE]` 结束  
- 异常行跳过，避免 JSON 半截  

Day 20 将封装为 SSE HTTP 接口。
