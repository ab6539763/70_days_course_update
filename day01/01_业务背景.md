## 3. 大模型行业全景（上午第一节摘要）

### 3.1 产业链位置

```text
芯片/算力 → 基础模型（预训练）→ 模型 API / 开源权重 → 应用层（我们做）→ 行业客户
```

应用层岗位大致分三类，本课程全覆盖，但侧重前两类：

1. **应用开发工程师**：RAG、Agent、API 集成、后端（本课程主路径）  
2. **算法/微调工程师**：数据、训练、评估（课程第五阶段）  
3. **产品/解决方案**：需求、验收、合规（课程含 PRD 训练）

### 3.2 为什么先学 Python 而不是直接调 GPT

客户现场常见约束：

- 内网不能随意访问公网 → 要会部署、会 Docker  
- 要把 ERP、工单、文档接进系统 → 要会 Python 洗数据、写服务  
- 出问题要能查日志 → 要懂变量、类型、异常，不能只会复制粘贴  

**Day 1 的「个人信息卡片」** 就是在练：**输入 → 处理 → 输出**，与 Day 12 调 API 的链路同构。

### 3.3 职业路径（培训生 → 独立交付）

| 阶段 | 能力 | 典型薪资区间（参考，因城市而异） |
|------|------|----------------------------------|
| 培训结业 | 能独立完成 RAG/Agent 小项目 | 初级岗位门槛 |
| 1 年 | 独立交付企业知识库、联调 | 中级应用开发 |
| 2–3 年 | 架构选型、带项目、微调 | 高级 / 技术负责人 |
