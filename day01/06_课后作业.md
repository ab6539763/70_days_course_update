## 必做题（共 5 题，约 2–3 小时）

### B1 · 环境证明

在 `homework/你的姓名/env_check.txt` 中粘贴以下命令的**完整输出**：

```bash
python3 --version
python3 -m pip --version
python3 code/hello_sparktech.py
```

并附 1 句话：你使用的操作系统与终端类型（如 Windows PowerShell）。

---

### B2 · 个人信息卡片（正式交付）

在 PRD 基础上完成 `personal_info_card_hw.py`，在 v1 基础上增加：

1. 程序启动时打印**可用部门列表**（序号 + 名称，数据来自 `constants.DEPARTMENTS`）  
2. 用户输入部门时可以输入**序号**或**部门全名**  
3. 若序号非法，回退到默认部门并 `print` 一行警告  

验收：三种输入方式均能生成合法卡片（全名 / 序号 / 回车默认）。

---

### B3 · 类型转换小实验

新建 `type_playground.py`，要求：

```python
# 1. 定义变量 a=10, b=3，打印 a/b 与 a//b 及各自 type()
# 2. 定义 s="100"，把 s 转成 int 后 +1，打印结果
# 3. 定义 flag="false"（字符串），说明为何 bool("false") 是 True
```

每题用 `print` 输出，并加**一行中文注释**解释结果。

---

### B4 · f-string 格式化

新建 `format_demo.py`：

- 给定 `name="李华"`, `dept="大模型应用开发部"`, `year=2026`  
- 用 **一种** f-string 输出：`【2026】李华 @ 大模型应用开发部`  
- 再用 f-string 控制浮点：`price=19.9`，输出 `单价: 19.90 元`（保留两位小数）

---

2. `homework(day01): 姓名`  

在 `homework/你的姓名/git_log.txt` 粘贴 `git log --oneline -5` 输出。
