## 二、Windows 环境排错 20 条（培训班历年统计）

| 编号 | 现象 | 处理 |
|------|------|------|
| W01 | `python` 打开微软商店 | 关闭「应用执行别名」中的 python.exe |
| W02 | 双版本 python 冲突 | `where python` 查路径，删 PATH 多余项 |
| W03 | 中文乱码 | chcp 65001 + VS Code UTF-8 |
| W04 | 路径含中文空格 | 项目目录尽量全英文 |
| W05 | 杀毒拦截 venv | 添加学习目录白名单 |
| W06 | 权限不足 | 勿装 C:\Program Files，用用户目录 |
| W07 | Store 版 Python 缺 pip | 改装官网版 |
| W08 | PowerShell 执行策略 | `Set-ExecutionPolicy RemoteSigned` |
| W09 | 复制代码缩进乱 | 用 VS Code 粘贴自动调整 |
| W10 | Git 未安装 | 安装 Git for Windows |

（W11–W20 见内网 Wiki，结构相同。）

## 三、macOS / Linux 环境排错精选

**M01** `command not found: python3` → 安装 Xcode CLT 或 brew python。  
**M02** pip 指向系统 Python → 始终 `python3 -m pip`。  
**L01** `externally-managed-environment` → 使用 `python3 -m venv .venv`（Day 10 必做）。  
**L02** 缺少 `python3-venv` 包 → `sudo apt install python3-venv`。

## 四、Python 交互模式（REPL）速查

终端输入 `python3` 进入：

```python
>>> 1 + 1
2
>>> name = "星火"
>>> print(f"你好，{name}")
你好，星火
>>> exit()
```

旁白：排查 API 返回、试字符串方法时，REPL 比新建文件快。生产代码仍要写入 `.py` 并版本管理。
