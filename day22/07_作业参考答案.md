## 选做 D · localStorage 要点

```javascript
function saveMessages() {
  const items = [...messageList.querySelectorAll('.message')].map((row) => ({
    role: row.classList.contains('user') ? 'user' : 'assistant',
    text: row.querySelector('.bubble').textContent,
  }));
  localStorage.setItem(STORAGE_KEY, JSON.stringify(items));
}
```

页面 `init` 时 `loadMessages()` 重建 DOM。

## 选做 F · fetch 与 CORS

**fetchChat 参数**：

| 字段 | 含义 |
|------|------|
| `message` | 用户本轮输入 |
| `session_id` | 会话 ID，多轮时服务端查历史 |
| `stream` | 是否 SSE 流式 |

**CORS**：浏览器同源策略限制 `http://127.0.0.1:8080` 访问 `:8000`。  
FastAPI 端：

```python
from fastapi.middleware.cors import CORSMiddleware
app.add_middleware(CORSMiddleware, allow_origins=["*"], ...)
```
