## 第一章 · HTML 语义结构（09:00–10:00）

### 1.1 为什么用语义标签

| 标签 | 用途 |
|------|------|
| `header` | 顶栏 Logo、标题 |
| `main` | 主内容区（消息列表） |
| `footer` | 底部输入栏 |
| `button` | 可点击操作 |
| `textarea` | 多行输入 |

搜索引擎与屏幕阅读器依赖语义，Chat 产品也要 **无障碍**。

### 1.2 Chat 页面骨架

打开 [static/index.html](./static/index.html)：

```html
<div class="app">
  <header class="app-header">...</header>
  <main id="message-list" class="chat-messages" role="log" aria-live="polite"></main>
  <footer class="chat-input-bar">...</footer>
</div>
```

**要点**：

- `id="message-list"` 供 JS `getElementById`  
- `role="log"` + `aria-live="polite"` 新消息时读屏友好  
- 脚本放 `</body>` 前，避免阻塞渲染  

### 1.3 资源引入

```html
<link rel="stylesheet" href="style.css" />
<script src="app.js" defer></script>
```

`defer` 保证 DOM 解析完再执行 JS。

## 第二章 · CSS 布局（10:00–11:30）

### 2.1 全屏 Flex 列布局

```css
.app {
  display: flex;
  flex-direction: column;
  height: 100vh;
}
.chat-messages {
  flex: 1;
  overflow-y: auto;
}
```

`flex: 1` 让消息区吃掉中间全部高度；`overflow-y: auto` 出现滚动条。

### 2.2 气泡样式

```css
.message.user {
  justify-content: flex-end;
}
.message.user .bubble {
  background: var(--user-bubble);
  color: #fff;
}
.message.assistant .bubble {
  background: var(--assistant-bubble);
  color: #1e293b;
}
```

user 右对齐、assistant 左对齐——微信/WhatsApp 通用模式。

### 2.3 响应式

```css
.app {
  max-width: 720px;
  margin: 0 auto;
}
@media (max-width: 480px) {
  .bubble { max-width: 88%; }
}
```

客户 Demo 常投屏手机尺寸，375px 必测。

## 第三章 · JavaScript 交互（14:00–15:30）

### 3.1 DOM 增删消息

```javascript
function appendMessage(role, text) {
  const row = document.createElement('div');
  row.className = `message ${role}`;
  const bubble = document.createElement('div');
  bubble.className = 'bubble';
  bubble.textContent = text;
  row.appendChild(bubble);
  messageList.appendChild(row);
  scrollToBottom();
  return bubble;
}
```

**讲师强调**：今日用 `textContent` 防 XSS；若将来渲染 Markdown 需消毒。

### 3.2 事件绑定

```javascript
btnSend.addEventListener('click', sendMessage);
userInput.addEventListener('keydown', (e) => {
  if (e.key === 'Enter' && !e.shiftKey) {
    e.preventDefault();
    sendMessage();
  }
});
```

### 3.3 mock 回复

```javascript
const MOCK_RESPONSES = [
  { keywords: ['天气'], reply: '上海当前天气：晴，26°C，湿度 58%。' },
  { keywords: ['订单', 'ST-'], reply: '订单 ST-10086：已发货...' },
];
```

`pickMockReply(userText)` 遍历关键词表——与 Day 21 工具路由同思路。

### 3.4 打字机效果

```javascript
async function typewriterEffect(element, text, delay = 18) {
  element.textContent = '';
  for (const ch of text) {
    element.textContent += ch;
    await sleep(delay);
    scrollToBottom();
  }
}
```

`async/await` + `sleep` 比 `setInterval` 更易读。

## 第四章 · fetch 预习（15:30–16:00）

Day 24 启用以下代码（今日保持注释）：

```javascript
async function fetchChat(message) {
  const res = await fetch(`${API_BASE}/api/chat`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      message,
      session_id: 'web-demo-001',
      stream: false,
    }),
  });
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}
```

| 概念 | 说明 |
|------|------|
| `fetch` | 浏览器发 HTTP 的 API |
| `POST` | 提交 JSON body |
| `res.json()` | 解析响应体 |

**CORS**：Day 24 FastAPI 需配置 `CORSMiddleware`，否则浏览器拦截跨域。
