## 1. 目标

1. **客户 Demo**：静态页面可演示完整对话流程。

3. **无后端**：今日不启动 Python 服务；`app.js` 本地 mock。  
4. **可扩展**：预留 `API_BASE` 与 `fetchChat`，Day 24 最小改动上线。

## 4. 功能需求

### 4.1 index.html

| 区域 | 要求 |
|------|------|
| `header` | 产品名「星火智服」、副标题、清空按钮 |
| `main#message-list` | 消息容器，`role="log"` `aria-live="polite"` |
| `footer` | `textarea` 或 `input` + 发送按钮 |
| 脚本 | 底部引入 `style.css`、`app.js` |

### 4.2 style.css

| 要求 | 说明 |
|------|------|
| 品牌色 | `--primary: #2563eb` |
| 布局 | 全屏 column flex；消息区 `flex:1` 可滚动 |
| 气泡 | user 右对齐蓝底白字；assistant 左对齐灰底 |
| 响应式 | `max-width: 720px` 居中；小屏 padding 缩小 |

### 4.3 app.js

| 符号/行为 | 说明 |
|-----------|------|
| `MOCK_RESPONSES` | 关键词 → 回复（对齐 Day 21 天气/订单文案） |
| `sendMessage()` | 追加 user 气泡 → 触发 mock 回复 |
| `appendMessage(role, text)` | DOM 增删 |
| `typewriterEffect(el, text)` | 打字机效果 |
| `clearChat()` | 清空列表，保留欢迎语 |
| `API_BASE` | 默认 `''`；Day 24 改为 `http://127.0.0.1:8000` |
| `fetchChat(message)` | **注释状态** 的 fetch 模板 |

### 4.4 mock 场景（至少 3 个）

| 用户输入含 | assistant 回复要点 |
|------------|-------------------|
| 天气 | 城市、温度、湿度 |
| 订单 / ST- | 订单号、状态 |
| 你好 / hello | 欢迎语 |
| 其他 | 默认兜底回复 |

## 5. 非功能需求

| 项 | 要求 |
|----|------|
| 依赖 | 无 npm/webpack（原生三件套） |
| 浏览器 | Chrome / Edge 最新版 |
| 性能 | mock 回复延迟 ≤ 1s |
| 无障碍 | 输入框 `aria-label`；按钮可键盘聚焦 |
