## 1. 目标

1. 掌握 `ChatMessageHistory` 内存存储  
2. 使用 `RunnableWithMessageHistory` 包装 LCEL 链  
3. 实现 Window / Summary / SQLite 三种 Memory 策略  
4. 交付 `session_memory_chat.py` CLI  
5. mock 模式验收

## 2. 功能需求

### 2.1 memory_demo.py

| 函数/类 | 说明 |
|---------|------|
| `demo_chat_message_history()` | 基础内存 history |
| `WindowChatMessageHistory` | 保留最近 k 对 |
| `SummaryChatMessageHistory` | 超阈值生成摘要 |
| `demo_sqlite_history()` | SQLite 持久化 |

### 2.2 session_memory_chat.py

| 功能 | 说明 |
|------|------|
| `build_chain_with_history()` | RunnableWithMessageHistory |
| `/session <id>` | 切换会话 |
| `/mode memory\|window\|sqlite` | 切换后端 |
| `/history` `/clear` `/exit` | 管理命令 |

### 2.3 verify_day27.py

- ChatMessageHistory 基础  
- Window 裁剪断言  
- Summary 摘要非空  
- SQLite 重载  
- RunnableWithMessageHistory 多轮  
- session 隔离
