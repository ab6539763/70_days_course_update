## 必做 C · export_history 要点

```python
def export_day14_json(session_id: str, history: BaseChatMessageHistory) -> dict:
    messages = []
    for m in history.messages:
        role = "user" if m.type == "human" else "assistant"
        if m.type == "human":
            role = "user"
        elif m.type == "ai":
            role = "assistant"
        else:
            role = m.type
        messages.append({"role": role, "content": str(m.content)})
    return {
        "session_id": session_id,
        "title": "LangChain 导出",
        "messages": messages,
    }
```
