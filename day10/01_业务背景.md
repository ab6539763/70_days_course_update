## 3. 与大模型开发的隐性联系

| 今日知识点 | 日后场景 |
|------------|----------|
| 包与 `__init__.py` 公开 API | `langchain`、`openai` SDK 的 import 结构 |
| 自定义异常 | API 重试策略：4xx 不重试、5xx 重试 |
| `try/finally` 关资源 | 流式响应、文件句柄、数据库连接 |
| `requirements.txt` | 部署 Agent 服务时锁定依赖版本 |
| `python-dotenv` | 本地 `.env` 存 `OPENAI_API_KEY`，不入 Git |
| `if __name__` | 同一文件既可被测试 import，又可 CLI 运行 |

张工补充：

> 「调 LLM API 时网络超时、JSON 解析失败、Key 缺失——三种错误处理策略完全不同。  
> 今天把异常分类写进 `exceptions.py`，等于提前练 **可观测的错误模型**。」
