## 2. import 查找链

```text
import sparktech
    │
    ▼
sys.path 各目录中是否存在 sparktech/ ？
    │
    ├─ 否 → ModuleNotFoundError
    │
    └─ 是 → 执行 sparktech/__init__.py
              │
              ├─ from .exceptions import ...
              └─ from .utils import ...
                    │
                    ├─ utils/__init__.py
                    ├─ validators.py
                    └─ io.py
```

## 3. 包内依赖（单向）

```mermaid
flowchart TB
    INIT[sparktech/__init__.py]
    EXC[exceptions.py]
    V[utils/validators.py]
    IO[utils/io.py]
    UINIT[utils/__init__.py]

    INIT --> EXC
    INIT --> UINIT
    UINIT --> V
    UINIT --> IO
    V --> EXC
    IO --> EXC
```

入口脚本 `demo_*.py` → `sparktech`；`sparktech` 内部不反向依赖 demo。

## 4. try / except / else / finally 时序

```text
        ┌─────────────┐
        │   try 块     │
        └──────┬──────┘
               │
       ┌───────┴───────┐
       │  发生异常？    │
       └───┬───────┬───┘
           │是     │否
           ▼       ▼
    ┌──────────┐  ┌──────────┐
    │ except   │  │  else    │
    └────┬─────┘  └────┬─────┘
         │             │
         └──────┬──────┘
                ▼
         ┌─────────────┐
         │  finally    │  ← 总是执行
         └─────────────┘
```

## 5. 异常传播

```text
validate_name("")
    │
    raise ValidationError("姓名不能为空", field="name")
    │
    ▼
demo_exceptions.demo_catch_hierarchy()
    │
    except ValidationError → 打印 field
    │
    ▼
（若未捕获）→ 栈回溯 traceback → 进程退出
```

## 6. load_json_file 决策树

```mermaid
flowchart TD
    START[load_json_file] --> EXISTS{is_file?}
    EXISTS -->|否| E1[DataLoadError 不存在]
    EXISTS -->|是| READ[read_text]
    READ --> OS{OSError?}
    OS -->|是| E2[DataLoadError 读取失败]
    OS -->|否| PARSE[json.loads]
    PARSE --> JSON{JSONDecodeError?}
    JSON -->|是| E3[DataLoadError 解析失败]
    JSON -->|否| OK[返回对象]
```

## 7. 虚拟环境创建流程

```text
setup_venv.sh
    │
    ├─ python3 -m venv .venv
    │       └─ 复制/链接解释器 + 新建 site-packages
    │
    ├─ source .venv/bin/activate
    │       └─ PATH 前置 .venv/bin
    │
    ├─ pip install --upgrade pip
    │
    └─ pip install -r requirements.txt
            ├─ requests
            └─ python-dotenv
```

## 8. 库层 vs 入口层

```text
┌─────────────────────────────────────────┐
│  demo_exceptions.py（入口 / 展示层）       │

                   │ 调用

│        raise ValidationError(...)       │

```
