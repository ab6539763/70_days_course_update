## 第一章 · Embedding 接入 LangChain（09:00–10:00）

### 1.1 Embeddings 接口

```python
class Embeddings:
    def embed_documents(self, texts: list[str]) -> list[list[float]]: ...
    def embed_query(self, text: str) -> list[float]: ...
```

- 文档批量 `embed_documents`  
- 查询单条 `embed_query`（部分模型对 query/doc 有区别）  

### 1.2 mock 模式

无 `OPENAI_API_KEY` 或 `SPARKTECH_MOCK=1` 时用 `SparkMockEmbeddings`：

- 确定性：同文本同向量  
- 主题词加权：「退款」「工单」等相近问句更相似  

运行：`python3 mock_embeddings.py`

## 第二章 · Chroma 基础（10:00–12:00）

### 2.1 为什么 Chroma

| 特点 | 说明 |
|------|------|
| 嵌入式 | 无需独立向量库服务 |
| 持久化 | `persist_directory` 落盘 |
| LangChain 集成 | `langchain-chroma` |

### 2.2 ChromaKnowledgeBase

```python
from chroma_kb import ChromaKnowledgeBase

kb = ChromaKnowledgeBase()
kb.reset()
kb.add_documents(chunks)
hits = kb.similarity_search_with_score("怎么退款", k=3)
```

### 2.3 Retriever

```python
retriever = kb.as_retriever(search_kwargs={"k": 4})
docs = retriever.invoke("退款流程")
```

Retriever 是 LangChain LCEL 标准组件，Day 30 直接链接 Prompt + LLM。
