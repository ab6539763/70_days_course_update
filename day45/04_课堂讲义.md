## 第一章 · Week 5 测验讲评（09:00–10:30）

### 1.1 Agent 三板斧

| 环节 | 关键问题 | Week 5 对应 |
|------|----------|-------------|
| 规划 | 要不要调工具？ | ReAct / Planner |
| 执行 | 调哪个工具、参数对吗？ | ToolRegistry |
| 观察 | 工具结果如何回传？ | tool 消息 + 下一轮 LLM |

### 1.2 易错题

- 工具越多越好 → **错**，描述不清反而降准确率  
- Dify 能替代一切 → **错**，CI/审计/深度集成需代码  
- mock 没价值 → **错**，编排逻辑可在 CI 验证
