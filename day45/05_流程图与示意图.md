# Day 45 流程图与示意图

## 1. Agent 工具环（ReAct）

```mermaid
sequenceDiagram
    participant U as 用户
    participant A as IntegratedAgentReview
    participant L as MockAgentLLM
    participant T as ToolRegistry

    U->>A: 用户问题
    A->>L: messages + tools schema
    alt 需要工具
        L-->>A: tool_calls
        A->>T: execute(name, args)
        T-->>A: 工具结果字符串
        A->>L: 追加 tool 消息
        L-->>A: 最终文本
    else 直接回答
        L-->>A: content
    end
    A-->>U: final_answer
```
