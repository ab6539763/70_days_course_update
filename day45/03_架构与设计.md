# Day 45 架构与设计 · Agent 综合复盘与低代码对照

## 1. 系统上下文

```text
┌─────────────┐     ┌──────────────────────────┐     ┌─────────────┐
│  用户 REPL  │────▶│ IntegratedAgentReview    │────▶│ MockAgentLLM│
└─────────────┘     │  ├ ConversationSession   │     └─────────────┘
                    │  └ ToolRegistry          │

                                │
                    ┌───────────▼──────────────┐

```

## 2. 模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| 会话 | `ConversationSession` | 维护 messages，裁剪历史 |
| 工具 | `ToolRegistry` | schema + execute |
| 模型 | `MockAgentLLM` | 启发式 tool_calls |
| 编排 | `IntegratedAgentReview` | ReAct 环 |
| 笔记 | `dify_workflow_notes.md` | 低代码对照（非运行时） |

## 3. Agent 循环（与 Day 19 对照）

```python
for round_idx in range(1, MAX_ROUNDS + 1):
    result = llm.chat(messages, schemas)
    if result.tool_calls:
        execute_tools → append tool messages
        continue
    return final_answer
```

与 Dify 工作流：画布上的「LLM 节点 → 条件 → 工具节点」与此循环同构。

## 4. 工具 schema 设计原则

1. **name** 动词短语：`search_knowledge` 优于 `kb`  
2. **description** 写清触发场景  
3. **parameters** 最小必要字段  
4. 返回值统一为 **字符串**（教学简化）

## 5. 低代码映射表

| 代码概念 | Dify | Coze |
|----------|------|------|
| `IntegratedAgentReview.run` | Workflow Run | Bot 对话 |
| `ToolRegistry` | Tool 节点 | 插件 |
| `search_knowledge` | Knowledge Retrieval | 知识库 |
| `MAX_ROUNDS` | 循环节点上限 | 工作流深度限制 |
| `verify_day45.py` | 无原生等价 | 无原生等价 |

## 6. 数据流

```text
user_text
  → session.add_user
  → llm.chat → tool_calls?
       yes → tools.execute → session.add_tool → loop
       no  → session.add_assistant → final_answer
```
