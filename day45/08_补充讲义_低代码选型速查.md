# Day 45 补充讲义 · 低代码选型速查

## 1. 一句话定位

| 平台 | 一句话 |
|------|--------|
| Dify | 开源 LLM 应用开发平台，工作流 + 知识库 + Agent |
| Coze | 字节系 Bot 搭建平台，国内模型与发布便捷 |
| 自研 | 最大灵活度，成本在工程与运维 |

## 2. 决策树

```text
需要一周内 Demo？
  ├─ 是 → 考虑 Dify / Coze
  └─ 否 → 继续
需要私有部署 + 细粒度审计？
  ├─ 是 → 自研为主，低代码辅助 PoC
  └─ 否 → 可评估托管低代码
```

## 3. 答辩高频题

**Q：为什么项目二不用 Dify？**  
A：混合检索调参、引用溯源、与客户 SSO 对接需要代码级控制；Dify 可用于运营侧 FAQ 试点。

**Q：Coze 和 Dify 怎么选？**  
A：国内 Bot 快速验证选 Coze；要私有化工作流选 Dify 开源版。
