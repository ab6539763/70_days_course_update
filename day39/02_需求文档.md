## 4. 功能需求

### 4.1 tools_basic.py

| 函数 | 行为 |
|------|------|
| `classify_ticket(text)` | 规则 mock 分类 refund/technical/account/complaint/general |
| `route_ticket(intent, tier?)` | 映射技能组 + SLA |
| `search_kb_snippet(query, limit?)` | mock KB，标注 day36 RAG 引用 |
| `calc_priority_score(u, i, vip?)` | P0–P3 优先级 |
| `run_tool(action, input)` | 统一执行入口 |

### 4.2 react_agent.py

| 符号 | 行为 |
|------|------|
| `parse_react_output(text)` | 解析 Thought/Action/Action Input/Final Answer |
| `ReActAgent.run(query)` | while 循环直至 Final Answer 或 max_steps |
| `ReActTrace` | 完整轨迹 dataclass |

### 4.3 mock_llm.py

| 符号 | 行为 |
|------|------|
| `ReActLLMClient` | mock/live 双模式 |
| `build_system_prompt` | 注入工具列表 |

## 5. 非功能需求

- 无硬编码 API Key  
- `SPARKTECH_MOCK=1` 强制 mock  
- 单测脚本 `verify_day39.py` 覆盖 import/tools/parse/agent  

## 6. 验收脚本

`python3 verify_day39.py` 检查项：

1. 模块 import  
2. 三工具返回值  
3. ReAct 文本解析  
4. 完整 agent 循环  
5. 三个 demo 脚本 exit 0
