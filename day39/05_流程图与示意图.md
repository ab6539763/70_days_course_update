# Day 39 流程图与示意图

## 1. ReAct 主循环

```mermaid
flowchart TD
    Start([用户工单]) --> Init[初始化 messages + system prompt]
    Init --> LLM[调用 LLM]
    LLM --> Parse{解析输出}
    Parse -->|Final Answer| Done([返回用户])
    Parse -->|Action| Tool[run_tool]
    Tool --> Obs[生成 Observation]
    Obs --> Append[追加到 messages]
    Append --> Check{step < max?}
    Check -->|是| LLM
    Check -->|否| Timeout([超时结束])
```

## 2. 星火智服 Phase3 工单路由

```mermaid
flowchart LR
    T[新工单] --> KB[search_kb_snippet]
    KB --> C[classify_ticket]
    C --> R[route_ticket]
    R --> A[分配技能组]
    A --> N[通知客服]
```
