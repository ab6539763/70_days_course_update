## 第一章 · 什么是 Agent（09:00–09:45）

**Agent** = LLM + 工具 + 循环决策。

| 组件 | 作用 |
|------|------|
| LLM | 推理、选工具、总结 |
| Tools | 查数据、改状态、调 API |
| Loop | 多步直至任务完成 |

星火智服 Phase3：Agent 读工单 → 分类 → 查 KB → 路由技能组。

## 第二章 · ReAct 论文要点（09:45–10:30）

**ReAct**（Reasoning + Acting）核心循环：

```text
Thought: 我需要先知道这是什么类型的工单
Action: classify_ticket
Action Input: {"text": "客户要求退款"}
Observation: {"intent": "refund", ...}

Thought: 退款应去账单组
Action: route_ticket
Action Input: {"intent": "refund", "customer_tier": "vip"}
Observation: {"team": "billing", ...}

Thought: 信息足够
Final Answer: 已路由至账单组，SLA 22 小时
```

对比 [Day 19](../day19/code/function_calling_agent.py)：那边 API 直接给 `tool_calls` JSON。
