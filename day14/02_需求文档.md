## 1. 产品概述

### 1.1 一句话描述

在终端运行的星火智服 AI 助手：维护多轮对话历史，支持斜杠命令管理会话，并将对话保存为 JSON 文件。

### 1.2 目标用户

- 内部培训生（开发与答辩）  
- 产品/销售同事（PoC 演示）  

### 1.3 非目标（Out of Scope）

- Web 界面、用户登录、多用户并发  
- 向量检索、RAG、工具调用（Agent）  
- 流式输出（SSE）—— Day 18+ 扩展

## 4. 功能需求

### 4.1 ChatMessage（models.py）

| 字段 | 类型 | 约束 |
|------|------|------|
| role | str | 仅 `system` / `user` / `assistant` |
| content | str | 非空（strip 后） |
| created_at | str | ISO8601 UTC，可选构造参数 |

| 方法 | 说明 |
|------|------|
| `to_dict()` | 序列化，供 JSON 与 API |
| `from_dict()` | 反序列化 |
| `system_prompt()` | 类方法工厂 |
| `__str__` | REPL 友好展示 |

非法 role 或空 content 必须 `raise ValueError`。

### 4.2 ConversationSession（session.py）

| 能力 | 说明 |
|------|------|
| 初始化 | 默认注入一条 system 消息 |
| `add_user_message` / `add_assistant_message` | 追加消息并更新 `updated_at` |
| `clear(keep_system=True)` | 清空历史，默认保留 system |
| `to_api_messages()` | 返回 `[{role, content}, ...]` 供 LLM |
| `to_dict()` / `from_dict()` | 完整会话序列化 |
| `messages` 属性 | 返回副本列表，避免外部直接篡改 |

### 4.3 LLMClient（llm_client.py）

| 模式 | 触发条件 | 行为 |
|------|----------|------|
| mock | 无 `OPENAI_API_KEY` 或 `SPARKTECH_MOCK=1` | 本地生成确定性 mock 回复 |
| live | 有效 `OPENAI_API_KEY` 且未强制 mock | 调用 OpenAI Chat Completions |

| 接口 | 签名 | 说明 |
|------|------|------|
| `chat` | `(messages: list[dict]) -> ChatCompletionResult` | **必须**接收完整历史，非单条 prompt |

异常统一转为 `LLMClientError`（继承 `SparkTechError`）。

### 4.4 斜杠命令（commands.py）

| 命令 | 行为 | 异常处理 |
|------|------|----------|
| `/help` | 打印帮助 | — |
| `/clear` | 清空会话（保留 system） | — |
| `/save [name]` | 写入 `data/sessions/` | 捕获存储异常，打印原因 |
| `/exit` | 退出 REPL（`/quit` 同义） | 返回 exit code 0 |
| 未知 `/xxx` | 提示使用 `/help` | 不退出 |

### 4.5 持久化（storage.py）

**JSON Schema（逻辑）：**

```json
{
  "session_id": "9b20049dc31f",
  "title": "未命名会话",
  "created_at": "2026-07-05T07:00:00+00:00",
  "updated_at": "2026-07-05T07:05:00+00:00",
  "messages": [
    {"role": "system", "content": "...", "created_at": "..."},
    {"role": "user", "content": "...", "created_at": "..."},
    {"role": "assistant", "content": "...", "created_at": "..."}
  ]
}
```

| 函数 | 说明 |
|------|------|
| `save_session(session, ...)` | 写入 JSON，返回 Path |
| `load_session(path)` | 恢复 `ConversationSession` |
| `ensure_sessions_dir()` | 自动创建目录 |

文件损坏时抛 `DataLoadError` 或 `SessionStorageError`。

### 4.6 CLI 主循环（main.py）

```text
启动 → 打印 Banner → 初始化 Session + LLMClient + CommandHandler
循环:
  读取 input
  若空行 → continue
  若以 / 开头 → CommandHandler.handle
  否则 → add_user → llm.chat → add_assistant → 打印回复
捕获: ValueError, LLMClientError, SparkTechError, 兜底 Exception
```

| 变量 | 必填 | 默认 | 说明 |

## 6. 异常处理需求

| 场景 | 期望行为 |
|------|----------|
| 用户发送空消息（非命令） | 忽略，不调用 LLM |
| ChatMessage 校验失败 | 打印 `[输入错误]`，继续 REPL |
| LLM API 失败 | 打印 `[LLM 错误]`，**不**写入 assistant 消息 |
| 保存失败 | 打印 `[保存失败]`，会话内存不受影响 |
| Ctrl+C | 提示可用 `/exit`，不直接崩溃 |

禁止：`except: pass`、静默吞掉异常。
