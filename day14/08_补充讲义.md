## 七、常见运行时问题

| 症状 | 原因 | 解决 |
|------|------|------|
| `ModuleNotFoundError: sparktech` | PYTHONPATH 未设 | `export PYTHONPATH=$(pwd)` 或用 `run.sh` |
| `No module named 'openai'` | 依赖未装 | `pip install -r requirements.txt` |
| mock 但想测 live | `SPARKTECH_MOCK=1` | 设为 `0` 并配置 Key |
| JSON 中文乱码 | 非 UTF-8 写入 | `ensure_ascii=False` + `encoding=utf-8` |
| venv 创建失败 | 缺 python3-venv | `apt install python3-venv` 或直接用系统 Python |
