## 第二章 · ConversationSession（10:15–11:00）

### 2.1 设计要点

`ConversationSession` 是 **list[ChatMessage] 的面向对象封装**，不是简单 alias。

必须实现：

| 方法 | 测试方法 |
|------|----------|
| `add_user_message` | `len(session)` 增加 |
| `to_api_messages` | 无 `created_at` 字段 |
| `clear(keep_system=True)` | 只剩 system |
| `to_dict` / `from_dict` | 往返不丢消息 |

### 2.2 参考实现片段

```python
def to_api_messages(self) -> list[dict]:
    return [{"role": m.role, "content": m.content} for m in self._messages]
```

### 2.3 常见错误

| 错误 | 后果 |
|------|------|
| 直接暴露 `_messages` 引用 | 外部 bypass 校验 |
| clear 删掉 system | 下一轮 LLM 无角色设定 |
| 忘记 `_touch()` | JSON 里 `updated_at` 不更新 |

## 第四章 · LLMClient（14:00–15:00）

### 4.1 Day 12/13 模式回顾

Day 9 是 `generate(prompt: str)`；Stage Project 升级为：

```python
result = client.chat(session.to_api_messages())
```

**整段历史** 发给模型，才能实现多轮 memory。

### 4.2 mock 模式逻辑

```python
@property
def is_mock_mode(self) -> bool:
    return self._force_mock or not self._api_key.strip()
```

mock 回复应：

1. 标明 `[mock/模型名]`  
2. 引用最近一条 user 内容  
3. 显示当前 `len(messages)` 证明上下文传入  

### 4.3 live 模式

```python

client = OpenAI(api_key=..., base_url=...)
response = client.chat.completions.create(model=..., messages=messages)
text = response.choices[0].message.content
```

捕获 `APIError` → `LLMClientError`。

## 第五章 · commands.py（15:00–15:45）

### 5.1 命令分发模式

```python
_dispatch = {
    "help": self._cmd_help,
    "clear": self._cmd_clear,
    "save": self._cmd_save,
    "exit": self._cmd_exit,
    "quit": self._cmd_exit,
}
```

返回 `CommandResult(handled, should_exit, message)`，**main 只解读结果**，不在 main 里写一堆 `if cmd == "clear"`。

### 5.2 `/save` 异常

```python
try:
    path = save_session(self.session, base_dir=self.sessions_dir)
except Exception as exc:
    return CommandResult(handled=True, message=f"保存失败：{exc}")
```

### 5.3 帮助文本

常量 `HELP_TEXT` 放在 `commands.py` 顶部，便于产品改文案。

## 第六章 · main.py 主循环（15:45–16:30）

### 6.1 结构模板

```python
def run_repl() -> int:
    client = LLMClient()
    session = ConversationSession()
    commands = CommandHandler(session, sessions_dir=DEFAULT_SESSIONS_DIR)

    while True:
        user_input = input("你> ").strip()
        if not user_input:
            continue
        if commands.is_command(user_input):
            result = commands.handle(user_input)
            ...
            continue
        try:
            session.add_user_message(user_input)
            completion = client.chat(session.to_api_messages())
            session.add_assistant_message(completion.text)
            print(f"\n助手> {completion.text}\n")
        except ...:
            ...
```

### 6.2 异常分层

| 捕获 | 场景 |
|------|------|
| `ValueError` | ChatMessage 校验 |
| `LLMClientError` | API 失败 |
| `SparkTechError` | 配置/存储 |
| `Exception` | 兜底，打印 `[未知错误]` |

**LLM 失败时不要** `add_assistant_message`，否则会污染历史。

### 6.3 Ctrl+C

```python
except (EOFError, KeyboardInterrupt):
    print("\n已中断，输入 /exit 可正常退出。")
    continue
```
