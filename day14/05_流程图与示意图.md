# Day 14 流程图与示意图

---

## 1. 总体 REPL 流程

```mermaid
flowchart TD
    Start([启动 run.sh]) --> Init[初始化 LLMClient + Session + Commands]
    Init --> Banner[打印 Banner 与模式]
    Banner --> Read[读取 你> 输入]
    Read --> Empty{空行?}
    Empty -->|是| Read
    Empty -->|否| Cmd{以 / 开头?}
    Cmd -->|是| Dispatch[CommandHandler.handle]
    Dispatch --> Exit{should_exit?}
    Exit -->|是| End([退出 0])
    Exit -->|否| PrintCmd[打印命令结果]
    PrintCmd --> Read
    Cmd -->|否| AddUser[session.add_user_message]
    AddUser --> API[llm.chat to_api_messages]
    API --> Mock{mock 模式?}
    Mock -->|是| MockReply[本地 mock 文本]
    Mock -->|否| LiveReply[OpenAI API]
    MockReply --> AddAsst[add_assistant_message]
    LiveReply --> AddAsst
    AddAsst --> PrintAsst[打印 助手>]
    PrintAsst --> Read
```

## 2. 斜杠命令决策树

```mermaid
flowchart TD
    Input["/xxx args"] --> Parse[拆分命令名与参数]
    Parse --> Help{/help}
    Parse --> Clear{/clear}
    Parse --> Save{/save}
    Parse --> Exit{/exit 或 /quit}
    Parse --> Unknown[未知命令]
    Help --> ShowHelp[打印 HELP_TEXT]
    Clear --> KeepSys[保留 system 消息]
    KeepSys --> Wipe[删除 user/assistant]
    Save --> HasName{有文件名?}
    HasName -->|是| NamedFile[写入 data/sessions/name.json]
    HasName -->|否| IdFile[写入 data/sessions/session_id.json]
    Exit --> Quit[should_exit=True]
    Unknown --> Hint[提示 /help]
```

## 3. 多轮 memory 数据流

```ascii
Round 1:
  messages = [system, user₁]
       │
       ▼ chat()
  messages = [system, user₁, assistant₁]

Round 2:
  messages = [system, user₁, assistant₁, user₂]
       │
       ▼ chat()  ← 注意：整表发送，不是只发 user₂
  messages = [system, user₁, assistant₁, user₂, assistant₂]
```

## 6. 异常传播（Day 10 模式）

```ascii
ValueError (ChatMessage)
    └── main: [输入错误] → 继续 REPL

LLMClientError
    └── main: [LLM 错误] → 不写入 assistant → 继续 REPL

SessionStorageError / DataLoadError
    └── commands / main: 打印原因 → 继续 REPL

Exception (未知)
    └── main: [未知错误] → 继续 REPL（不 exit）
```
