## Part A · Review 要点（讲评用）

### 常见扣分项

| 现象 | 扣分原因 | 修复 |
|------|----------|------|
| `messages` 全局 list | 无 Session 封装 | 迁入 `ConversationSession` |
| 只把最后一句发给 LLM | 假多轮 | 用 `to_api_messages()` 全量 |
| `except: pass` | 吞异常 | 打印并 continue |
| assistant 写入失败回复 | 污染历史 | LLM 成功后再 append |
| `/save` 路径写死 C 盘 | 不可移植 | `Path(__file__).parent.parent` |

### 示范：合格的主循环异常处理

```python
try:
    session.add_user_message(user_input)
    completion = client.chat(session.to_api_messages())
    session.add_assistant_message(completion.text)
    print(f"\n助手> {completion.text}\n")
except ValueError as exc:
    print(f"[输入错误] {exc}")
except LLMClientError as exc:
    print(f"[LLM 错误] {exc.message}")
```

def _cmd_load(self, args: list[str]) -> CommandResult:
    if not args:
        return CommandResult(handled=True, message="用法：/load <文件名>")
    name = args[0]
    if not name.endswith(".json"):
        name += ".json"
  path = (self.sessions_dir or DEFAULT_SESSIONS_DIR) / name

## 答辩 Q&A 参考

**Q：为什么 ConversationSession 不直接用 list？**  
A：封装后可在 `add_*` 统一校验、更新时间戳、转换 API 格式，避免 main 里散落逻辑。

**Q：`created_at` 发给 API 会怎样？**  
A：OpenAI 会忽略未知字段，但规范做法是 `to_api_messages()` 只发 role/content。

**Q：mock 回复为什么要显示消息条数？**  
A：答辩时向评委证明 **完整上下文已传入**，而非单轮 prompt。
