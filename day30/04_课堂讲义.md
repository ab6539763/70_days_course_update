## 第三章 · RAGPipeline 源码走读（11:00–12:00）

### 3.1 ingest

```python
pipeline = RAGPipeline()
n = pipeline.ingest(reset=True)
```

内部：`load_documents` → `split_documents` → `Chroma.add_documents`

### 3.2 retrieve

```python
chunks = pipeline.retrieve("如何退款", k=4)
# RetrievedChunk: content, source, score
```

### 3.3 generate + unknown

```python
result = pipeline.generate("今天天气怎么样？")
assert result.fallback_unknown
```

`RAG_SCORE_THRESHOLD` 默认 0.35，可在 `.env` 调整。

### 3.4 mock 生成

无 Key 时 `_mock_generate` 从检索块抽取退款/工单相关句，并附 `引用：[faq_refund.txt]`。
