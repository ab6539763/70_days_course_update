# Day 30 架构与设计 · 完整 RAG 流水线

## 1. 六阶段数据流

```text
┌─────────┐   ┌─────────┐   ┌──────────┐   ┌─────────┐
│  load   │──▶│  split  │──▶│  embed   │──▶│  store  │
└─────────┘   └─────────┘   └──────────┘   └────┬────┘
                                                   │
     ┌─────────┐   ┌──────────┐                    │
     │ generate│◀──│ retrieve │◀───────────────────┘
     └─────────┘   └──────────┘
```

## 2. generate 分支

```text
retrieve(query, k)
      │
      ▼
_should_unknown?
   是 ──▶ UNKNOWN_REPLY（无 citations）
   否 ──▶ mock_generate / live LLM
              │
              ▼
         answer + citations
```
