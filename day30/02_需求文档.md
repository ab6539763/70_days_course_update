## 2. 功能需求

### rag_pipeline.py

| 方法 | 阶段 |
|------|------|
| `ingest()` | load+split+embed+store |
| `retrieve()` | retrieve |
| `generate()` | retrieve+generate |
| `ask()` | 自动 ingest + generate |

### rag_cli.py

| 子命令 | 说明 |
|--------|------|
| `ingest` | 重建索引 |
| `ask` | 单次问答，`--json` |
| `chat` | 交互式 |

### prompts/rag_prompt.txt

占位符：`{context}`、`{question}`

### unknown 规则

- 无检索结果  
- 最高 score < threshold  
- 明显无关 query（天气/股票等）且上下文无匹配  

标准文案：

```text
我不知道。建议联系人工客服或查阅官方文档。
```
