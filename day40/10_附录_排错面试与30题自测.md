## 一、现场排错剧本（10 个场景）

### 剧本 1：verify 报 ImportError: tools_basic

**台词**：「先确认 day39 目录完整，不要只 clone day40。」

```bash
ls ../day39/code/tools_basic.py
cd day40/code && python3 -c "from lc_tools import classify_ticket; print(classify_ticket.name)"
```

### 剧本 2：Agent 输出「我无法访问工具」

**原因**：`MessagesPlaceholder("agent_scratchpad")` 缺失或拼写错误。  
**验证**：打印 `prompt.messages` 是否含 scratchpad 占位。

### 剧本 3：live 模式一直 Could not parse LLM output

**原因**：模型不支持 native tool_calls（如部分开源模型未正确配置）。  
**处理**：换 `gpt-4o-mini` / 通义千问 FC 版；或回退 `create_react_agent`。

### 剧本 4：mock 只 classify 不 route

**原因**：`MockToolChatModel` 第二轮逻辑要求 bound 含 `route_ticket`；检查 `get_ticket_routing_tools()` 是否包含 route。  
**对照代码**：`lc_mock_llm.py` 第 148–170 行。

### 剧本 5：intermediate_steps 为空

**原因**：`return_intermediate_steps=False`（默认）。  
**修复**：`lc_agent.py` 已设 `True`，若自建 Executor 勿遗漏。

### 剧本 6：工具返回 dict 导致 TypeError

**原因**：@tool 应返回 str。  
**修复**：`return json.dumps(data, ensure_ascii=False)`。

### 剧本 7：max_iterations 用尽无 output

**现象**：verbose 显示 6 步全是 classify。  
**处理**：工具返回应引导模型前进；检查 classify 返回 JSON 是否含 `intent` 字段。

### 剧本 8：search_calc 不算数

**原因**：用户未触发 calculator 关键词。  
**演示句**：「请用 calculator 计算 4*5+3」——明确要求工具名。

### 剧本 9：多进程下 mock 不一致

**原因**：环境变量未 export 到子进程。  
**处理**：`SPARKTECH_MOCK=1 python3 lc_agent.py` 写在一行。

### 剧本 10：requirements 版本冲突

```bash
pip install langchain>=0.2 langchain-openai langchain-community
python3 verify_day40.py
```

## 四、面试快答（8 题）

1. **@tool 与 OpenAI function 关系？** — LangChain 封装，生成兼容 schema。  
2. **AgentExecutor vs LangGraph？** — 前者隐式循环；后者显式图，适合 HITL。  
3. **tool_calls 与 ReAct 字符串？** — 结构化 vs 文本解析，生产选前者。  
4. **max_iterations 与 max_tokens？** — 前者限制 Agent 步数；后者限制单次生成。  
5. **如何做工具权限控制？** — 按角色过滤 tools 列表，而非全量 bind。  
6. **intermediate_steps 存哪？** — 内存返回；生产写日志/OTel span。  
7. **Mock LLM 测试什么？** — 编排逻辑，不测模型智商。  
8. **Day 40 最大技术债？** — search_kb 未接真 RAG HTTP。

## 五、自测 @tool 与 Schema（1–10）

1. `@tool` 装饰器做了什么？→ 生成 name、description、args_schema。  
2. docstring 为何重要？→ 模型选型依据。  
3. `max_iterations=5` 作用？→ 防死循环。  
4. `return_intermediate_steps=True`？→ 返回 (action, observation) 列表。  
5. `create_tool_calling_agent` vs ReAct？→ 结构化 tool_calls。  
6. 如何强制用某工具？→ Prompt + 清晰描述（无法 100% 强制）。  
7. 多工具选错？→ 改描述、Few-shot、Supervisor。  
8. search_kb 对接 Day 36？→ HTTP 调 rag_service。  
9. Could not parse LLM output？→ 模型未返回 tool_calls。  
10. mock 如何路由？→ `lc_mock_llm._plan_tool_calls` 关键词。
