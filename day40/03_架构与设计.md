# Day 40 架构与设计

## 1. 三层架构

```text
ChatPromptTemplate + MessagesPlaceholder(agent_scratchpad)
        │
        ▼
create_tool_calling_agent(llm, tools, prompt)
        │
        ▼
AgentExecutor(agent, tools, max_iterations)
        │
        ▼
Tool.invoke ← @tool 包装 Day 39 tools_basic
```

## 2. 与 Day 19/39 对照

| 层 | Day 19 | Day 39 | Day 40 |
|----|--------|--------|--------|
| Schema | JSON 文件 | 文本工具列表 | @tool 自动生成 |
| 执行 | tool_runner | run_tool | Tool.invoke |
| 循环 | FunctionCallingAgent | ReActAgent | AgentExecutor |

## 3. Prompt 设计

- `system`：角色 + 业务约束  
- `human`：`{input}`  
- `agent_scratchpad`：框架自动填充 tool 往返  

## 4. Mock 策略

`MockToolChatModel` 启发式返回 `AIMessage(tool_calls=[...])`，第二轮根据 tool 结果返回 route 或 finalize。
