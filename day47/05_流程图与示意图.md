```mermaid
flowchart LR

    LLM --> SQL[SELECT 语句]

    V -->|拒绝| E[错误提示]
```

## 2. ER 图

```mermaid
erDiagram
    customers ||--o{ orders : places
    orders ||--o{ order_items : contains
    products ||--o{ order_items : "line item"

    customers {
        int customer_id PK
        text name
        text city
        text segment
    }
    products {
        int product_id PK
        text sku
        text category
        real unit_price
    }
    orders {
        int order_id PK
        int customer_id FK
        text order_date
        text status
    }
    order_items {
        int item_id PK
        int order_id FK
        int product_id FK
        real line_amount
    }
```
