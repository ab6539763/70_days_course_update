# Day 47 需求文档 · Text-to-SQL 销售分析 Agent

## 1. 用户故事

**US-01** 作为财务 BP，我用中文提问「各品类收入多少」，系统返回表格摘要。  
**US-02** 作为 DBA，我要求任何写操作 SQL 被拒绝。  
**US-03** 作为 QA，我运行 `verify_day47.py` 验证核心分析问题。
