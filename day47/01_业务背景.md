# Day 47 业务背景 · 财务 BP 的自然语言查数需求

## 1. 事件回顾

**需求方**：财务部 BP 小林  
**场景**：每周销售复盘需查 SQLite 仓（教学库）中品类收入、区域订单、企业客户贡献  
**痛点**：不会写 JOIN，Excel 导出滞后  

张工方案：

> Text-to-SQL Agent = schema 描述 + LLM 生成 SELECT + 执行层白名单校验 + 自然语言总结

## 2. 业务表概览

| 表 | 业务含义 |
|----|----------|
| customers | 客户主数据（城市、segment） |
| products | SKU 与品类单价 |
| orders | 订单头（日期、状态、区域） |
| order_items | 订单行金额 |

## 3. 安全红线

1. **只读**：仅允许 `SELECT`  
2. **单语句**：拒绝 `;` 多语句  
3. **关键字黑名单**：DROP / DELETE / PRAGMA 等  
4. Day 46 护栏可复用于用户自然语言输入
