# Day 47 课堂讲义 · Text-to-SQL 实战

## 第一章 · 概念（09:00–10:30）

### 1.1 Text-to-SQL 链路

```text
Schema + 用户问题 → LLM → SQL → 校验 → 执行 → 总结
```

### 1.2 为何必须校验

LLM 可能生成 `DROP TABLE` 或 `DELETE`。执行层 **白名单** 是最后防线。

```bash
python3 text_to_sql_agent.py
```

### 3.2 课堂必测四问

| 问题 | 期望 |
|------|------|
| 总销售额是多少 | SUM(line_amount) |
| 各品类收入 | GROUP BY category |
| 各城市订单数 | JOIN customers |
| Enterprise 客户销售额 | segment 过滤 |

### 3.3 读 `validate_sql`

只允许 `SELECT`，拒绝多语句与危险关键字。

### 3.4 Mock vs Live

- Mock：`MockTextToSQL` 启发式  
- Live：将 schema 拼入 Prompt，解析 ```sql 代码块（作业扩展）
