## B2 流程图参考答案

### add 流程（要点）

1. 用户输入各字段  
2. `strip` / `normalize_phone` / `normalize_email`  
3. `validate_name` / `validate_phone`  
4. 遍历检查手机号是否重复  
5. 构造 `dict`，写入 `created_at` / `updated_at`  
6. `contacts.append(record)`  
7. `next_id += 1`，`dirty = True`  

### quit 落盘

`main` 在 `break` 前调用 `save_contacts(contacts, next_id, path)` → `json.dump` 写入含 `contacts` 与 `next_id` 的顶层对象。

### next_id 恢复

`load_contacts` 读取 JSON 的 `next_id` 字段；若缺失则默认 `1`。

## X1 import_employees 思路

```python
root, _ = load_mock()  # 复用 day05 parse_api
contacts, next_id = load_contacts()
phones = {c["phone"] for c in contacts}
for emp in employees:
    phone = normalize_phone(emp.get("phone", ""))
    if phone in phones:
        continue
    next_id = add_contact(
        contacts, next_id,
        emp.get("name", ""),
        phone,
        department=emp.get("department", "未分配"),
        notes=f"import:{emp.get('employee_id', '')}",
    )
    phones.add(phone)
save_contacts(contacts, next_id)
```
