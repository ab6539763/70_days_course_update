## 3. 数据模型（v1.0）

### 3.1 单条联系人（dict）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | int | 是 | 自增，从 1 开始，全局唯一 |
| `name` | str | 是 | strip 后非空 |
| `phone` | str | 是 | 去空格后至少 7 位数字 |
| `email` | str | 否 | strip 后小写，可空串 |
| `department` | str | 否 | 默认 `未分配` |
| `notes` | str | 否 | 备注，可空 |
| `created_at` | str | 是 | ISO 8601 时间戳 |
| `updated_at` | str | 是 | 最后修改时间 |

### 3.2 JSON 文件顶层结构

```json
{
  "version": "1.0",
  "updated_at": "2026-07-05T08:30:00+00:00",
  "next_id": 6,
  "contacts": [ /* list[dict] */ ]
}
```

### 3.3 内存状态

```python
contacts: list[dict] = []
next_id: int = 1
data_path: Path = .../contacts.json
```

## 4. 功能需求

### 4.1 CLI 命令

| 编号 | 命令 | 行为 |
|------|------|------|
| 1 | add | 交互录入，校验后追加 |
| 2 | list | 展示全部，可选排序 id/name/department |
| 3 | search | 关键词搜索，可选范围：全部/姓名/手机/部门/邮箱 |
| 4 | update | 按 id 更新，留空字段表示不修改 |
| 5 | delete | 按 id 删除 |
| 6 | save | 手动保存到 JSON |
| 7 | reload | 从文件重新加载（需确认，防丢未保存修改） |
| 8 | stats | 按部门统计人数 |
| 0 | quit | 退出，**自动 save** |

### 4.2 列表展示格式

```text
[#1] 陈晓 | 13800138001 | 大模型应用开发部 | chen.xiao@sparktech.cn | 备注: Day1 入职卡片原型负责人
```

### 4.3 校验规则

| 编号 | 规则 |
|------|------|
| V-01 | 姓名 strip 后不得为空 |
| V-02 | 手机号去空格后至少 7 位数字 |
| V-03 | 同一手机号不得重复添加 |
| V-04 | update/delete 时 id 必须存在 |
| V-05 | JSON 损坏时友好提示，不崩溃退出整个 Python |
