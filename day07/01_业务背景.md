### 1.1 现场情况

周五上午站会前，刘姐在部门群发了条消息：

> 「培训生这周学了变量、字符串、循环、列表、字典和 JSON——  
> 下午周测之外，请交付一个 **命令行通讯录**：能录联系人、能搜、能改、能删，**关掉程序再打开数据还在**。  
> 字段至少包含：姓名、手机、部门；邮箱和备注可选。  
> 这是 Week 1 的毕业作品，也是下周一 Day 8 学 OOP 之前的「裸写版」基线。」

张工把需求翻译成工程师语言：

| 业务说法 | 技术说法 |
|----------|----------|
| 通讯录 | `list[dict]` 内存存储 + JSON 文件持久化 |
| 录入联系人 | `add`：校验 + `append` |
| 修改资料 | `update`：按 `id` 定位后改字段 |
| 删除记录 | `delete`：按 `id` `pop` |
| 按姓名/手机搜 | `search`：遍历 + 子串匹配 |
| 关掉再打开还在 | `json.dump` / `json.load` 读写 `contacts.json` |
| Week 1 收官 | 串联 Day 1～6，不写新语法大类 |

## 2. 今日你在项目中的任务

```text
  contacts.json（示例 / 持久化文件）
            │
            ▼
  load_contacts() ──▶  contacts: list[dict]  +  next_id
            │
            ▼
  CLI 主循环：add / list / search / update / delete / save / reload / stats
            │
            ▼
  save_contacts() ──▶  contacts.json（退出时自动保存）
            │
            ▼
  刘姐验收 ──▶  Day 8 用 class Contact 重构同一业务
```
