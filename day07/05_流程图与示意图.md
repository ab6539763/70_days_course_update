## 2. add 联系人流程

```mermaid
flowchart TD
    A[用户选择 add] --> B[输入姓名/手机等]
    B --> C[strip 与规范化]
    C --> D{校验通过?}
    D -->|否| E[打印 ValueError 提示]
    E --> Z[返回菜单]
    D -->|是| F{手机号重复?}
    F -->|是| E
    F -->|否| G[构造 dict 记录]
    G --> H[append 到 contacts]
    H --> I[next_id += 1]
    I --> J[dirty = True]
    J --> Z
```

## 3. search 流程

```mermaid
flowchart TD

    B --> C[keyword.strip.lower]
    C --> D[初始化 results=[]]
    D --> E{遍历 contacts}
    E --> F{field 匹配?}
    F -->|all| G[拼接多字段子串匹配]
    F -->|name/phone/...| H[单字段匹配]
    G --> I{命中?}
    H --> I
    I -->|是| J[append 到 results]
    I -->|否| E
    J --> E
    E -->|结束| K[按 id 排序]
    K --> L[print_contact_table]
```

## 4. JSON 持久化时序

```mermaid
sequenceDiagram

```
