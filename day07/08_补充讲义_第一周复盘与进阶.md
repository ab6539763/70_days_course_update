## 3. 十大常见坑（Week 1 合集）

| # | 坑 | 正确做法 |
|---|-----|----------|
| 1 | `input` 得到的全是 str | 比较数字前 `int()` |
| 2 | 缩进混用 Tab 和空格 | 统一 4 空格 |
| 3 | `while` 忘记更新循环变量 | 死循环 |
| 4 | `list` 赋值 `b=a` 共享引用 | 拷贝用 `list(a)` 或切片 |
| 5 | `dict` 缺键用 `d[k]` 崩溃 | 用 `.get(k, 默认)` |
| 6 | JSON 里写 `True` 当 python | Python 用 `True`，JSON 用 `true` |
| 7 | `json.dump` 忘 `encoding` | 文件 `open(..., encoding='utf-8')` |
| 8 | 修改 list 时边遍历边删 | 先收集索引或倒序删 |
| 9 | 函数不 `return` 却用返回值 | 默认 `return None` |
| 10 | 改内存忘写文件 | 通讯录必须 `save` |

## 7. Day 8 预习：为什么要 OOP？

今日 `address_book.py` 约 500 行单文件。随着功能增加：

- 函数参数越来越多（`contacts`, `next_id`, `path` 到处传）  
- 数据与操作分离在概念上是一体的「通讯录」  

**类**把数据（属性）和操作（方法）绑在一起：

```python
book = ContactBook()
book.load()
book.add("陈晓", "138...")
book.save()
```

周一先别背语法，带着「今日函数怎么搬进类」的问题上课。
