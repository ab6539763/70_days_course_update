## 1. 目标

1. **HTTP 可演示**：`http_basics_demo.py` 覆盖 GET/POST、状态码、headers、JSON body。  
2. **首次真 API**：`LLMClient` 封装 DeepSeek Chat Completions（OpenAI 兼容）。  
3. **安全合规**：API Key 仅来自环境变量；提供 `.env.example`；禁止硬编码。  
4. **mock 可运行**：无 Key 时打印将发送的请求，返回模拟回复，全流程可验收。  
5. **CLI v0**：`cli_chat_v0.py` 单轮问答，支持交互与 `-q` 非交互。

## 4. 功能需求

### 4.1 http_basics_demo.py

| 演示项 | 要求 |
|--------|------|
| GET | 访问 `https://httpbin.org/get`，带 query params |
| POST JSON | 访问 `/post`，body 含 `model` + `messages` 示例 |
| 状态码 | 演示 200 / 404 / 500 |
| headers | 自定义 `Authorization`、`X-SparkTech-Project` |

### 4.2 llm_client.py — LLMClient

| 方法/属性 | 行为 |
|-----------|------|
| `__init__` | 读 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`（默认 `https://api.deepseek.com`） |
| `mock_mode` | 无 Key 时为 `True` |
| `build_messages()` | 构造 `[{role, content}, ...]` |
| `build_payload()` | 含 `model`、`messages`、`temperature`、`max_tokens` |
| `chat()` | 单轮对话；mock 时 `_print_mock_request` + 模拟回复 |
| `ChatResponse` | `content`、`model`、`usage`、`mock` 标志 |

**API 端点**：`POST {BASE_URL}/v1/chat/completions`

**请求头**：
```text
Authorization: Bearer <DEEPSEEK_API_KEY>
Content-Type: application/json
```

**响应解析路径**：
```text
response.json()["choices"][0]["message"]["content"]
```

### 4.3 cli_chat_v0.py

| 模式 | 行为 |
|------|------|
| 交互 | 循环读入，输入 `quit`/`exit`/`q` 退出 |
| 非交互 | `python cli_chat_v0.py -q "问题"` 打印单条回复 |
| 系统提示 | 默认星火智服客服人设，可通过 `--system` 覆盖 |

**范围外（Day 14）**：多轮 `messages` 历史、会话持久化。

### 4.4 环境变量（.env.example）

```env
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
```
