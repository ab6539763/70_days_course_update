## 3. 与大模型开发的隐性联系

| 今日知识点 | 日后场景 |
|------------|----------|
| POST + JSON body | 所有 Chat Completions / Agent 工具调用 |
| `messages` 角色 | system 定人设、user 提问、assistant 历史（Day 14） |
| 状态码 401/429 | Key 轮换、限流退避、告警 |
| 响应解析 `choices[0]` | 流式 SSE 前必先理解非流式结构 |
| 环境变量存 Key | 生产用 K8s Secret / 密钥管理服务 |
| mock 模式 | 单元测试、PR 检查、离线开发 |

## 4. 今日学习目标（业务语言）

1. 理解 HTTP GET/POST、状态码、headers、body 在 LLM API 中的对应关系  
2. 熟练使用 `requests` 访问公开端点并构造 JSON POST  
3. 完成星火智服首次 DeepSeek API 调用（或 mock 等价演示）  
4. 掌握 API Key 管理规范，代码零硬编码  
5. 交付单轮命令行问答程序，为 Day 14 多轮对话奠基
