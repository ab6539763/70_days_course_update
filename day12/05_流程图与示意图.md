```text
  GET  /resource?id=1     ──▶  取数据，参数在 URL（查询字符串）
```

## 4. LLM API 完整时序

```mermaid
sequenceDiagram
    participant App as cli_chat_v0
    participant LC as LLMClient
    participant Req as requests
    participant DS as DeepSeek

    App->>LC: chat("VPN 问题")
    LC->>LC: build_messages + build_payload
    alt mock_mode
        LC->>LC: _print_mock_request(payload)
        LC-->>App: ChatResponse(mock=True)
    else live
        LC->>Req: post(url, headers, json=payload)
        Req->>DS: HTTPS POST
        DS-->>Req: 200 + JSON body
        Req-->>LC: Response
        LC->>LC: json() → choices[0].message.content
        LC-->>App: ChatResponse(mock=False)
    end
    App->>App: print 星火智服: content
```

## 8. mock vs LIVE 对比

| 维度 | mock 模式 | LIVE 模式 |
|------|-----------|-----------|
| 触发条件 | 无 `DEEPSEEK_API_KEY` | Key 已配置 |
| 网络 | 不请求 | HTTPS 至 DeepSeek |
| 输出 | 打印将发送的请求 + 模拟回复 | 真实模型文本 |
| 用途 | 课堂、CI、无额度账号 | 里程碑演示、作业真机 |
| `ChatResponse.mock` | `True` | `False` |

## 9. 与 httpbin 演示的对照

```text
  上午 http_basics_demo          下午 llm_client
  ─────────────────────          ─────────────────
  POST httpbin.org/post    ≈     POST api.deepseek.com/.../chat/completions
  headers: User-Agent      ≈     headers: Authorization
  json: { model, messages }≈     json: { model, messages, temperature }
  response.json()["json"]  ≈     response.json()["choices"][0]["message"]
```
